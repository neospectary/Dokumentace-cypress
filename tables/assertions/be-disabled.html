be.disabled

Ověření, že element je deaktivovaný (disabled). Používá se pro ověření, že element není aktivní.

Kdy použít

  • Pro ověření, že tlačítko je disabled před vyplněním formuláře
  • Pro kontrolu, že element je správně deaktivovaný
  • Pro testování validace formuláře

Syntaxe

cy.should('be.disabled')
cy.and('be.disabled')

Příklady

Základní použití

cy.get('button[type="submit"]').should('be.disabled')
cy.get('input[disabled]').should('be.disabled')

Před vyplněním formuláře

cy.get('button[type="submit"]').should('be.disabled')
cy.get('input[name="email"]').type('test@example.com')
cy.get('button[type="submit"]').should('be.enabled')

Důležité poznámky

  • Opačná assertion: be.enabled
  • Funguje s inputy, textarea, select, button
