be.enabled

Ověření, že element je aktivní (není disabled). Používá se pro inputy, tlačítka a další interaktivní elementy.

Kdy použít

  • Před interakcí s inputem nebo tlačítkem
  • Pro ověření, že tlačítko je aktivní po vyplnění formuláře
  • Pro kontrolu, že element není disabled
  • Po změně stavu, která by měla aktivovat element

Syntaxe

cy.should('be.enabled')
cy.and('be.enabled')

Příklady

Základní použití

cy.get('button[type="submit"]').should('be.enabled')
cy.get('input[name="email"]').should('be.enabled')

Po vyplnění formuláře

cy.get('input[name="email"]').type('test@example.com')
cy.get('input[name="password"]').type('password')
cy.get('button[type="submit"]').should('be.enabled')

Kombinace s dalšími assertions

cy.get('button')
  .should('be.visible')
  .and('be.enabled')
  .and('not.have.class', 'loading')

Důležité poznámky

  • Funguje s inputy, textarea, select, button
  • Opačná assertion: be.disabled
  • Automaticky čeká na změnu stavu

Související assertions

  • be.disabled - element je deaktivovaný
  • be.visible - element je viditelný
