be.hidden

Ověření, že element je skrytý. Element může existovat v DOM, ale není viditelný.

Kdy použít

  • Pro ověření, že element je skrytý po akci
  • Pro kontrolu, že modál nebo menu bylo zavřeno
  • Pro testování toggle funkcionality

Syntaxe

cy.should('be.hidden')
cy.and('be.hidden')

Příklady

Základní použití

cy.get('.modal').should('be.hidden')
cy.get('.menu').should('be.hidden')

Po zavření

cy.get('.close-button').click()
cy.get('.modal').should('be.hidden')

Důležité poznámky

  • Opačná assertion: be.visible
  • Element může existovat v DOM, ale být skrytý
