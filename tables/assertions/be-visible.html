be.visible

Ověření, že element je viditelný na stránce. Element musí být v DOM a mít CSS vlastnosti, které ho činí viditelným (display: none, visibility: hidden, opacity: 0, atd. způsobí selhání).

Kdy použít

  • Před interakcí s elementem (click, type, atd.)
  • Pro ověření, že se element zobrazil po akci
  • Pro kontrolu, že element není skrytý
  • Po načtení stránky nebo po změně stavu

Syntaxe

cy.should('be.visible')
cy.and('be.visible')

Příklady

Základní použití

cy.get('button').should('be.visible')
cy.get('.modal').should('be.visible')

Před interakcí

cy.get('input[name="email"]')
  .should('be.visible')
  .type('test@example.com')

Po akci

cy.get('[data-cy="open-modal"]').click()
cy.get('.modal').should('be.visible')

Kombinace s dalšími assertions

cy.get('button')
  .should('be.visible')
  .and('be.enabled')
  .and('contain', 'Odeslat')

Důležité poznámky

  • Element musí být v DOM a viditelný
  • Automaticky čeká na viditelnost (retry mechanismus)
  • Selže pokud je element skrytý pomocí CSS (display: none, visibility: hidden, opacity: 0)
  • Nepoužívejte pokud element může být mimo viewport (použijte scrollIntoView)

Kdy NEPOUŽÍVAT

  • Když element může být mimo viewport - použijte .scrollIntoView() předtím
  • Když chcete jen ověřit existenci - použijte exist
  • Když element může být skrytý - použijte be.hidden nebo not.be.visible
