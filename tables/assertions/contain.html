contain

Ověření, že element obsahuje text (částečná shoda). Užitečné když nepotřebujete ověřit přesný text.

Kdy použít

  • Když potřebujete ověřit, že element obsahuje část textu
  • Pro flexibilnější testování (nezávislé na přesném formátování)
  • Když text může obsahovat dynamické části

Syntaxe

cy.should('contain', text)
cy.and('contain', text)

Parametry

  • text (String) - Text, který má element obsahovat

Příklady

Základní použití

cy.get('h1').should('contain', 'Vítejte')
cy.get('.message').should('contain', 'úspěšně')

S dynamickým obsahem

cy.get('.user-name').should('contain', 'David')
// Funguje i když text je "Vítejte, David!"

Kombinace

cy.get('button')
  .should('be.visible')
  .and('contain', 'Odeslat')

Důležité poznámky

  • Částečná shoda - element musí obsahovat zadaný text
  • Case-sensitive (rozlišuje velká/malá písmena)
  • Pro přesnou shodu použijte have.text
  • Alias: include.text funguje stejně
