exist / not.exist

Ověření existence elementu v DOM. Element může být skrytý, ale musí existovat v DOM stromu.

Kdy použít

  • Když potřebujete ověřit, že element existuje (i když je skrytý)
  • Pro kontrolu, že element byl přidán do DOM
  • Pro ověření, že element byl odstraněn z DOM
  • Když nezáleží na viditelnosti, jen na existenci

Syntaxe

cy.should('exist')
cy.should('not.exist')
cy.and('exist')

Příklady

Základní použití

cy.get('form').should('exist')
cy.get('.hidden-element').should('exist')

Ověření odstranění

cy.get('.item').click()
cy.get('.item').should('not.exist')

Rozdíl oproti be.visible

// exist - element je v DOM (může být skrytý)
cy.get('.hidden').should('exist')

// be.visible - element je viditelný
cy.get('.visible').should('be.visible')

Důležité poznámky

  • exist - element je v DOM (může být skrytý)
  • not.exist - element není v DOM
  • Rozdíl oproti be.visible - exist ověřuje jen přítomnost v DOM
  • Element může existovat, ale být skrytý (display: none)
