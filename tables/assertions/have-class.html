have.class

Ověření, že element má CSS třídu. Používá se pro kontrolu styling stavů (active, disabled, error, atd.).

Kdy použít

  • Pro ověření stavu elementu (active, selected, error)
  • Pro kontrolu styling tříd
  • Pro testování toggle funkcionality
  • Pro ověření validace (ng-invalid, ng-valid)

Syntaxe

cy.should('have.class', className)
cy.and('have.class', className)

Parametry

  • className (String) - Název CSS třídy

Příklady

Základní použití

cy.get('button').should('have.class', 'active')
cy.get('.item').should('have.class', 'selected')

Angular validace

cy.get('input').should('have.class', 'ng-valid')
cy.get('input').should('not.have.class', 'ng-invalid')

Po akci

cy.get('button').click()
cy.get('button').should('have.class', 'clicked')

Negace

cy.get('button').should('not.have.class', 'disabled')
cy.get('.item').should('not.have.class', 'hidden')

Důležité poznámky

  • Ověřuje jednu konkrétní třídu
  • Element může mít více tříd současně
  • Pro negaci použijte not.have.class
