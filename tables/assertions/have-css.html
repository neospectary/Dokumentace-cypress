have.css

Ověření CSS vlastnosti elementu. Umožňuje kontrolovat styling elementu.

Kdy použít

  • Pro ověření CSS vlastností (color, background, display, atd.)
  • Pro kontrolu styling po změně
  • Pro testování responzivního designu

Syntaxe

cy.should('have.css', propertyName)
cy.should('have.css', propertyName, value)
cy.and('have.css', propertyName, value)

Parametry

  • propertyName (String) - Název CSS vlastnosti
  • value (String, volitelné) - Očekávaná hodnota

Příklady

Základní použití

cy.get('button').should('have.css', 'background-color')
cy.get('div').should('have.css', 'display', 'flex')

Barvy

cy.get('.error').should('have.css', 'color', 'rgb(255, 0, 0)')

Důležité poznámky

  • Hodnoty jsou vráceny v computed formátu (např. rgb() místo hex)
  • Pro barvy použijte rgb() nebo rgba() formát
