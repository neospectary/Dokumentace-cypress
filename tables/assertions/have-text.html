have.text

Ověření přesného textového obsahu elementu. Porovnává celý text včetně whitespace a textu z potomků.

Kdy použít

  • Když potřebujete ověřit přesný text elementu
  • Pro kontrolu textu po změně
  • Když potřebujete ověřit celý text včetně whitespace

Syntaxe

cy.should('have.text', text)
cy.and('have.text', text)

Parametry

  • text (String) - Očekávaný přesný text

Příklady

Základní použití

cy.get('h1').should('have.text', 'Vítejte')
cy.get('button').should('have.text', 'Odeslat')

S whitespace

cy.get('p').should('have.text', 'Text s   mezerami')

Po změně

cy.get('button').click()
cy.get('.message').should('have.text', 'Úspěšně odesláno')

Důležité poznámky

  • Porovnává přesný text včetně whitespace
  • Zahrnuje text z potomků elementu
  • Pro částečnou shodu použijte contain nebo include.text
  • Case-sensitive (rozlišuje velká/malá písmena)

Rozdíl oproti contain

// have.text - přesná shoda
cy.get('p').should('have.text', 'Přesný text')

// contain - částečná shoda
cy.get('p').should('contain', 'Přesný')
