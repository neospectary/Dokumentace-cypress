have.value

Ověření hodnoty inputu, textarea nebo select elementu. Používá se pro kontrolu vyplněných hodnot.

Kdy použít

  • Po vyplnění inputu nebo textarea
  • Pro ověření, že hodnota byla správně uložena
  • Pro kontrolu předchozí hodnoty
  • Po změně hodnoty

Syntaxe

cy.should('have.value', value)
cy.and('have.value', value)

Parametry

  • value (String) - Očekávaná hodnota

Příklady

Základní použití

cy.get('input[name="email"]').type('test@example.com')
cy.get('input[name="email"]').should('have.value', 'test@example.com')

S textarea

cy.get('textarea').type('Dlouhý text')
cy.get('textarea').should('have.value', 'Dlouhý text')

Po změně

cy.get('input').clear().type('nová hodnota')
cy.get('input').should('have.value', 'nová hodnota')

Prázdná hodnota

cy.get('input').clear()
cy.get('input').should('have.value', '')

Důležité poznámky

  • Funguje s input, textarea, select
  • Porovnává přesnou hodnotu
  • Pro částečnou shodu použijte include
