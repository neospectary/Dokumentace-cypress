Přehled Assertions (Chainers)

Kompletní přehled všech dostupných assertions (chainers) v Cypressu. Tyto se používají s příkazy .should() a .and() pro ověření stavu elementů, hodnot a podmínek.

Jak používat assertions

Assertions se používají s příkazy .should() a .and(): 

cy.get('button').should('be.visible')
cy.get('input').should('be.enabled')
cy.get('h1').should('have.text', 'Nadpis')
cy.get('a').should('have.attr', 'href')

Kategorie assertions

  • Stav elementu - be.visible, be.hidden, be.disabled, be.enabled, exist, not.exist
  • Text a obsah - have.text, contain, include.text
  • Atributy - have.attr, have.class, have.id, have.value
  • CSS vlastnosti - have.css, have.length
  • Hodnoty - equal, deep.equal, include, match

Rychlý přehled - kdy použít který assertion

Viditelnost a existence

  • be.visible - element je viditelný (použijte před interakcí)
  • be.hidden - element je skrytý (po zavření modálu, menu)
  • exist - element existuje v DOM (i když je skrytý)
  • not.exist - element neexistuje v DOM (po odstranění)

Stav elementu

  • be.enabled - element je aktivní (před kliknutím na tlačítko)
  • be.disabled - element je deaktivovaný (před vyplněním formuláře)
  • be.checked - checkbox/radio je zaškrtnutý (po .check())
  • be.focused - element má focus (po .focus())

Text a obsah

  • have.text - přesný text (včetně whitespace) - pro přesnou kontrolu
  • contain - obsahuje text (částečná shoda) - flexibilnější
  • include.text - alias pro contain

Atributy

  • have.attr - má atribut (href, src, data-cy, atd.)
  • have.class - má CSS třídu (active, error, ng-valid, atd.)
  • have.id - má ID
  • have.value - má hodnotu (input, textarea po .type())

CSS a styling

  • have.css - má CSS vlastnost (color, background, display, atd.)
  • have.length - má určitý počet elementů (tabulka, seznam)

Hodnoty (pro cy.wrap() a cy.then())

  • equal - přesná shoda hodnoty
  • deep.equal - hluboká shoda objektů/arrays
  • include - obsahuje hodnotu
  • match - odpovídá regex patternu

Nejčastější kombinace

Před interakcí

cy.get('button')
  .should('be.visible')
  .and('be.enabled')
  .click()

Po vyplnění formuláře

cy.get('input').type('text')
cy.get('input').should('have.value', 'text')
cy.get('button').should('be.enabled')

Ověření textu

cy.get('h1')
  .should('be.visible')
  .and('contain', 'Nadpis')
  .and('have.class', 'title')

Kontrola kolekce

cy.get('li')
  .should('have.length', 5)
  .first()
  .should('be.visible')

Negace assertions

Všechny assertions lze negovat pomocí not.: 

cy.should('not.be.visible')
cy.should('not.have.class', 'error')
cy.should('not.contain', 'text')
cy.should('not.exist')
