.blur()

Odstranění focusu z elementu. Deaktivuje focus na elementu (ztráta focusu). Užitečné pro testování blur událostí nebo simulaci kliknutí mimo element.

Syntaxe

.blur()
.blur(options)

Použití

✅ Správné použití

cy.get('input').blur()                          // Odstranění focusu
cy.get('textarea').blur()                       // Blur textarea
cy.get('input').type('text').blur()             // Psaní a blur

❌ Nesprávné použití

cy.blur()                                        // Chyba, nelze řetězit z 'cy'
cy.window().blur()                               // Chyba, window není focusable element

Argumenty

options (Object)

  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s elementem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('input').blur()
cy.get('textarea').blur()

Testování validace po blur

cy.get('input[name="email"]')
  .type('invalid-email')
  .blur()
  
cy.get('.error-message').should('be.visible')

S focus

cy.get('input')
  .focus()
  .type('text')
  .blur()

Poznámky

Blur událost

.blur() spouští blur událost na elementu. Užitečné pro testování validace, která se spouští při ztrátě focusu.

Focusable elementy

.blur() funguje jen na focusable elementy (input, textarea, button, select, a, atd.). Element musí mít focus, aby bylo možné ho blur.

Validace

.blur() je často používán pro testování validace formulářů, která se spouští při ztrátě focusu (onBlur validace).

Command Log

Příkaz je zobrazen v Command Log s informacemi o blur elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
