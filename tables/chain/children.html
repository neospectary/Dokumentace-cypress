.children()

Výběr přímých potomků elementu. Vrací všechny přímé děti (children) aktuálního elementu. Užitečné pro práci s přímými potomky, ne vnořenými elementy.

Syntaxe

.children()
.children(selector)

Použití

✅ Správné použití

cy.get('ul').children().should('have.length', 5)     // Všechny děti
cy.get('ul').children('li').click()                  // Děti s třídou
cy.get('form').children('input').type('text')        // Děti input

❌ Nesprávné použití

cy.children()                                         // Chyba, nelze řetězit z 'cy'
cy.window().children()                                // Chyba, window nemá děti

Argumenty

selector (String, volitelné)

CSS selektor pro filtrování přímých potomků. Pokud je zadán, vrací pouze přímé potomky, které odpovídají selektoru.

Co vrací (Yields)

Vrací Chainable s přímými potomky. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('ul').children().should('have.length', 5)
cy.get('.container').children().first().click()

S selektorem

cy.get('ul').children('li').should('have.length', 5)
cy.get('form').children('input').type('text')

Práce s tabulkou

cy.get('table tbody tr')
  .first()
  .children('td')
  .should('have.length', 4)

Rozdíl mezi children() a find()

// children() - jen přímé potomky
cy.get('.parent').children('.child')

// find() - všechny potomky (včetně vnořených)
cy.get('.parent').find('.child')

Poznámky

Přímí potomci

.children() vrací jen přímé potomky (children), ne vnořené elementy. Pokud má element vnořené potomky, .children() je nevrátí.

Rozdíl od .find()

.children() vrací jen přímé potomky, zatímco .find() hledá všechny potomky (včetně vnořených). Pro přímé potomky použijte .children(), pro všechny potomky použijte .find().

Command Log

Příkaz je zobrazen v Command Log s informacemi o přímých potomcích. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
