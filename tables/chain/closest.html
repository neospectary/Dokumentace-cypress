.closest()

Výběr nejbližšího předka (ancestor), který odpovídá selektoru. Hledá směrem nahoru v DOM stromu od aktuálního elementu. Užitečné pro nalezení wrapper elementu nebo kontejneru.

Syntaxe

.closest(selector)

Použití

✅ Správné použití

cy.get('span').closest('.container').click()    // Nejbližší .container
cy.get('input').closest('form').submit()        // Nejbližší form
cy.get('button').closest('.card').find('.title') // Nejbližší .card

❌ Nesprávné použití

cy.closest('.container')                         // Chyba, nelze řetězit z 'cy'
cy.window().closest('.container')                // Chyba, window nemá předky
cy.get('span').closest()                         // Chyba, chybí selector

Argumenty

selector (String)

CSS selektor pro hledání předka. Hledá směrem nahoru v DOM stromu od aktuálního elementu a vrací nejbližší předka, který odpovídá selektoru.

Co vrací (Yields)

Vrací Chainable s nejbližším předkem, který odpovídá selektoru. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('span').closest('.container').click()
cy.get('input').closest('form').submit()

Práce s modálem

cy.get('.modal-content')
  .closest('.modal')
  .find('.close-button')
  .click()

Práce s kartou

cy.get('button')
  .closest('.card')
  .find('.card-title')
  .should('contain', 'Název')

Poznámky

Hledání směrem nahoru

.closest() hledá směrem nahoru v DOM stromu (od elementu k předkům). Vrací nejbližší předka, který odpovídá selektoru. Pokud předek neexistuje, test selže.

Rozdíl od .parent()

.parent() vrací přímého rodiče, zatímco .closest() hledá předka podle selektoru (může být i vyšší v DOM stromu). .closest() je užitečnější, když potřebujete najít konkrétní wrapper element.
