.eq()

Výběr elementu na konkrétním indexu z kolekce. Vrací element na zadané pozici (0-based index). Užitečné pro výběr konkrétního elementu podle pozice.

Syntaxe

.eq(index)

Použití

✅ Správné použití

cy.get('li').eq(0).click()                   // První element (index 0)
cy.get('li').eq(2).click()                   // Třetí element (index 2)
cy.get('button').eq(1).should('be.visible')  // Druhý element

❌ Nesprávné použití

cy.eq(0)                                     // Chyba, nelze řetězit z 'cy'
cy.window().eq(0)                            // Chyba, window není kolekce
cy.get('li').eq()                            // Chyba, chybí index

Argumenty

index (Number)

Index elementu v kolekci (0-based). První element má index 0, druhý má index 1, atd. Negativní indexy se počítají od konce (-1 = poslední, -2 = předposlední, atd.).

Co vrací (Yields)

Vrací Chainable s elementem na zadaném indexu. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('li').eq(0).click()  // první element
cy.get('li').eq(2).click()  // třetí element
cy.get('button').eq(1).should('be.visible')

Práce s tabulkou

cy.get('table tbody tr')
  .eq(3)  // čtvrtý řádek
  .find('td')
  .eq(1)  // druhá buňka
  .should('contain', 'Hodnota')

Negativní index

cy.get('li').eq(-1)  // poslední element
cy.get('li').eq(-2)  // předposlední element

Poznámky

0-based index

Index je 0-based - první element má index 0, druhý má index 1, atd. Pokud index neexistuje (je mimo rozsah), test selže.

Negativní indexy

Negativní indexy se počítají od konce: -1 = poslední, -2 = předposlední, atd. .eq(-1) je ekvivalentní k .last().

Alternativa

Pro první element použijte .first(), pro poslední .last(). .eq() je užitečné pro výběr elementu uprostřed kolekce.

Command Log

Příkaz je zobrazen v Command Log s informacemi o vybraném elementu a indexu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
