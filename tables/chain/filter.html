.filter()

Filtrování elementů z kolekce podle selektoru nebo callback funkce. Vrací pouze elementy, které splňují podmínku. Užitečné pro zúžení kolekce podle kritérií.

Syntaxe

.filter(selector)
.filter(callbackFn)

Použití

✅ Správné použití

cy.get('button').filter('.active').click()         // Podle třídy
cy.get('input').filter('[type="text"]').type('text') // Podle atributu
cy.get('tr').filter(($row) => {                     // Callback funkce
  return $row.find('td').length > 3
})

❌ Nesprávné použití

cy.filter('.active')                                 // Chyba, nelze řetězit z 'cy'
cy.window().filter('.active')                        // Chyba, window není kolekce

Argumenty

selector (String)

CSS selektor pro filtrování elementů. Vrátí pouze elementy, které odpovídají selektoru.

callbackFn (Function)

Callback funkce pro vlastní filtrování. Dostává jQuery element a index jako argumenty. Vrátí true pro elementy, které mají být zahrnuty.

Co vrací (Yields)

Vrací Chainable s filtrovanými elementy. Lze řetězit další příkazy.

Příklady

Filtrování podle selektoru

cy.get('button').filter('.active').click()
cy.get('li').filter('.selected').should('have.length', 3)

Filtrování podle atributu

cy.get('input').filter('[type="text"]').type('text')
cy.get('a').filter('[href*="example"]').should('have.length', 5)

Filtrování pomocí callback

cy.get('tr').filter(($row) => {
  return $row.find('td').length > 3
}).should('have.length', 10)

Filtrování podle textu

cy.get('li').filter(($el) => {
  return $el.text().includes('Important')
}).click()

Poznámky

Filtrování z kolekce

.filter() filtruje z aktuální kolekce elementů. Vrací novou kolekci s elementy, které splňují podmínku.

Callback funkce

Callback dostává jQuery element jako první argument a index jako druhý argument. Vrátí true pro elementy, které mají být zahrnuty do výsledku.

Rozdíl od .not()

.filter() vybírá elementy, které splňují podmínku, zatímco .not() vybírá elementy, které podmínku nesplňují (negace).
