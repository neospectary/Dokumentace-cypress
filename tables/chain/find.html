.find()

Hledání potomků uvnitř aktuálně vybraného elementu. Chain příkaz, který hledá jen uvnitř scope vybraného elementu (na rozdíl od cy.get(), který hledá všude v dokumentu). Užitečné pro zúžení scope hledání na konkrétní kontejner.

Syntaxe

.find(selector)
.find(selector, options)

Použití

✅ Správné použití

cy.get('.container').find('.item')              // Hledá jen uvnitř .container
cy.get('table').find('tr')                      // Hledá jen uvnitř table
cy.get('form').find('input[name="email"]')      // Hledá jen uvnitř form

❌ Nesprávné použití

cy.find('.item')                                 // Chyba, nelze řetězit z 'cy'
cy.window().find('.item')                        // Chyba, window není DOM element

Argumenty

selector (String)

CSS selektor pro hledání uvnitř vybraného elementu. Hledá všechny potomky (včetně vnořených), které odpovídají selektoru.

options (Object, volitelné)

  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s nalezenými potomky. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('.container').find('.item')
cy.get('table').find('tr')
cy.get('form').find('input[name="email"]')

Práce s tabulkou

cy.get('table')
  .find('tbody')
  .find('tr')
  .first()
  .find('td')
  .eq(0)
  .should('contain.text', 'Hodnota')

Práce s modálem

cy.dataCy('modal-window')
  .find('input')
  .type('Hodnota')

cy.dataCy('modal-window')
  .find('button')
  .contains('Uložit')
  .click()

Rozdíl mezi cy.get() a .find()

// ❌ cy.get() hledá všude v dokumentu
cy.get('.parent').get('.child')  // Hledá .child všude

// ✅ .find() hledá jen uvnitř parent
cy.get('.parent').find('.child')  // Hledá .child jen uvnitř .parent

// ✅ cy.within() také zúží scope
cy.get('.parent').within(() => {
  cy.get('.child')  // Hledá jen uvnitř .parent
})

Poznámky

Scope hledání

.find() hledá jen uvnitř aktuálně vybraného elementu, ne v celém dokumentu. Na rozdíl od cy.get(), který hledá všude, .find() zúží scope hledání.

Všechny potomky

.find() hledá všechny potomky (včetně vnořených), zatímco .children() vrací jen přímé potomky. Pro přímé potomky použijte .children().

Alternativa

Alternativou k .find() je cy.within(), které také zúží scope hledání. Volba závisí na preferenci a čitelnosti kódu.

Command Log

Příkaz je zobrazen v Command Log s informacemi o nalezených potomcích. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
