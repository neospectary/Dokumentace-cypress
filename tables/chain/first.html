.first()

Výběr prvního elementu z kolekce. Vrací první element (index 0) z nalezených elementů. Užitečné pro práci s prvním prvkem v seznamu nebo tabulce.

Syntaxe

.first()

Použití

✅ Správné použití

cy.get('li').first().click()                  // První element
cy.get('button').first().should('be.visible') // Ověření prvního
cy.get('table tbody tr').first().find('td')   // První řádek

❌ Nesprávné použití

cy.first()                                     // Chyba, nelze řetězit z 'cy'
cy.window().first()                            // Chyba, window není kolekce

Argumenty

.first() nemá žádné argumenty. Vybírá vždy první element (index 0) z kolekce.

Co vrací (Yields)

Vrací Chainable s prvním elementem z kolekce. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('li').first().click()
cy.get('button').first().should('be.visible')

S dalšími příkazy

cy.get('table tbody tr')
  .first()
  .find('td')
  .first()
  .should('contain', 'Text')

Práce s formulářem

cy.get('input[type="checkbox"]')
  .first()
  .check()

Poznámky

Kolekce elementů

.first() funguje jen na kolekcích elementů. Pokud je jen jeden element, vrátí ho. Pokud nejsou žádné elementy, test selže.

Index

.first() vrací element na indexu 0 (první element). Ekvivalentní k .eq(0), ale čitelnější.

Řetězení

Lze kombinovat s dalšími chain příkazy. Často se používá s .find(), .click(), .should(), atd.

Command Log

Příkaz je zobrazen v Command Log s informacemi o prvním elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
