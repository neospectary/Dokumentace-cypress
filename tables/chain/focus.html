.focus()

Nastavení focusu na element. Aktivuje element pro vstup (input, textarea, button, atd.). Užitečné pro testování focus událostí nebo aktivaci elementu před interakcí.

Syntaxe

.focus()
.focus(options)

Použití

✅ Správné použití

cy.get('input').focus()                        // Focus na input
cy.get('textarea').focus()                     // Focus na textarea
cy.get('input[name="email"]').focus().type('text') // Focus a psaní

❌ Nesprávné použití

cy.focus()                                      // Chyba, nelze řetězit z 'cy'
cy.window().focus()                             // Chyba, window není focusable element

Argumenty

options (Object)

  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s elementem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('input').focus()
cy.get('textarea').focus()

S následným psaním

cy.get('input[name="email"]')
  .focus()
  .type('test@example.com')

Testování focus událostí

cy.get('input').focus()
cy.get('.focus-indicator').should('be.visible')

S blur

cy.get('input')
  .focus()
  .type('text')
  .blur()

Poznámky

Automatické focus

Cypress automaticky volá .focus() před .type(), takže obvykle není nutné volat .focus() explicitně před psaním.

Focusable elementy

.focus() funguje jen na focusable elementy (input, textarea, button, select, a, atd.). Pro ostatní typy elementů může selhat.

Kdy použít

.focus() je užitečné pro testování focus událostí nebo když potřebujete explicitně nastavit focus před interakcí.

Command Log

Příkaz je zobrazen v Command Log s informacemi o focus elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
