.last()

Výběr posledního elementu z kolekce. Vrací poslední element z nalezených elementů. Užitečné pro práci s posledním prvkem v seznamu nebo tabulce.

Syntaxe

.last()

Použití

✅ Správné použití

cy.get('li').last().click()                  // Poslední element
cy.get('button').last().should('be.visible') // Ověření posledního
cy.get('table tbody tr').last().find('td')   // Poslední řádek

❌ Nesprávné použití

cy.last()                                     // Chyba, nelze řetězit z 'cy'
cy.window().last()                            // Chyba, window není kolekce

Argumenty

.last() nemá žádné argumenty. Vybírá vždy poslední element z kolekce.

Co vrací (Yields)

Vrací Chainable s posledním elementem z kolekce. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('li').last().click()
cy.get('button').last().should('be.visible')

S dalšími příkazy

cy.get('table tbody tr')
  .last()
  .find('td')
  .last()
  .should('contain', 'Text')

Práce s formulářem

cy.get('input[type="checkbox"]')
  .last()
  .check()

Poznámky

Kolekce elementů

.last() funguje jen na kolekcích elementů. Pokud je jen jeden element, vrátí ho. Pokud nejsou žádné elementy, test selže.

Index

.last() vrací poslední element z kolekce (index length - 1). Ekvivalentní k .eq(-1), ale čitelnější.

Řetězení

Lze kombinovat s dalšími chain příkazy. Často se používá s .find(), .click(), .should(), atd.

Command Log

Příkaz je zobrazen v Command Log s informacemi o posledním elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
