.next()

Výběr následujícího sourozence. Vrací bezprostředně následující element (next sibling). Užitečné pro práci s pořadím elementů.

Syntaxe

.next()
.next(selector)

Použití

✅ Správné použití

cy.get('li').first().next().click()              // Následující element
cy.get('input').next('label').should('contain', 'Label') // Následující label
cy.get('button').next('.tooltip').should('be.visible')   // Následující tooltip

❌ Nesprávné použití

cy.next()                                         // Chyba, nelze řetězit z 'cy'
cy.window().next()                                // Chyba, window nemá sourozence

Argumenty

selector (String, volitelné)

CSS selektor pro ověření následujícího elementu. Pokud je zadán, test selže, pokud následující element neodpovídá selektoru.

Co vrací (Yields)

Vrací Chainable s následujícím sourozencem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('li').first().next().click()
cy.get('input').next('label').should('contain', 'Label')

S selektorem

cy.get('button').next('.tooltip').should('be.visible')
cy.get('h2').next('p').should('contain', 'Text')

Vícenásobné next()

cy.get('li').first()
  .next()
  .next()
  .should('have.class', 'third-item')

Poznámky

Bezprostředně následující

.next() vrací bezprostředně následujícího sourozence (next sibling). Pokud následující element neexistuje, test selže.

Řetězení

Lze řetězit více .next() za sebou pro přístup k dalším sourozencům. Každé .next() jde o jeden krok dopředu.

Rozdíl od .siblings()

.next() vrací jen následujícího sourozence, zatímco .siblings() vrací všechny sourozence.

Command Log

Příkaz je zobrazen v Command Log s informacemi o následujícím elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
