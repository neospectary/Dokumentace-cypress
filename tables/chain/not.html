.not()

Vyloučení elementů z kolekce. Vrací elementy, které nesplňují podmínku (negace filtrování). Opačná logika k .filter().

Syntaxe

.not(selector)
.not(callbackFn)

Použití

✅ Správné použití

cy.get('button').not('.disabled').click()       // Vyloučit disabled
cy.get('input').not('[disabled]').type('text')  // Vyloučit disabled
cy.get('tr').not(($row) => {                    // Callback funkce
  return $row.hasClass('header-row')
})

❌ Nesprávné použití

cy.not('.active')                                // Chyba, nelze řetězit z 'cy'
cy.window().not('.active')                       // Chyba, window není kolekce

Argumenty

selector (String)

CSS selektor pro vyloučení elementů. Vrátí pouze elementy, které neodpovídají selektoru.

callbackFn (Function)

Callback funkce pro vlastní logiku vyloučení. Dostává jQuery element a index jako argumenty. Vrátí true pro elementy, které mají být vyloučeny.

Co vrací (Yields)

Vrací Chainable s elementy, které nesplňují podmínku. Lze řetězit další příkazy.

Příklady

Vyloučení podle třídy

cy.get('button').not('.disabled').click()
cy.get('li').not('.hidden').should('be.visible')

Vyloučení podle atributu

cy.get('input').not('[disabled]').type('text')
cy.get('a').not('[href="#"]').should('have.attr', 'href')

Vyloučení pomocí callback

cy.get('tr').not(($row) => {
  return $row.hasClass('header-row')
}).should('have.length', 10)

Kombinace s dalšími příkazy

cy.get('button')
  .not('.disabled')
  .not('.hidden')
  .should('have.length', 5)

Poznámky

Vyloučení z kolekce

.not() vylučuje elementy z aktuální kolekce. Vrací novou kolekci s elementy, které nesplňují podmínku.

Řetězení

Lze řetězit více .not() za sebou pro vyloučení více podmínek. Každé .not() vyloučí elementy podle své podmínky.

Rozdíl od .filter()

.not() je opačná logika k .filter(). .filter() vybírá elementy, které splňují podmínku, .not() vybírá elementy, které podmínku nesplňují.

Command Log

Příkaz je zobrazen v Command Log s informacemi o vyloučených elementech. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
