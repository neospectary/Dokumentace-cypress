.parent()

Výběr rodičovského elementu. Vrací přímého rodiče (parent) aktuálního elementu. Užitečné pro práci s kontejnery nebo wrapper elementy.

Syntaxe

.parent()
.parent(selector)

Použití

✅ Správné použití

cy.get('span').parent().click()                      // Přímý rodič
cy.get('input').parent('.form-group').should('exist') // Rodič s třídou
cy.get('button').parent('form').submit()             // Rodič form

❌ Nesprávné použití

cy.parent()                                          // Chyba, nelze řetězit z 'cy'
cy.window().parent()                                 // Chyba, window nemá parent

Argumenty

selector (String, volitelné)

CSS selektor pro ověření rodiče. Pokud je zadán, test selže, pokud rodič neodpovídá selektoru. Pokud není zadán, vrací přímého rodiče bez ověření.

Co vrací (Yields)

Vrací Chainable s rodičovským elementem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('span').parent().click()
cy.get('input').parent().should('have.class', 'form-group')

S selektorem

cy.get('span').parent('.container').should('exist')
cy.get('button').parent('form').submit()

Práce s checkboxy

cy.get('input[type="checkbox"]')
  .parent('label')
  .click()

Vícenásobné parent()

cy.get('span')
  .parent()
  .parent()
  .should('have.class', 'grandparent')

Poznámky

Přímý rodič

.parent() vrací přímého rodiče (parent element), ne všechny předky. Pro hledání předka podle selektoru použijte .closest().

Řetězení

Lze řetězit více .parent() za sebou pro přístup k vyšším úrovním v DOM stromu. Každé .parent() jde o jednu úroveň výše.

Rozdíl od .closest()

.parent() vrací přímého rodiče, zatímco .closest() hledá předka podle selektoru (může být i vyšší v DOM stromu).
