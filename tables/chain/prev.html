.prev()

Výběr předchozího sourozence. Vrací bezprostředně předcházející element (previous sibling). Užitečné pro práci s pořadím elementů.

Syntaxe

.prev()
.prev(selector)

Použití

✅ Správné použití

cy.get('li').last().prev().click()              // Předchozí element
cy.get('input').prev('label').should('contain', 'Label') // Předchozí label
cy.get('button').prev('.icon').should('be.visible')       // Předchozí ikona

❌ Nesprávné použití

cy.prev()                                         // Chyba, nelze řetězit z 'cy'
cy.window().prev()                                // Chyba, window nemá sourozence

Argumenty

selector (String, volitelné)

CSS selektor pro ověření předchozího elementu. Pokud je zadán, test selže, pokud předchozí element neodpovídá selektoru.

Co vrací (Yields)

Vrací Chainable s předchozím sourozencem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('li').last().prev().click()
cy.get('input').prev('label').should('contain', 'Label')

S selektorem

cy.get('button').prev('.icon').should('be.visible')
cy.get('p').prev('h2').should('contain', 'Nadpis')

Vícenásobné prev()

cy.get('li').last()
  .prev()
  .prev()
  .should('have.class', 'third-from-end')

Poznámky

Bezprostředně předcházející

.prev() vrací bezprostředně předcházejícího sourozence (previous sibling). Pokud předchozí element neexistuje, test selže.

Řetězení

Lze řetězit více .prev() za sebou pro přístup k dalším sourozencům. Každé .prev() jde o jeden krok zpět.

Rozdíl od .siblings()

.prev() vrací jen předchozího sourozence, zatímco .siblings() vrací všechny sourozence.

Command Log

Příkaz je zobrazen v Command Log s informacemi o předchozím elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
