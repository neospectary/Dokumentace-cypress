.siblings()

Výběr sourozenců elementu. Vrací všechny sourozence (siblings) aktuálního elementu - elementy se stejným rodičem. Užitečné pro práci s elementy na stejné úrovni DOM stromu.

Syntaxe

.siblings()
.siblings(selector)

Použití

✅ Správné použití

cy.get('li.active').siblings().should('have.length', 4)  // Všichni sourozenci
cy.get('input').siblings('label').should('contain', 'Label') // Sourozenci label
cy.get('button').siblings('span').should('be.visible')   // Sourozenci span

❌ Nesprávné použití

cy.siblings()                                           // Chyba, nelze řetězit z 'cy'
cy.window().siblings()                                  // Chyba, window nemá sourozence

Argumenty

selector (String, volitelné)

CSS selektor pro filtrování sourozenců. Pokud je zadán, vrací pouze sourozence, kteří odpovídají selektoru.

Co vrací (Yields)

Vrací Chainable se sourozenci. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('li.active').siblings().should('have.length', 4)
cy.get('input').siblings('label').should('contain', 'Label')

S selektorem

cy.get('li.active').siblings('.item').click()
cy.get('button').siblings('span').should('be.visible')

Práce s formulářem

cy.get('input[name="email"]')
  .siblings('.error-message')
  .should('not.exist')

Poznámky

Sourozenci

.siblings() vrací všechny sourozence - elementy se stejným rodičem. Samotný element není zahrnut do výsledku.

Rozdíl od .next() a .prev()

.siblings() vrací všechny sourozence, zatímco .next() vrací jen následujícího sourozence a .prev() vrací jen předchozího sourozence.

Command Log

Příkaz je zobrazen v Command Log s informacemi o sourozencích. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
