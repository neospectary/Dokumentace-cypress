.submit()

Odeslání formuláře. Simuluje submit událost na form elementu. Užitečné jako alternativa k kliknutí na submit tlačítko.

Syntaxe

.submit()
.submit(options)

Použití

✅ Správné použití

cy.get('form').submit()                        // Odeslání formuláře
cy.get('form#login').submit()                  // Konkrétní form
cy.get('form').within(() => {
  cy.get('input[name="email"]').type('test@example.com')
}).submit()

❌ Nesprávné použití

cy.submit()                                     // Chyba, nelze řetězit z 'cy'
cy.get('button').submit()                       // Chyba, button není form
cy.window().submit()                            // Chyba, window není form

Argumenty

options (Object)

  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s form elementem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('form').submit()
cy.get('form#login').submit()

Po vyplnění formuláře

cy.get('form').within(() => {
  cy.get('input[name="email"]').type('test@example.com')
  cy.get('input[name="password"]').type('password')
}).submit()

Alternativa k kliknutí

// Místo:
cy.get('button[type="submit"]').click()

// Můžete použít:
cy.get('form').submit()

Poznámky

Form elementy

.submit() funguje jen na form elementy (<form>). Nelze použít na submit tlačítko nebo jiné elementy.

Submit událost

.submit() simuluje submit událost na form elementu. Spustí submit handler formuláře (stejně jako kliknutí na submit tlačítko).

Alternativa

.submit() je alternativa k kliknutí na submit tlačítko. Obě metody mají stejný efekt, ale .submit() je někdy čitelnější.

Command Log

Příkaz je zobrazen v Command Log s informacemi o odeslaném formuláři. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
