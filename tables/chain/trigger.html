.trigger()

Spuštění DOM události na elementu. Umožňuje simulovat různé DOM události jako mouseover, focus, blur, change, atd. Užitečné pro testování event handlerů nebo simulaci událostí, které nejsou přímo podporované Cypress příkazy.

Syntaxe

.trigger(eventName)
.trigger(eventName, options)

Použití

✅ Správné použití

cy.get('button').trigger('mouseover')           // Mouseover událost
cy.get('input').trigger('focus')                // Focus událost
cy.get('input').trigger('change')               // Change událost
cy.get('.tooltip-trigger').trigger('mouseenter') // Mouseenter

❌ Nesprávné použití

cy.trigger('mouseover')                         // Chyba, nelze řetězit z 'cy'
cy.window().trigger('focus')                    // Chyba, window není DOM element

Argumenty

eventName (String)

Název DOM události k spuštění: 'mouseover', 'focus', 'blur', 'change', 'mouseenter', 'mouseleave', 'keydown', 'keyup', atd.

options (Object)

  • bubbles (Boolean) - Zda událost probublává
  • cancelable (Boolean) - Zda je událost zrušitelná
  • detail (Any) - Custom data pro událost
  • key (String) - Klávesa pro keyboard události
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s elementem. Lze řetězit další příkazy.

Příklady

Základní události

cy.get('button').trigger('mouseover')
cy.get('input').trigger('focus')
cy.get('input').trigger('blur')

Mouse události

cy.get('.tooltip-trigger').trigger('mouseenter')
cy.get('.menu-item').trigger('mouseleave')
cy.get('button').trigger('mousedown')
cy.get('button').trigger('mouseup')

Keyboard události

cy.get('input').trigger('keydown', { key: 'Enter' })
cy.get('input').trigger('keyup', { key: 'Escape' })

Custom události

cy.get('.custom-element').trigger('customEvent', {
  detail: { value: 'test' }
})

Poznámky

Simulace událostí

.trigger() simuluje DOM události, ne skutečné uživatelské akce. Pro reálné uživatelské akce použijte nativní Cypress příkazy (např. .click(), .type()) nebo plugin cypress-real-events.

Podporované události

Cypress podporuje všechny standardní DOM události (mouse, keyboard, focus, change, atd.). Můžete také vytvářet custom události.

Kdy použít

.trigger() je užitečné pro testování event handlerů nebo simulaci událostí, které nejsou přímo podporované Cypress příkazy. Pro většinu případů použijte nativní Cypress příkazy.

Command Log

Příkaz je zobrazen v Command Log s informacemi o spuštěné události. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
