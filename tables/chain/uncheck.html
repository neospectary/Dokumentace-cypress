.uncheck()

Odškrtnutí checkboxu. Ověří a odškrtne checkbox element. Užitečné pro změnu stavu checkboxu z checked na unchecked nebo testování toggle funkcionality.

Syntaxe

.uncheck()
.uncheck(options)

Použití

✅ Správné použití

cy.get('input[type="checkbox"]').uncheck()      // Odškrtnutí checkboxu
cy.get('[data-cy="terms"]').uncheck()           // S data-cy atributem
cy.get('input[type="checkbox"]').uncheck({ force: true }) // S force

❌ Nesprávné použití

cy.uncheck()                                     // Chyba, nelze řetězit z 'cy'
cy.get('button').uncheck()                       // Chyba, button není checkbox

Argumenty

options (Object)

  • force (Boolean) - Vynutí akci, vypne čekání na akceschopnost
  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s elementem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('input[type="checkbox"]').uncheck()
cy.get('[data-cy="terms"]').uncheck()

S force

cy.get('input[type="checkbox"]').uncheck({ force: true })

Toggle checkbox

cy.get('input[type="checkbox"]').check()
cy.get('input[type="checkbox"]').uncheck()

Poznámky

Checkbox elementy

.uncheck() funguje jen s checkbox elementy (input[type="checkbox"]). Automaticky čeká na to, aby element byl uncheckable (viditelný, enabled, atd.).

Force option

force: true vynutí akci a vypne čekání na akceschopnost. Používejte opatrně, pouze když je to nezbytné.

Proti .check()

Pro zaškrtnutí checkboxu použijte .check(). .uncheck() odškrtává checkbox.

Command Log

Příkaz je zobrazen v Command Log s informacemi o odškrtnutém checkboxu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
