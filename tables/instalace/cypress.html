Instalace Cypressu

Postup instalace Cypressu do projektu. Cypress se instaluje jako dev dependency pomocí npm nebo yarn.

Kdy použít

  • Při vytváření nového projektu s Cypressem
  • Když přidáváte Cypress do existujícího projektu
  • Když potřebujete aktualizovat Cypress

Instalace

1. Vytvoření projektu (pokud neexistuje)

mkdir cypress-project
cd cypress-project
npm init -y

2. Instalace Cypressu

# Pomocí npm
npm install --save-dev cypress

# Nebo pomocí yarn
yarn add -D cypress

3. Otevření Cypressu

# První spuštění (otevře Cypress Test Runner)
npx cypress open

# Nebo pomocí yarn
yarn cypress open

Struktura projektu po instalaci

cypress-project/
├── cypress/
│   ├── e2e/              # Testovací soubory
│   ├── fixtures/         # Testovací data
│   ├── support/          # Custom commands, helpers
│   │   ├── commands.ts
│   │   └── e2e.ts
│   └── downloads/        # Stažené soubory
├── cypress.config.ts     # Konfigurace Cypressu
└── package.json

Důležité poznámky

  • Cypress se instaluje jako dev dependency (--save-dev)
  • První spuštění vytvoří strukturu složek
  • Doporučená verze: nejnovější LTS
