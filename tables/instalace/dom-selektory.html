Co je DOM a CSS selektory

Cypress hledá prvky na stránce pomocí selektorů. Aby dávalo smysl, co píšeš do cy.get(), musíš nejdřív vědět, co je DOM a jak selektory fungují. Bez toho je každý Cypress příkaz jen magická zaklínadla.

Co je DOM

DOM znamená Document Object Model. Je to reprezentace HTML stránky jako stromová struktura — každý HTML tag je uzel (node) ve stromě, který má rodiče, sourozence a děti.

HTML kód stránky

<body>
  <header>
    <h1>Moje aplikace</h1>
  </header>
  <main>
    <form>
      <input type="text" placeholder="Jméno" />
      <button class="btn-primary">Odeslat</button>
    </form>
  </main>
</body>

Jak prohlížeč vidí stejný kód — DOM strom

body
├── header
│   └── h1  →  "Moje aplikace"
└── main
    └── form
        ├── input  (type="text")
        └── button  →  "Odeslat"  (class="btn-primary")

Cypress prochází tento strom a hledá elementy, které odpovídají tvému selektoru. Když napíšeš cy.get('button'), Cypress projde celý DOM a najde všechny prvky <button>.

Jak zobrazit DOM v prohlížeči

V Chrome nebo Firefox klikni pravým tlačítkem na libovolný prvek stránky → Prozkoumat (Inspect). Otevře se DevTools s panelem Elements, kde vidíš celý DOM strom. Tohle je tvůj nejlepší přítel při psaní selektorů.

CSS selektory — jak popsat, co hledáš

Selektor je řetězec, který popisuje, který element chceš najít. Stejné selektory, které znáš z CSS stylů, fungují i v Cypressu.

Selektor podle tagu

cy.get('button')        // najde všechny <button> elementy
cy.get('input')         // najde všechny <input> elementy
cy.get('h1')            // najde všechny <h1> elementy

Selektor podle třídy (class) — tečka

// HTML: <button class="btn-primary">Odeslat</button>
cy.get('.btn-primary')  // tečka = hledej podle class
cy.get('.error-message')
cy.get('.active')

Selektor podle ID — mřížka

// HTML: <input id="email-input" />
cy.get('#email-input')  // # = hledej podle id
cy.get('#submit-btn')
cy.get('#main-content')

Selektor podle atributu — hranaté závorky

// HTML: <input type="email" />
cy.get('[type="email"]')          // hledej input s type="email"
cy.get('[placeholder="Jméno"]')   // hledej element s daným placeholder
cy.get('[disabled]')              // hledej jakýkoli disabled element

Selektor podle data-cy atributu (doporučeno v Cypress)

// HTML: <button data-cy="submit-btn">Odeslat</button>
cy.get('[data-cy="submit-btn"]')
cy.get('[data-cy="login-form"]')
cy.get('[data-cy="error-message"]')

Kombinované selektory

cy.get('button.btn-primary')       // <button> se třídou btn-primary
cy.get('input[type="text"]')       // <input> s type="text"
cy.get('form .error')              // .error uvnitř <form>
cy.get('.card button')             // <button> kdekoliv uvnitř .card

Proč ne vždy class nebo ID?

Třídy a ID se mění — designer přejmenuje třídu, vývojář změní strukturu. Test pak spadne, i když aplikace funguje správně. Proto Cypress doporučuje speciální atribut data-cy, který existuje jen pro testy a nikdo ho nemá důvod měnit. 

// ❌ Fragilní — změní se při redesignu
cy.get('.MuiButton-root.MuiButton-contained')

// ✅ Stabilní — existuje jen pro test
cy.get('[data-cy="submit-button"]')
