Funkce a arrow functions

V Cypressu narazíš na závorky, šipky a složené závorky doslova v každém druhém řádku. Toto je zápis funkcí v JavaScriptu. Bez pochopení funkcí budeš Cypress příkazy kopírovat, aniž bys věděl, co píšeš.

Co je funkce

Funkce je pojmenovaný blok kódu, který můžeš spustit kdykoliv chceš — a opakovaně. Místo abys psal stejný kód na deseti místech, napíšeš ho jednou jako funkci a pak ji jen voláš.

Analogie z reálného světa

Recept na palačinky je funkce. Napíšeš ho jednou. Kdykoli chceš palačinky, „zavoláš" recept — postupuješ podle kroků, dostaneš výsledek. Recept může mít parametry: „udělej palačinky pro 4 osoby" — číslo 4 je argument.

Klasická funkce

// Definice funkce
function pozdrav() {
  console.log('Ahoj!')
}

// Volání funkce
pozdrav()    // vypíše: Ahoj!

Funkce s parametrem

// Parametr = proměnná, která dostane hodnotu při volání
function pozdrav(jmeno) {
  console.log('Ahoj, ' + jmeno + '!')
}

pozdrav('Pavle')    // vypíše: Ahoj, Pavle!
pozdrav('Mario')    // vypíše: Ahoj, Mario!

Funkce s návratovou hodnotou

function secti(a, b) {
  return a + b      // return = pošli výsledek zpátky volajícímu
}

const vysledek = secti(3, 5)
console.log(vysledek)    // 8

Arrow function — zkrácený zápis

Arrow function (šipková funkce) dělá totéž co klasická funkce, ale píše se kratší. Cypress ji používá všude — v .then(), .each(), beforeEach() a dalších.

Základní tvar

// Klasická funkce
function pozdrav() {
  console.log('Ahoj!')
}

// Totéž jako arrow function
const pozdrav = () => {
  console.log('Ahoj!')
}

pozdrav()    // funguje stejně

Arrow function s parametrem

// Klasická
function pozdrav(jmeno) {
  console.log('Ahoj, ' + jmeno + '!')
}

// Arrow
const pozdrav = (jmeno) => {
  console.log('Ahoj, ' + jmeno + '!')
}

// Zkrácený zápis — bez závorek při jednom parametru
const pozdrav = jmeno => {
  console.log('Ahoj, ' + jmeno + '!')
}

Arrow function s return — ultra zkrácený zápis

// Plný zápis
const secti = (a, b) => {
  return a + b
}

// Zkrácený — bez složených závorek a bez return (implicitní return)
const secti = (a, b) => a + b

console.log(secti(3, 5))    // 8

Callback funkce — funkce jako argument

Toto je klíčový koncept pro Cypress. Callback je funkce, kterou předáš jiné funkci jako argument. Říkáš tím: „Až budeš hotový, zavolej tuto funkci."

Analogie

Zavoláš pizzerii a řekneš: „Až bude pizza hotová, zavolej mi." Číslo tvého telefonu je callback — pizzerie ho zavolá (spustí), až splní svůj úkol.

Callback v čistém JavaScriptu

// setTimeout čeká 2 sekundy, pak zavolá callback funkci
setTimeout(() => {
  console.log('Uplynuly 2 sekundy!')
}, 2000)
//          ↑ toto je callback — arrow function předaná jako argument

Callback v Cypressu — .then()

cy.get('[data-cy="username"]')
  .then(($element) => {           // ← toto je callback funkce
    const text = $element.text()  //   $element je argument — dostaneš ho od Cypressu
    cy.log(text)
  })

Callback v Cypressu — beforeEach()

beforeEach(() => {           // ← callback — Cypress ho zavolá před každým testem
  cy.visit('/login')
  cy.get('[data-cy="email"]').type('test@test.cz')
})

Rozložení zápisu krok za krokem

cy.get('.price')           // 1. Najdi element s třídou .price
  .then(                   // 2. Až ho najdeš, zavolej tuto funkci...
    ($el) => {             // 3. ...s argumentem $el (jQuery element)
      const text = $el.text()   // 4. Přečti text elementu
      console.log(text)         // 5. Vypiš ho do konzole
    }
  )

Proč Cypress používá arrow functions

Arrow functions v Cypressu jsou všude z jednoho důvodu: jsou kratší a přehlednější pro zápis callbacků. Navíc správně zacházejí s kontextem (this), což je důležité v Mocha testech. 

// Bez arrow function — delší, méně přehledné
cy.get('li').each(function($li) {
  cy.wrap($li).should('be.visible')
})

// S arrow function — kratší, přehledné
cy.get('li').each(($li) => {
  cy.wrap($li).should('be.visible')
})

Přehled tvarů arrow functions v Cypressu

ZápisKdy použít
() => { ... } Callback bez parametru (beforeEach, describe, it)
($el) => { ... } Callback s jedním parametrem (.then, .each)
(a, b) => { ... } Callback s více parametry
($el) => $el.text() Zkrácený — vrátí výsledek výrazu přímo

Příklady z praxe

describe('Login stránka', () => {          // () => { } — bez parametru
  beforeEach(() => {                        // () => { } — bez parametru
    cy.visit('/login')
  })

  it('přihlásí uživatele', () => {         // () => { } — bez parametru
    cy.get('[data-cy="email"]')
      .then(($input) => {                  // ($input) => { } — s parametrem
        cy.log($input.val())
      })

    cy.get('li').each(($li) => {           // ($li) => { } — s parametrem
      cy.wrap($li).should('be.visible')
    })
  })
})
