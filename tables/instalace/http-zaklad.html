HTTP základ — requesty a response

Cypress příkazy cy.intercept(), cy.request() a cy.wait() pracují s HTTP komunikací mezi prohlížečem a serverem. Aby ti dávaly smysl, musíš vědět, co je HTTP request, response, metody GET/POST a stavové kódy.

Co je HTTP

HTTP (HyperText Transfer Protocol) je způsob, jakým spolu komunikuje prohlížeč a server. Vždy jde o dvojici: request (žádost) a response (odpověď).

Analogie — restaurace

Zákazník (prohlížeč)          Číšník (HTTP)          Kuchyně (server)

1. "Dám si svíčkovou"    →   request (žádost)   →   zpracuje objednávku
2. "Prosím, svíčková"    ←   response (odpověď) ←   připraví jídlo

Prohlížeč vždy první pošle request. Server odpovídá response. Tato komunikace probíhá při každém načtení stránky, kliknutí na tlačítko nebo načítání dat.

HTTP metody — co chci udělat

HTTP metoda říká serveru, jakou akci chce klient provést. Jsou to standardizované „příkazy".

MetodaAkceAnalogiePříklad
GET Načti data „Ukaž mi menu" Načtení seznamu uživatelů
POST Vytvoř nový záznam „Objednávám svíčkovou" Registrace, přihlášení, odeslání formuláře
PUT Celá aktualizace záznamu „Vyměň celou objednávku" Uložení celého profilu uživatele
PATCH Částečná aktualizace „Změň jen přílohu" Změna jen emailu v profilu
DELETE Smaž záznam „Zruš objednávku" Smazání uživatele, záznamu

Metody v Cypress

// cy.intercept — zachytí request dané metody a URL
cy.intercept('GET', '/api/users').as('getUsers')
cy.intercept('POST', '/api/users').as('createUser')
cy.intercept('DELETE', '/api/users/42').as('deleteUser')

// cy.request — pošle request přímo z testu
cy.request('GET', '/api/users')
cy.request('POST', '/api/login', { email: 'a@b.cz', password: 'heslo' })

URL a endpoint

URL (adresa) requestu říká, kam žádost míří. V kontextu API se hovoří o endpointu — konkrétní adrese, na které server čeká na určitý typ požadavku. 

https://api.example.com/users
│       │               │
│       │               └── endpoint — "users" zdroj
│       └── doména — kde server běží
└── protokol — HTTP nebo HTTPS
// Typické API endpointy
GET    /api/users           // seznam všech uživatelů
GET    /api/users/42        // jeden uživatel s ID 42
POST   /api/users           // vytvoř nového uživatele
PUT    /api/users/42        // aktualizuj uživatele 42
DELETE /api/users/42        // smaž uživatele 42

Stavové kódy — jak to dopadlo

Server v response vždy vrátí číslo — stavový kód — který říká, jak požadavek dopadl. Jsou rozděleny do skupin podle první číslice.

KódNázevZnamená
200OKVše proběhlo v pořádku, data v odpovědi
201CreatedNový záznam byl úspěšně vytvořen
204No ContentÚspěch, ale bez dat v odpovědi (např. DELETE)
400Bad RequestŠpatný formát požadavku, chybí data
401UnauthorizedNejsi přihlášen — pošli token
403ForbiddenPřihlášen jsi, ale nemáš oprávnění
404Not FoundZáznam nebo stránka neexistuje
500Internal Server ErrorChyba na straně serveru

Stavové kódy v Cypress

// Ověření stavového kódu po requestu
cy.request('GET', '/api/users')
  .its('status')
  .should('eq', 200)

// Ověření kódu přes wait + intercept
cy.wait('@getUsers')
  .its('response.statusCode')
  .should('eq', 200)

// Cypress ve výchozím nastavení selže při 4xx a 5xx
// Lze vypnout pomocí failOnStatusCode
cy.request({
  url: '/api/users/neexistujici',
  failOnStatusCode: false,           // neselže automaticky
}).its('status').should('eq', 404)

Co je JSON

JSON (JavaScript Object Notation) je formát dat, ve kterém servery nejčastěji posílají odpovědi. Vypadá téměř jako JavaScript objekt — a Cypress s ním pracuje přímo.

Příklad JSON odpovědi ze serveru

// Server vrátí toto jako odpověď na GET /api/users/42
{
  "id": 42,
  "jmeno": "Pavel",
  "email": "pavel@example.cz",
  "jeAdmin": false,
  "role": ["editor", "viewer"]
}

Práce s JSON v Cypress

cy.request('GET', '/api/users/42').then((response) => {
  // response.body je už automaticky parsovaný JSON objekt
  expect(response.body.jmeno).to.eq('Pavel')
  expect(response.body.jeAdmin).to.eq(false)
  expect(response.body.role).to.include('editor')
})

// Nebo přes .its()
cy.request('GET', '/api/users/42')
  .its('body.jmeno')
  .should('eq', 'Pavel')

Request a response v DevTools

V Chrome DevTools (F12) → záložka Network vidíš všechny HTTP requesty, které prohlížeč posílá. Každý request má záložky:

  • Headers — metadata requestu (metoda, URL, autorizační token)
  • Payload — tělo requestu (data odesílaná na server)
  • Response — odpověď serveru (JSON data)
  • Status — stavový kód (200, 404...)

Tato záložka je neocenitelná při psaní cy.intercept() — přesně odtud zjistíš, jaká URL a metoda se volá, abys je mohl správně zachytit.
