Instalace Node.js

Node.js je runtime prostředí pro JavaScript. Cypress vyžaduje Node.js verze 18 nebo vyšší.

Kdy použít

  • Před instalací Cypressu
  • Když nemáte Node.js nainstalovaný
  • Když potřebujete aktualizovat verzi

Instalace

1. Stáhnutí Node.js

Navštivte nodejs.org a stáhněte LTS verzi (doporučeno).

2. Ověření instalace

node --version
npm --version

Měli byste vidět verzi Node.js (např. v20.x.x) a npm (např. 10.x.x).

Alternativa: nvm (Node Version Manager)

Pro správu více verzí Node.js použijte nvm: 

# Instalace nvm (Mac/Linux)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Instalace Node.js přes nvm
nvm install 20
nvm use 20

Důležité poznámky

  • Cypress vyžaduje Node.js 18+
  • LTS verze je doporučená (Long Term Support)
  • npm je automaticky součástí Node.js
