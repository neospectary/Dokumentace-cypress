Proměnné, objekty a pole

Každý Cypress příkaz pracuje s daty — texty, čísly, seznamy, nastavením. Aby ti kód dával smysl, musíš vědět, jak JavaScript ukládá a organizuje data. Tato stránka pokrývá minimum, které nutně potřebuješ.

Proměnné — const a let

Proměnná je pojmenované místo v paměti, kde si uložíš hodnotu. V moderním JavaScriptu používáš dvě klíčová slova: const a let.

const — hodnota se nemění

const jmeno = 'Pavel'
const vek = 30
const jeAdmin = true

// const nelze přepsat — dostaneš chybu
jmeno = 'Mario'    // ❌ TypeError: Assignment to constant variable

Používej const jako výchozí volbu — říkáš tím: „tato hodnota se nezmění." Dělá kód předvídatelným.

let — hodnota se může změnit

let pocet = 0
pocet = pocet + 1    // ✅ let lze přepsat
pocet = 5            // ✅ funguje

let zprava = 'Načítám...'
zprava = 'Hotovo!'   // ✅ funguje

Používej let jen když víš, že hodnotu budeš měnit — čítače, stavy, akumulátory.

var — nepoužívej

// var je starý způsob — má nevyzpytatelné chování
// V moderním JavaScriptu a Cypressu var neuvidíš (ani nepiš)
var staraPromenna = 'zastaralo'    // ❌ nepoužívej

Template literals — vkládání proměnné do textu

const jmeno = 'Pavel'
const vek = 30

// Staré spojování stringů — nepřehledné
const zprava = 'Jmenuji se ' + jmeno + ' a je mi ' + vek + ' let.'

// Template literal — backtick (`) a ${proměnná}
const zprava = `Jmenuji se ${jmeno} a je mi ${vek} let.`

// Výsledek: "Jmenuji se Pavel a je mi 30 let."

Template literals poznáš podle zpětných uvozovek ` (backtick). Proměnnou vložíš pomocí ${}. V Cypressu je uvidíš například při dynamickém sestavování URL nebo zpráv v logách. 

const userId = 42
cy.visit(`/users/${userId}/profile`)     // navštíví /users/42/profile
cy.log(`Testuju uživatele ID: ${userId}`)

Objekty — {} složené závorky

Objekt je kolekce pojmenovaných hodnot (klíč–hodnota páry). Složené závorky {} vždy znamenají objekt v JavaScriptu.

Vytvoření objektu

const uzivatel = {
  jmeno: 'Pavel',
  vek: 30,
  jeAdmin: false,
  email: 'pavel@example.cz',
}

Přístup k hodnotám

console.log(uzivatel.jmeno)     // 'Pavel'  — tečková notace
console.log(uzivatel['vek'])    // 30        — hranatá notace
console.log(uzivatel.jeAdmin)   // false

Objekty jako options v Cypress

Cypress příkazy přijímají nastavení jako objekt — proto všude vidíš { timeout: 10000 } nebo { log: false }. 

// Objekt s nastavením předaný jako argument
cy.get('[data-cy="modal"]', { timeout: 10000 })
//                           ↑ toto je objekt — klíč: hodnota

cy.visit('/login', { failOnStatusCode: false })
//                  ↑ toto je objekt

cy.request({
  method: 'POST',          // ← klíč: hodnota
  url: '/api/login',       // ← klíč: hodnota
  body: {                  // ← vnořený objekt
    email: 'a@b.cz',
    password: 'heslo123',
  },
})

Pole — [] hranaté závorky

Pole je seřazený seznam hodnot. Hranaté závorky [] vždy znamenají pole. Položky jsou indexovány od 0.

Vytvoření pole

const ovoce = ['jablko', 'hruška', 'banán']
const cisla = [1, 2, 3, 4, 5]
const smisene = ['text', 42, true, null]

Přístup k položkám

console.log(ovoce[0])    // 'jablko'  — první položka (index 0)
console.log(ovoce[1])    // 'hruška'  — druhá položka (index 1)
console.log(ovoce[2])    // 'banán'   — třetí položka (index 2)
console.log(ovoce.length) // 3         — počet položek

Pole v Cypressu

// Čekání na více aliasů najednou — pole stringů
cy.wait(['@getUsers', '@getSettings', '@getNotifications'])
//       ↑ toto je pole stringů

// cy.env přijímá pole klíčů
cy.env(['apiUrl', 'apiKey']).then(({ apiUrl, apiKey }) => {
  cy.visit(apiUrl)
})

Destrukturování — zkrácený přístup k hodnotám

Destrukturování ti umožňuje "rozbalit" objekt nebo pole do pojmenovaných proměnných najednou. V Cypressu to uvidíš hlavně při práci s cy.env() nebo cy.then().

Destrukturování objektu

const uzivatel = { jmeno: 'Pavel', vek: 30, email: 'p@e.cz' }

// Bez destrukturování — opakuješ "uzivatel."
const jmeno = uzivatel.jmeno
const vek = uzivatel.vek

// S destrukturováním — jednořádkový zápis
const { jmeno, vek } = uzivatel

console.log(jmeno)    // 'Pavel'
console.log(vek)      // 30

Destrukturování v Cypress callback

// cy.env vrátí objekt { apiUrl: '...', apiKey: '...' }
// Destrukturování ho rovnou rozbalíme do pojmenovaných proměnných
cy.env(['apiUrl', 'apiKey']).then(({ apiUrl, apiKey }) => {
  //                                 ↑ destrukturování objektu v parametru
  cy.request({
    url: `${apiUrl}/users`,
    headers: { Authorization: `Bearer ${apiKey}` },
  })
})
