Spuštění Cypressu

Způsoby spuštění Cypress testů. Cypress lze spustit v interaktivním režimu (Test Runner) nebo v headless režimu (CI/CD).

Interaktivní režim (Test Runner)

Otevře grafické rozhraní pro spouštění a debugování testů.

Spuštění

npx cypress open
# nebo
yarn cypress open

Kdy použít

  • Při vývoji testů
  • Pro debugování
  • Pro vizuální kontrolu

Headless režim (CLI)

Spuštění testů z příkazové řádky bez grafického rozhraní.

Spuštění všech testů

npx cypress run
# nebo
yarn cypress run

Spuštění konkrétního souboru

npx cypress run --spec "cypress/e2e/my-test.cy.ts"

Spuštění s prohlížečem

npx cypress run --browser chrome
npx cypress run --browser firefox
npx cypress run --browser edge

Kdy použít

  • V CI/CD pipeline
  • Pro automatické spouštění
  • Pro rychlejší spuštění

NPM skripty

Přidejte do package.json pro snadné spouštění: 

{
  "scripts": {
    "cy:open": "cypress open",
    "cy:run": "cypress run",
    "cy:run:chrome": "cypress run --browser chrome",
    "test:e2e": "cypress run"
  }
}

Použití

npm run cy:open
npm run cy:run
npm run cy:run:chrome

Důležité poznámky

  • Interaktivní režim: pro vývoj a debug
  • Headless režim: pro CI/CD a automatizaci
  • V headless režimu se automaticky pořizují screenshots při selhání
