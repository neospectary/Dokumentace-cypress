Nastavení TypeScriptu

TypeScript přidává type safety do Cypress testů. Doporučeno pro lepší vývojovou zkušenost a autocomplete.

Kdy použít

  • Pro lepší autocomplete a type checking
  • Pro větší projekty s více testy
  • Když chcete type safety

Instalace

1. Instalace TypeScriptu

npm install --save-dev typescript
npm install --save-dev @types/node

2. Vytvoření tsconfig.json

{
  "compilerOptions": {
    "target": "es5",
    "lib": ["es5", "dom"],
    "types": ["cypress", "node"],
    "module": "esnext",
    "moduleResolution": "node",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true
  },
  "include": ["cypress/**/*.ts"],
  "exclude": ["node_modules"]
}

3. Přejmenování souborů

# Přejmenujte .js soubory na .ts
cypress/e2e/example.cy.js → cypress/e2e/example.cy.ts

Konfigurace Cypressu pro TypeScript

cypress.config.ts

import { defineConfig } from 'cypress';

export default defineConfig({
  e2e: {
    setupNodeEvents(on, config) {
      // implement node event listeners here
    },
    baseUrl: 'http://localhost:4200',
  },
});

Důležité poznámky

  • TypeScript je volitelný, ale doporučený
  • Umožňuje autocomplete a type checking
  • Soubory musí mít příponu .ts nebo .tsx
