Instalace a setup

Kompletní průvodce instalací Cypressu, TypeScriptu a nastavením projektu. Všechny kroky potřebné pro začátek práce s Cypress testováním.

Co budete potřebovat

  • Node.js - verze 18 nebo vyšší
  • npm nebo yarn - správce balíčků
  • VS Code - doporučený editor (volitelné)
  • Git - pro verzování (volitelné)
