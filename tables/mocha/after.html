after()

after() je Mocha hook, který se spustí jednou po všech testech v daném describe() bloku. V Cypressu se používá spíš výjimečně – typicky pro úklid globálního stavu nebo testovacích dat po celé sadě testů.

Syntaxe

after(fn)

Kdy použít after()

  • Když chceš něco spustit jen jednou po všech testech ve skupině.
  • Typicky: úklid testovacích dat, odhlášení, zavření speciálních zdrojů (pokud je používáš).
  • Ne: reset stavu mezi testy – to patří do afterEach() nebo spíš do čistého beforeEach() setupu.

Příklad – úklid po sadě testů

describe('Import kontaktů', () => {
  before(() => {
    cy.tokenAuth('/contacts/import');
  });

  it('naimportuje CSV soubor', () => {
    // ...
  });

  it('zobrazí historii importů', () => {
    // ...
  });

  after(() => {
    // Příklad: smazání dočasných importovaných dat
    // (pseudo-kód podle konkrétního API)
    // cy.request('DELETE', '/api/contacts?tag=temp-import');
  });
});
