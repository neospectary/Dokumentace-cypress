afterEach()

afterEach() je Mocha hook, který se spustí po každém testu v daném describe() bloku. V Cypressu se používá hlavně pro úklid, logování nebo doplňkové akce po testu.

Syntaxe

afterEach(fn)

Kdy použít afterEach()

  • Když potřebuješ po každém testu uklidit (např. smazat vytvořená data přes API).
  • Pro logování stavu po testu, případně pro doplňkové screenshoty.
  • Méně často než beforeEach(), ale užitečné v komplexnějších scénářích.

Příklad – úklid testovacích dat

describe('Segmenty', () => {
  beforeEach(() => {
    cy.tokenAuth('/segments');
  });

  afterEach(() => {
    // Příklad: smazání dočasně vytvořeného segmentu přes API
    // (pseudo-kód podle konkrétního API)
    // cy.request('DELETE', '/api/segments/temp-test-segment');
  });

  it('vytvoří dočasný testovací segment', () => {
    // ...
  });
});
