before()

before() je Mocha hook, který se spustí jednou před všemi testy v daném describe() bloku. V Cypressu se používá hlavně pro nastavení „drahých“ věcí, které nechceš dělat před každým testem zvlášť (např. přihlášení).

Syntaxe

before(fn)

Kdy použít before()

  • Když chceš něco spustit jen jednou před všemi testy ve skupině.
  • Typicky: přihlášení, vytvoření testovacích dat přes API, nastavení globálního stavu.
  • Ne: věci, které se mají resetovat před každým testem (to patří do beforeEach()).

Příklad z praxe – přihlášení jednou pro celou sadu

describe('Dashboard', () => {
  before(() => {
    // Přihlášení jen jednou před všemi testy
    cy.tokenAuth('/dashboard');
  });

  it('zobrazí souhrnné statistiky', () => {
    cy.dataCy('stats-card')
      .should('be.visible')
      .and('have.length.at.least', 1);
  });

  it('umožní přejít do detailu feedu', () => {
    cy.dataCy('feed-row').first().click();
    cy.location('pathname').should('include', '/feeds/');
  });
});

Pozor na sdílený stav mezi testy

before() se spustí jen jednou – pokud v testech měníš stav aplikace (např. mažeš data), další testy mohou běžet už v „rozbitém“ stavu. Proto:

  • Používej before() pro věci, které jsou bezpečné pro všechny testy (přihlášení, základní nastavení).
  • Pro reset stavu (např. otevření konkrétní stránky) preferuj beforeEach().
