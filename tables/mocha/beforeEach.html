beforeEach()

beforeEach() je Mocha hook, který se spustí před každým testem v daném describe() bloku. V Cypressu je to nejpoužívanější hook – slouží pro nastavení opakujícího se stavu před každým testem.

Syntaxe

beforeEach(fn)

Kdy použít beforeEach()

  • Když chceš mít každý test ve stejném výchozím stavu.
  • Typicky: otevření konkrétní URL, vyčištění dat, nastavení výchozího filtru, reset formuláře.
  • Pomáhá udržet testy nezávislé – každý test začíná „na čisto“.

Příklad z praxe – stránka mailing listu

describe('Mailing list', () => {
  beforeEach(() => {
    // Přihlášení + otevření stránky před KAŽDÝM testem
    cy.tokenAuth('/mailing-list');
  });

  it('zobrazí seznam mailing listů', () => {
    cy.dataCy('mailing-list-row').should('have.length.at.least', 1);
  });

  it('umožní vytvořit nový mailing list', () => {
    cy.dataCy('create-mailing-list').click();
    cy.dataCy('notification')
      .should('be.visible')
      .and('contain.text', 'Mailing list byl vytvořen');
  });
});

beforeEach() vs before()

  • before() – spustí se JEDNOU před všemi testy.
  • beforeEach() – spustí se PŘED KAŽDÝM testem.
  • Pro čistý a opakovatelný stav testů preferuj beforeEach() na úrovni konkrétního describe().
