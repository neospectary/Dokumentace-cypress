describe(), context() a it()

Základní stavební kameny Mocha BDD syntaxe. Pomocí describe() / context() strukturuješ testy do skupin a pomocí it() definuješ jednotlivé scénáře.

describe() – skupina (suite) testů

describe() vytvoří skupinu testů pro jednu oblast (feature, stránku, modul). Uvnitř bývají hooky a it() testy.

Syntaxe

describe(title, fn)

Použití

describe('Dashboard', () => {
  it('zobrazí souhrnné statistiky', () => {
    // ...
  });

  it('umožní přejít do detailu', () => {
    // ...
  });
});

V Cypressu můžeš mít v jednom souboru více describe() bloků (např. pro různé části aplikace), ale obvykle je lepší držet se jedné větší oblasti na soubor.

context() – alias pro describe()

context() je jen alias pro describe(). Používá se často pro slovní vyjádření „když…“ (when), aby byl test čitelnější.

Použití

describe('Mailing list', () => {
  context('když je uživatel přihlášený', () => {
    it('vidí seznam mailing listů', () => {
      // ...
    });
  });

  context('když není přihlášený', () => {
    it('je přesměrován na login', () => {
      // ...
    });
  });
});

it() – jednotlivý test

it() definuje jeden konkrétní test – scénář chování, které chceš ověřit. V názvu testu popiš očekávání (co by se mělo stát).

Syntaxe

it(title, fn)

Použití v naší aplikaci

describe('Mailing list', () => {
  beforeEach(() => {
    cy.tokenAuth('/mailing-list');
  });

  it('vytvoří nový mailing list', () => {
    cy.dataCy('create-mailing-list').click();
    cy.dataCy('notification')
      .should('be.visible')
      .and('contain.text', 'Mailing list byl vytvořen');
  });

  it('smaže existující mailing list', () => {
    cy.dataCy('mailing-list-row').first().within(() => {
      cy.dataCy('delete-button').click();
    });
    cy.dataCy('confirm-delete').click();

    cy.dataCy('notification')
      .should('be.visible')
      .and('contain.text', 'Mailing list byl smazán');
  });
});

Doporučení pro psaní názvů

  • Používej popisný text: „uloží formulář při validních datech“, ne jen „formulář 1“.
  • Kombinuj s context() pro různé stavy (přihlášený, nepřihlášený, prázdná data…).
