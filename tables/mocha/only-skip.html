.only() a .skip()

.only() a .skip() jsou Mocha utility pro filtrování testů. Pomáhají při ladění – můžeš spouštět jen vybrané testy nebo některé dočasně přeskočit.

.only() – spustit jen vybrané testy

.only() říká Mocha/Cypressu: „spusť jen tento test nebo tuto skupinu“. Hodí se při debugování konkrétního scénáře.

Použití na úrovni describe()

describe.only('Mailing list', () => {
  it('vytvoří nový mailing list', () => { /* ... */ });
  it('smaže mailing list', () => { /* ... */ });
});

Použití na úrovni it()

it.only('ladím jen tento test', () => {
  // ...
});

Pozor: Pokud někde v souboru existuje .only, spustí se jen tyto testy a ostatní se ignorují. Ideální pro lokální vývoj, ale nemělo by zůstat v kódu při commitu.

.skip() – dočasně přeskočit test

.skip() říká Mocha/Cypressu: „tento test teď neprováděj“. Použij, pokud je scénář dočasně nefunkční nebo čeká na úpravu.

Použití

it.skip('dočasně nefunkční scénář', () => {
  // tento test se nyní neprovede
});

Přeskočené testy se v reportu zobrazí jako „skipped“. Je dobré k nim doplnit komentář, proč jsou přeskočené.

Doporučení pro praxi

  • Používej .only() a .skip() jen při vývoji / ladění.
  • Před commitem do repozitáře zkontroluj, že v kódu nezůstalo žádné .only.
  • Pokud něco dlouhodobě nefunguje, raději scénář uprav nebo přeskočení zdůvodni v komentáři.
