Mocha v Cypressu – přehled

Cypress používá jako testovací „motor“ knihovnu Mocha v BDD syntaxi. Díky tomu máš k dispozici známé funkce jako describe(), context(), it(), before(), beforeEach(), afterEach(), after(), a také .only() a .skip() pro filtrování testů.

Oficiální dokumentace: Bundled Libraries – Mocha →

Co Mocha v Cypressu řeší

  • Struktura testů – skupiny a jednotlivé testy (describe(), it()).
  • Lifecycle – nastavení a úklid před/po testech (before(), beforeEach(), afterEach(), after()).
  • Filtrování testů – spouštění jen vybraných testů (.only, .skip).

Mocha se stará o strukturu a běh testů, zatímco Cypress se stará o samotné příkazy (cy.*) a retry-ability.

Základní BDD struktura

describe('Mailing list', () => {
  beforeEach(() => {
    cy.tokenAuth('/mailing-list');
  });

  it('vytvoří nový mailing list', () => {
    cy.dataCy('create-mailing-list').click();
    cy.dataCy('notification')
      .should('be.visible')
      .and('contain.text', 'Mailing list byl vytvořen');
  });
});
  • describe() – skupina testů pro jednu oblast (feature, stránku).
  • beforeEach() – opakovaný setup před každým testem.
  • it() – jeden konkrétní scénář, který něco ověřuje.

Jak Mocha zapadá do Cypress ekosystému

  • Mocha – struktura testů a lifecycle (describe/it/hooky).
  • Chai + Chai-jQuery – assertions (např. .should('be.visible'), .should('have.text', ...)).
  • Cypress – příkazy (cy.get(), cy.request(), cy.intercept(), …) a chytré čekání.
