Vlastní příkazy pro Angular direktivy

Komplexní průvodce vytvářením vlastních Cypress příkazů pro testování Angular komponent a direktiv. Naučíte se vytvářet specializované příkazy pro práci s Angular Material, custom komponentami a direktivami.

Proč vlastní příkazy pro Angular?

Angular aplikace často používají custom komponenty a direktivy, které vyžadují specifický přístup k testování. Vlastní příkazy umožňují zapouzdřit tuto logiku a vytvořit čitelné, udržovatelné testy.

  • Angular Material komponenty - Specifické selektory a interakce
  • Custom direktivy - Vlastní logika pro práci s direktivami
  • Reactive Forms - Práce s FormControl a validací
  • Component Inputs/Outputs - Testování vstupů a výstupů

Základní setup pro Angular

1. Instalace Cypress Angular pluginu

npm install --save-dev cypress-angular

2. Konfigurace v cypress.config.ts

import { defineConfig } from 'cypress';

export default defineConfig({
  e2e: {
    setupNodeEvents(on, config) {
      // Angular specifická konfigurace
    },
    baseUrl: 'http://localhost:4200',
  },
});

3. Import v support/e2e.ts

import './commands';
import 'cypress-angular';

Příkaz pro Angular Material Select

Angular Material má specifické komponenty, které vyžadují jiný přístup než standardní HTML elementy.

TypeScript deklarace

declare global {
  namespace Cypress {
    interface Chainable {
      selectMatOption(selector: string, optionText: string): Chainable<JQuery<HTMLElement>>;
    }
  }
}

Implementace

Cypress.Commands.add('selectMatOption', (selector, optionText) => {
  // Otevřít select
  cy.get(selector).click();
  
  // Vybrat option podle textu
  cy.get('mat-option')
    .contains(optionText)
    .click();
  
  // Ověřit výběr
  cy.get(selector).should('contain', optionText);
});

Použití

cy.selectMatOption('[data-cy="country-select"]', 'Česká republika');

Příkaz pro Angular Reactive Forms

Práce s Angular Reactive Forms vyžaduje specifický přístup k FormControl elementům.

TypeScript deklarace

interface Chainable {
  fillFormControl(
    formControlName: string,
    value: string,
    options?: { clear?: boolean }
  ): Chainable<JQuery<HTMLElement>>;
}

Implementace

Cypress.Commands.add('fillFormControl', (formControlName, value, { clear = false } = {}) => {
  const selector = `[formControlName="${formControlName}"]`;
  
  cy.get(selector).then(($el) => {
    const tagName = $el.prop('tagName').toLowerCase();
    
    if (tagName === 'input' || tagName === 'textarea') {
      if (clear) {
        cy.get(selector).clear();
      }
      cy.get(selector).type(value);
    } else if (tagName === 'select') {
      cy.get(selector).select(value);
    }
  });
  
  // Ověření validace
  cy.get(selector).should('not.have.class', 'ng-invalid');
});

Použití

cy.fillFormControl('email', 'test@example.com');
cy.fillFormControl('password', 'heslo123', { clear: true });

Příkaz pro Angular Custom Direktivy

Testování vlastních Angular direktiv vyžaduje specifický přístup k jejich funkcionalitě.

Příklad: Testování tooltip direktivy

Cypress.Commands.add('checkTooltip', (selector, expectedText) => {
  cy.get(selector)
    .trigger('mouseenter')
    .then(() => {
      cy.get('mat-tooltip-component')
        .should('be.visible')
        .and('contain', expectedText);
    });
  
  cy.get(selector).trigger('mouseleave');
});

Příklad: Testování custom validace

Cypress.Commands.add('checkCustomValidation', (formControlName, errorMessage) => {
  cy.get(`[formControlName="${formControlName}"]`)
    .should('have.class', 'ng-invalid');
  
  cy.get(`[formControlName="${formControlName}"]`)
    .parent()
    .find('.error-message')
    .should('contain', errorMessage);
});

Příkaz pro Angular Component Inputs

Testování, že komponenta správně reaguje na změny inputů.

TypeScript deklarace

interface Chainable {
  setComponentInput(
    componentSelector: string,
    inputName: string,
    value: any
  ): Chainable<JQuery<HTMLElement>>;
}

Implementace

Cypress.Commands.add('setComponentInput', (componentSelector, inputName, value) => {
  cy.window().then((win) => {
    const component = win.ng.probe(
      Cypress.$(componentSelector)[0]
    )?.componentInstance;
    
    if (component) {
      component[inputName] = value;
      win.ng.probe(Cypress.$(componentSelector)[0])?.injector.get(
        win.ng.coreTokens.ApplicationRef
      ).tick();
    }
  });
});

Příkaz pro Angular Router

Testování navigace v Angular aplikaci pomocí Router API.

TypeScript deklarace

interface Chainable {
  navigateTo(route: string): Chainable<void>;
}

Implementace

Cypress.Commands.add('navigateTo', (route) => {
  cy.window().then((win) => {
    const router = win.ng.probe(
      Cypress.$('app-root')[0]
    )?.injector.get(win.ng.router.Router);
    
    router.navigate([route]);
  });
  
  cy.url().should('include', route);
});

Použití

cy.navigateTo('/dashboard');
cy.navigateTo('/users/123');

Kompletní příklad: Formulář s Angular komponentami

Ukázka použití vlastních příkazů v komplexním testu Angular formuláře. 

describe('Angular formulář', () => {
  beforeEach(() => {
    cy.visit('/register');
  });

  it('úspěšná registrace', () => {
    // Vyplnění Reactive Form
    cy.fillFormControl('firstName', 'David');
    cy.fillFormControl('lastName', 'Novák');
    cy.fillFormControl('email', 'david@example.com');
    
    // Angular Material Select
    cy.selectMatOption('[data-cy="country-select"]', 'Česká republika');
    
    // Checkbox s Angular Material
    cy.get('mat-checkbox[data-cy="terms"]').click();
    
    // Odeslání
    cy.get('button[type="submit"]').click();
    
    // Ověření navigace
    cy.url().should('include', '/dashboard');
  });
});

Best Practices pro Angular

✅ DOPORUČENO

  • Používejte data-cy atributy na Angular komponentách
  • Vytvářejte příkazy pro opakující se Angular patterns
  • Čekejte na Angular stabilitu před interakcemi
  • Používejte Angular DevTools pro debugování

❌ NEDOPORUČENO

  • Nespoléhejte se na interní Angular strukturu
  • Nepoužívejte přímý přístup k komponentám bez opatrnosti
  • Nevytvářejte příkazy závislé na konkrétní Angular verzi

Čekání na Angular

Angular aplikace potřebují čas na inicializaci. Vytvořte příkaz pro čekání na Angular. 

Cypress.Commands.add('waitForAngular', () => {
  cy.window().then((win) => {
    if (win.getAllAngularTestabilities) {
      return new Cypress.Promise((resolve) => {
        win.getAllAngularTestabilities()[0].whenStable(resolve);
      });
    }
  });
});

Použití

cy.visit('/');
cy.waitForAngular();
cy.get('.app-content').should('be.visible');

Debugging Angular komponent

Tipy pro ladění Angular komponent v Cypress testech.

1. Přístup k komponentě

cy.get('[data-cy="my-component"]').then(($el) => {
  const component = Cypress.$(Cypress.dom.getElementsByTagName($el[0], 'app-my-component')[0]);
  const instance = Cypress.$(component[0]).data('$ngController');
  cy.log('Component instance:', instance);
});

2. Ověření stavu komponenty

cy.window().then((win) => {
  const component = win.ng.probe(
    Cypress.$('[data-cy="my-component"]')[0]
  )?.componentInstance;
  
  expect(component.isLoading).to.be.false;
});
