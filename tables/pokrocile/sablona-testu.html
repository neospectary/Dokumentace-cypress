Šablona pro nové testy

Kompletní šablona struktury testu založená na analýze reálných profesionálních testů. Použijte tuto šablonu jako startovní bod pro nové testy.

Kompletní šablona s komentáři

/**
 * Název scénáře
 * -------------------------------------------------------------
 * Tento scénář testuje:
 * 1. Vytvoření nového záznamu
 * 2. Ověření zobrazení v tabulce
 * 3. Editace záznamu
 * 4. Smazání záznamu
 */

// ============================================
// KONSTANTY PRO TESTOVACÍ DATA
// ============================================
const HASH = (+new Date()).toString(36);
const TEST_NAME = `Test_${HASH}`;
const TEST_EMAIL = `test_${HASH}@example.com`;

// ============================================
// HLAVNÍ BLOK TESTOVÁNÍ
// ============================================
describe('Název feature (např. Contact List)', () => {
  
  // Context pro viewport/device
  context('DESKTOP', Cypress.env('resolution')['desktop'], () => {
    
    // ============================================
    // SETUP - PŘÍPRAVA TESTOVACÍHO PROSTŘEDÍ
    // ============================================
    before(() => {
      // Autentizace pomocí API (rychlejší než UI)
      cy.tokenAuth('/cesta-k-strance');
      
      // Nebo pomocí UI
      // cy.visit('/login');
      // cy.authorization('/dashboard');
    });

    // ============================================
    // KROK 1: VYTVOŘENÍ ZÁZNAMU
    // ============================================
    describe('Step 1: Vytvoření nového záznamu', () => {
      
      it('otevře formulář pro vytvoření', () => {
        cy.intercept({ method: 'GET', url: '**/api/endpoint' }).as('getData');
        cy.dataCy('create-button').should('be.visible').click();
        cy.wait('@getData');
        cy.dataCy('modal-window').should('be.visible');
      });

      it('vyplní název záznamu', () => {
        cy.dataCy('modal-window').within(() => {
          cy.checkLabel('name-container', {
            labelValue: 'Název',
            tooltipValue: 'Tooltip text'
          });
          cy.fillInput('name-container', TEST_NAME, {
            required: true,
            type: 'text'
          });
        });
      });

      it('vyplní email', () => {
        cy.dataCy('modal-window').within(() => {
          cy.checkLabel('email-container', {
            labelValue: 'Email'
          });
          cy.fillInput('email-container', TEST_EMAIL, {
            type: 'email',
            required: true
          });
        });
      });

      it('uloží záznam', () => {
        cy.dataCy('modal-window').within(() => {
          cy.intercept({ method: 'POST', url: '**/api/endpoint' }).as('create');
          cy.dataCy('save-button').click();
          cy.wait('@create');
        });
        cy.dataCy('modal-window').should('not.exist');
      });
    });

    // ============================================
    // KROK 2: OVĚŘENÍ V TABULCE
    // ============================================
    describe('Step 2: Ověření v tabulce', () => {
      
      it('vyhledá vytvořený záznam', () => {
        cy.intercept({ method: 'GET', url: '**/api/endpoint/**' }).as('search');
        cy.searchInput('search-container', TEST_NAME);
        cy.wait('@search');
      });

      it('ověří zobrazení záznamu v tabulce', () => {
        cy.dataCy('table-row').should('have.length', 1);
        cy.dataCy('cell-name').should('contain.text', TEST_NAME);
        cy.dataCy('cell-email').should('contain.text', TEST_EMAIL);
      });
    });

    // ============================================
    // KROK 3: EDITACE
    // ============================================
    describe('Step 3: Editace záznamu', () => {
      
      it('otevře detail záznamu', () => {
        cy.intercept({ method: 'GET', url: '**/api/endpoint/**' }).as('getDetail');
        cy.dataCy('detail-button').click();
        cy.wait('@getDetail');
        cy.dataCy('page-header').should('contain.text', TEST_NAME);
      });

      it('upraví název', () => {
        const UPDATED_NAME = `Updated_${TEST_NAME}`;
        cy.fillInput('name-container', UPDATED_NAME, {
          clear: true,
          required: true
        });
      });

      it('uloží změny', () => {
        cy.intercept({ method: 'PUT', url: '**/api/endpoint/**' }).as('update');
        cy.continue('endpoint', 'PUT');
        cy.wait('@update');
      });

      it('ověří uložení změn', () => {
        cy.dataCy('page-header').should('contain.text', `Updated_${TEST_NAME}`);
        cy.checkInputValue('name-container', `Updated_${TEST_NAME}`);
      });
    });

    // ============================================
    // KROK 4: SMAZÁNÍ
    // ============================================
    describe('Step 4: Smazání záznamu', () => {
      
      it('otevře modál pro smazání', () => {
        cy.dataCy('dropdown-button').click();
        cy.dataCy('delete-button').should('be.visible').click();
        cy.dataCy('modal-window').should('be.visible');
      });

      it('potvrdí smazání', () => {
        cy.dataCy('modal-window').within(() => {
          cy.intercept({ method: 'DELETE', url: '**/api/endpoint/**' }).as('delete');
          cy.acceptModal('**/api/endpoint/**', 'Smazat', {
            header: 'Smazat záznam?',
            description: `Opravdu si přejete smazat ${TEST_NAME}?`,
            method: 'DELETE'
          });
          cy.wait('@delete');
        });
      });

      it('ověří, že záznam byl smazán', () => {
        cy.searchInput('search-container', TEST_NAME, { clear: true });
        cy.dataCy('empty-table').should('be.visible');
      });
    });
  });
});

Nejčastější patterns

1. Autentizace

// Rychlá autentizace pomocí API (doporučeno)
before(() => {
  cy.tokenAuth('/dashboard');
});

// Nebo pomocí UI
before(() => {
  cy.visit('/login');
  cy.authorization('/dashboard');
});

2. Mockování API

// Před akcí, která spustí request
cy.intercept({ method: 'GET', url: '**/api/endpoint' }).as('getData');
cy.dataCy('button').click();
cy.wait('@getData');

// Ověření response
cy.wait('@getData').its('response.statusCode').should('eq', 200);

3. Práce s formulářem

// Vyplnění inputu
cy.fillInput('name-container', 'Hodnota', {
  required: true,
  type: 'text',
  clear: true
});

// Vyplnění textarea
cy.fillTextarea('description-container', 'Text', {
  required: false,
  clear: true
});

// Výběr z dropdownu
cy.selectFromList('Hodnota', 0);

// Checkbox
cy.fillCheckbox('terms-container', 'Souhlasím', {
  required: true
});

4. Ověření

// Viditelnost a stav
cy.get('button')
  .should('be.visible')
  .and('be.enabled');

// Text
cy.get('h1')
  .should('be.visible')
  .and('contain.text', 'Nadpis');

// Atributy
cy.get('a')
  .should('have.attr', 'href')
  .and('include', '/page');

// Hodnoty
cy.checkInputValue('name-container', 'Hodnota');

5. Práce s modálem

// Otevření modálu
cy.dataCy('open-modal-button').click();
cy.dataCy('modal-window').should('be.visible');

// Práce uvnitř modálu
cy.dataCy('modal-window').within(() => {
  cy.fillInput('name', 'Hodnota');
  cy.dataCy('save-button').click();
});

// Zavření modálu
cy.dataCy('modal-window').should('not.exist');

6. Práce s tabulkou

// Vyhledávání
cy.searchInput('search-container', 'Hledaný text');

// Ověření počtu řádků
cy.dataCy('table-row').should('have.length', 5);

// Práce s konkrétním řádkem
cy.dataCy('table-row')
  .eq(0)
  .within(() => {
    cy.dataCy('cell-name').should('contain.text', 'Text');
    cy.dataCy('detail-button').click();
  });

7. Navigace

// Ověření URL
cy.url().should('include', '/dashboard');
cy.location('pathname').should('eq', '/settings');

// Navigace zpět
cy.go('back');
cy.goBack(); // vlastní příkaz

Best Practices

✅ DOPORUČENO

  • Používejte HASH pro unikátní hodnoty - const HASH = (+new Date()).toString(36);
  • Autentizace v before() - pomocí API je rychlejší
  • Rozdělte testy do logických kroků - použijte describe() pro kroky
  • Každý it() testuje jednu věc - jasný popis v názvu
  • Používejte cy.intercept() a cy.wait() - pro čekání na API
  • Používejte cy.dataCy() - místo cy.get('[data-cy="..."]')
  • Komentáře nahoře - popište, co test dělá
  • Konstanty pro data - snadná údržba a změna

❌ NEDOPORUČENO

  • Nepoužívejte cy.wait(ms) - použijte cy.wait('@alias')
  • Nepoužívejte hardcoded hodnoty - použijte konstanty
  • Nekombinujte více akcí v jednom it() - rozdělte na více testů
  • Nepoužívejte cy.pause() v produkci - jen pro debug

Organizace testů - kdy použít describe() pro kroky

✅ Použijte describe() pro kroky když:

  • Test má více logických kroků (Step 1, Step 2, atd.)
  • Chcete jasně oddělit části testu
  • Test je komplexní a má více fází

Příklad s kroky:

describe('Contact List', () => {
  describe('Step 1: Vytvoření seznamu', () => {
    it('otevře formulář', () => {});
    it('vyplní údaje', () => {});
    it('uloží seznam', () => {});
  });

  describe('Step 2: Ověření v tabulce', () => {
    it('vyhledá seznam', () => {});
    it('ověří zobrazení', () => {});
  });
});

Nepoužívejte describe() když:

  • Test je jednoduchý a má jen pár testů
  • Kroky na sebe nezávisí

Časté problémy a řešení

1. Element není nalezen

// ❌ ŠPATNĚ
cy.get('.element').click(); // může selhat

// ✅ SPRÁVNĚ
cy.dataCy('element')
  .should('be.visible')
  .click();

2. Čekání na načtení

// ❌ ŠPATNĚ
cy.wait(2000); // anti-pattern

// ✅ SPRÁVNĚ
cy.intercept('GET', '**/api/data').as('getData');
cy.dataCy('button').click();
cy.wait('@getData');

3. Práce s dynamickými daty

let CREATED_ID;

it('použije uložené ID', () => {
  cy.visit(`/detail/${CREATED_ID}`);
});

Tipy pro začátek

  1. Začněte s minimální šablonou - přidejte postupně další části
  2. Nejdřív napište strukturu - describe(), context(), before(), it()
  3. Pak přidejte autentizaci - v before()
  4. Pak přidejte první test - jednoduchý, který funguje
  5. Postupně přidávejte další testy - jeden po druhém
  6. Refaktorujte - když vidíte opakování, vytvořte vlastní příkaz
  7. Používejte konstanty - pro data, které se opakují
  8. Testujte postupně - spouštějte test po každém přidání
