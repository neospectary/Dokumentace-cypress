Vlastní příkazy (Custom Commands)

Vlastní příkazy v Cypressu umožňují vytvářet znovupoužitelné funkce, které zjednodušují testování. Pomocí custom commands můžete zapouzdřit opakující se logiku a vytvořit vlastní API pro vaše testy.

Co jsou vlastní příkazy?

Vlastní příkazy (Custom Commands) jsou uživatelsky definované funkce, které rozšiřují Cypress API. Umožňují vám vytvořit vlastní příkazy jako cy.fillInput(), cy.checkLabel(), atd.

Proč je používat?

  • DRY princip - Vyhnete se opakování kódu napříč testy
  • Čitelnější testy - Test kód je srozumitelnější a expresivnější
  • Snadná údržba - Změny logiky na jednom místě
  • Týmová spolupráce - Jednotné API pro celý tým

Kde se vlastní příkazy definují?

Vlastní příkazy se obvykle definují v souboru cypress/support/commands.ts (nebo commands.js). Tento soubor je automaticky načítán před každým testem.

Struktura projektu

cypress/
├── e2e/
│   └── your-test.cy.ts
├── support/
│   ├── commands.ts        ← Zde definujeme příkazy
│   └── e2e.ts             ← Automaticky načítá commands.ts
└── tsconfig.json

TypeScript deklarace

Pro správnou TypeScript podporu je nutné deklarovat signatury vlastních příkazů. 

/// <reference types="cypress" />

declare global {
  namespace Cypress {
    interface Chainable {
      fillInput(dataCy: string, value: string): Chainable<JQuery<HTMLElement>>;
    }
  }
}

export {};

Vytvoření prvního příkazu

1. TypeScript deklarace

declare global {
  namespace Cypress {
    interface Chainable {
      asterisk(required: boolean): Chainable<JQuery<HTMLElement>>;
    }
  }
}

2. Implementace

Cypress.Commands.add('asterisk', (required) => {
  if (required) {
    cy.dataCy('asterisk').scrollIntoView().should('be.visible');
  } else {
    cy.dataCy('asterisk').should('not.exist');
  }
});

3. Použití

cy.asterisk(true);

Pokročilý příkaz: fillInput

TypeScript deklarace

interface Chainable {
  fillInput(
    dataCy: string,
    typeValue: string | null,
    options?: {
      clear?: boolean;
      type?: string;
      required?: boolean | null;
    }
  ): Chainable<JQuery<HTMLElement>>;
}

Implementace

Cypress.Commands.add('fillInput', (dataCy, typeValue, { clear, type, required = false } = {}) => {
  cy.dataCy(dataCy)
    .scrollIntoView()
    .within(() => {
      const input = cy.get(`input${type ? `[type=${type}]` : ''}`);
      
      if (clear) {
        input.clear();
      }
      
      if (typeValue) {
        input.type(typeValue, { delay: 0 });
      }
      
      if (required) {
        cy.asterisk(required);
      }
    });
});

Použití

cy.fillInput('user-name', 'David');
cy.fillInput('user-email', 'test@example.com', { type: 'email', required: true });

Praktický příkaz: selectDropdownItem

Příkaz pro výběr položky z overlay dropdownu (např. Angular Material, custom select komponenty). Automaticky otevře dropdown, najde overlay kontejner a vybere položku podle textu.

TypeScript deklarace

interface Chainable {
  selectDropdownItem(
    dataCy: string,
    itemText: string
  ): Chainable<JQuery<HTMLElement>>;
}

Implementace

Cypress.Commands.add('selectDropdownItem', (dataCy: string, itemText: string) => {
  cy.dataCy(dataCy).scrollIntoView().click();
  cy.get('.cdk-overlay-container')
    .find('.dropdown-item')
    .contains(itemText)
    .should('be.visible')
    .click();
});

Co příkaz dělá?

  1. cy.dataCy(dataCy).scrollIntoView().click() – Najde trigger dropdownu podle data-cy atributu, scrolluje k němu a klikne (otevře dropdown).
  2. cy.get('.cdk-overlay-container') – Najde overlay kontejner, kam se vykreslil dropdown seznam.
  3. .find('.dropdown-item') – Hledá položky dropdownu jen uvnitř overlay kontejneru (ne na celé stránce).
  4. .contains(itemText) – Najde položku obsahující zadaný text.
  5. .should('be.visible') – Ověří, že položka je viditelná (explicitní assertion).
  6. .click() – Klikne na položku a zavře dropdown.

Použití

// Výběr typu feedu
cy.selectDropdownItem('feed-type-select', 'Obecný XML');

// Výběr země
cy.selectDropdownItem('country-select', 'Česká republika');

// Výběr segmentu
cy.selectDropdownItem('segment-select', 'Aktivní uživatelé');

Výhody tohoto příkazu

  • Automatické scrollování – scrollIntoView() zajistí, že trigger je viditelný před kliknutím.
  • Omezení scope – .find('.dropdown-item') hledá jen uvnitř overlay kontejneru, ne na celé stránce.
  • Explicitní ověření – .should('be.visible') zajišťuje, že položka je skutečně viditelná před kliknutím.
  • Čitelnost testů – V testu stačí napsat cy.selectDropdownItem('feed-type-select', 'Obecný XML') místo několika řádků kódu.

Kdy použít

Tento příkaz je ideální pro overlay dropdowny (Angular Material, custom select komponenty), kde se seznam vykresluje do .cdk-overlay-container nebo podobného overlay kontejneru. Pro nativní HTML <select> použij cy.select().

Osvědčené postupy

✅ DOPORUČENO

  • Vytvářejte příkazy pro opakující se akce
  • Používejte options pattern pro flexibilitu
  • Vracejte Chainable typy pro řetězení
  • Používejte TypeScript pro type safety

❌ NEDOPORUČENO

  • Nevytvářejte příliš komplexní příkazy
  • Neukládejte stav do proměnných mimo Cypress
  • Nepoužívejte async/await
