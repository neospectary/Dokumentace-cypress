Testování accordionů

Kompletní průvodce testováním accordionů v Cypressu. Zahrnuje otevírání, zavírání a ověření obsahu accordionů.

Otevření accordionu

cy.dataCy('personal-info-accordion-item')
  .should('be.visible')
  .click();

Ověření otevření

cy.dataCy('personal-info-accordion-item')
  .should('have.class', 'open')
  .or('have.attr', 'aria-expanded', 'true');

Ověření obsahu accordionu

cy.dataCy('personal-info-accordion-item').click();
cy.dataCy('personal-info-accordion-item')
  .within(() => {
    cy.fillInput('phone-container', '123456789');
    cy.fillInput('address-container', 'Adresa');
  });

Otevření více accordionů

cy.dataCy('personal-info-accordion-item').click();
cy.dataCy('address-accordion-item').click();
cy.dataCy('additional-info-accordion-item').click();

Kompletní příklad

describe('Accordiony', () => {
  before(() => {
    cy.tokenAuth('/contacts/create');
  });

  it('otevře všechny sekce', () => {
    cy.dataCy('personal-info-accordion-item').click();
    cy.dataCy('address-accordion-item').click();
    cy.dataCy('additional-info-accordion-item').click();
  });

  it('vyplní údaje v otevřených sekcích', () => {
    cy.dataCy('personal-info-accordion-item').within(() => {
      cy.fillInput('phone-container', '123456789');
    });
    
    cy.dataCy('address-accordion-item').within(() => {
      cy.fillInput('street-container', 'Ulice 123');
    });
  });
});
