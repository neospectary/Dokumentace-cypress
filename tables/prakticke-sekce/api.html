Testování API

Kompletní průvodce testováním API v Cypressu. Zahrnuje mockování requestů, ověření response a testování API endpointů.

Mockování API requestů

Základní intercept

cy.intercept({ method: 'GET', url: '**/api/endpoint' }).as('getData');
cy.dataCy('load-button').click();
cy.wait('@getData');

Ověření response

cy.wait('@getData').its('response.statusCode').should('eq', 200);
cy.wait('@getData').its('response.body').should('have.property', 'data');

Mockování response

cy.intercept('GET', '**/api/users', {
  statusCode: 200,
  body: {
    users: [
      { id: 1, name: 'Test User' }
    ]
  }
}).as('getUsers');

cy.dataCy('load-users').click();
cy.wait('@getUsers');

Přímé testování API

cy.request({
  method: 'GET',
  url: 'https://api.example.com/users',
  headers: {
    Authorization: `Bearer ${Cypress.env('API_TOKEN')}`
  }
}).then((response) => {
  expect(response.status).to.eq(200);
  expect(response.body).to.have.property('users');
});

Ověření API response po smazání

// Custom příkaz pro ověření 404
Cypress.Commands.add('verifyApiResponse', (baseApiURL, expectedStatus) => {
  cy.wait(1000);
  cy.request({
    method: 'GET',
    url: baseApiURL,
    failOnStatusCode: expectedStatus < 400,
    headers: {
      Authorization: `Bearer ${Cypress.env('CY_API_TOKEN')}`
    }
  }).then((response) => {
    expect(response.status).to.eq(expectedStatus);
  });
});

// Použití
const ITEM_ID = '123';
cy.verifyApiResponse(
  `https://api.example.com/items/${ITEM_ID}`,
  404
);

Kompletní příklad

describe('API testování', () => {
  it('mockuje API request', () => {
    cy.intercept('GET', '**/api/users', {
      statusCode: 200,
      body: { users: [] }
    }).as('getUsers');
    
    cy.visit('/users');
    cy.wait('@getUsers');
  });

  it('ověří API response', () => {
    cy.request({
      method: 'GET',
      url: 'https://api.example.com/users',
      headers: {
        Authorization: `Bearer ${Cypress.env('API_TOKEN')}`
      }
    }).then((response) => {
      expect(response.status).to.eq(200);
      expect(response.body).to.have.property('users');
    });
  });
});
