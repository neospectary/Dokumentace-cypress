Testování drobečkové navigace (Breadcrumb)

Kompletní průvodce testováním drobečkové navigace (breadcrumb) v Cypressu. Zahrnuje ověření zobrazení, obsahu jednotlivých položek a navigaci pomocí breadcrumb.

Základní ověření breadcrumb

Ověření existence breadcrumb

cy.dataCy('breadcrumb').should('be.visible');

Ověření jednotlivých položek

cy.dataCy('breadcrumb-item-0')
  .should('be.visible')
  .and('contain.text', 'Nastavení');

cy.dataCy('breadcrumb-item-1')
  .should('be.visible')
  .and('contain.text', 'Datové zdroje');

cy.dataCy('breadcrumb-item-2')
  .should('be.visible')
  .and('contain.text', 'Feedy');

Ověření aktuální stránky v breadcrumb

// Aktuální stránka je obvykle poslední položka nebo text v breadcrumb
cy.dataCy('breadcrumb')
  .should('contain.text', 'Feedy');

// Nebo pro konkrétní stránku
cy.dataCy('breadcrumb')
  .should('contain.text', 'Párování feedu');

Navigace pomocí breadcrumb

Kliknutí na konkrétní položku

cy.intercept({ method: 'GET', url: '**/settings/**' }).as('navigate');
cy.dataCy('breadcrumb-item-0')
  .should('be.visible')
  .click();
cy.wait('@navigate');
cy.url().should('include', '/settings');

Navigace na předchozí úroveň

// Kliknutí na předposlední položku
cy.dataCy('breadcrumb-item-1')
  .should('be.visible')
  .click();
cy.url().should('include', '/settings/data-sources');

Navigace z výsledků vyhledávání

cy.intercept({ method: 'GET', url: '**/contact-list/grid/**' }).as('goToLists');
cy.dataCy('breadcrumb-seznamy-kontaktů')
  .should('be.visible')
  .click();
cy.wait('@goToLists');
cy.dataCy('page-header').should('contain.text', 'Seznamy kontaktů');

Komplexní ověření breadcrumb

Ověření celé cesty

it('ověří breadcrumb navigaci', () => {
  cy.dataCy('breadcrumb').should('be.visible');
  cy.dataCy('breadcrumb-item-0')
    .should('be.visible')
    .and('contain.text', 'Nastavení');
  cy.dataCy('breadcrumb-item-1')
    .should('be.visible')
    .and('contain.text', 'Datové zdroje');
  cy.dataCy('breadcrumb-item-2')
    .should('be.visible')
    .and('contain.text', 'Feedy');
  cy.dataCy('breadcrumb')
    .should('contain.text', 'Párování feedu');
});

Ověření po navigaci

// Po kliknutí na breadcrumb položku
cy.dataCy('breadcrumb-item-0').click();
cy.url().should('include', '/settings');
cy.dataCy('page-header')
  .should('be.visible')
  .and('contain.text', 'Nastavení');

Práce s více breadcrumb na stránce

// Pokud je na stránce více breadcrumb (např. v různých sekcích)
cy.dataCy('breadcrumb-item-0')
  .last() // poslední výskyt
  .click();

Kompletní příklad

describe('Breadcrumb navigace', () => {
  before(() => {
    cy.tokenAuth('/settings/data-sources/feed');
  });

  it('zobrazí breadcrumb navigaci', () => {
    cy.dataCy('breadcrumb').should('be.visible');
    cy.dataCy('breadcrumb-item-0')
      .should('be.visible')
      .and('contain.text', 'Nastavení');
    cy.dataCy('breadcrumb-item-1')
      .should('be.visible')
      .and('contain.text', 'Datové zdroje');
    cy.dataCy('breadcrumb')
      .should('contain.text', 'Feedy');
  });

  it('naviguje na předchozí úroveň', () => {
    cy.intercept({ method: 'GET', url: '**/settings/data-sources/**' }).as('navigate');
    cy.dataCy('breadcrumb-item-1').click();
    cy.wait('@navigate');
    cy.url().should('include', '/settings/data-sources');
  });

  it('naviguje na kořenovou stránku', () => {
    cy.intercept({ method: 'GET', url: '**/settings/**' }).as('navigate');
    cy.dataCy('breadcrumb-item-0').click();
    cy.wait('@navigate');
    cy.url().should('include', '/settings');
  });
});

Breadcrumb v různých kontextech

Breadcrumb na stránce seznamu

describe('Seznam feedů', () => {
  it('zobrazí breadcrumb se správnými položkami', () => {
    cy.dataCy('breadcrumb').should('be.visible');
    cy.dataCy('breadcrumb-item-0').should('contain.text', 'Nastavení');
    cy.dataCy('breadcrumb-item-1').should('contain.text', 'Datové zdroje');
    cy.dataCy('breadcrumb').should('contain.text', 'Feedy');
  });
});

Breadcrumb na stránce detailu/editace

describe('Editace feedu', () => {
  it('zobrazí breadcrumb s aktuální stránkou', () => {
    cy.dataCy('breadcrumb').should('be.visible');
    cy.dataCy('breadcrumb-item-0').should('contain.text', 'Nastavení');
    cy.dataCy('breadcrumb-item-1').should('contain.text', 'Datové zdroje');
    cy.dataCy('breadcrumb-item-2').should('contain.text', 'Feedy');
    cy.dataCy('breadcrumb').should('contain.text', 'Párování feedu');
  });
});

Důležité poznámky

  • Breadcrumb položky jsou obvykle indexované od 0 (breadcrumb-item-0, breadcrumb-item-1, atd.)
  • Aktuální stránka může být zobrazena jako poslední položka nebo jako text v breadcrumb kontejneru
  • Při navigaci pomocí breadcrumb je vhodné použít cy.intercept() a cy.wait() pro čekání na načtení stránky
  • Pokud je na stránce více breadcrumb, použijte .last() nebo .eq() pro výběr správného
