Testování chybových stavů

Kompletní průvodce testováním chybových stavů v Cypressu. Zahrnuje ověření chybových zpráv, 404 stránek a chyb API.

Chybové zprávy v UI

Ověření chybové zprávy

cy.dataCy('error-message')
  .should('be.visible')
  .and('contain.text', 'Došlo k chybě');

Chybová zpráva po neúspěšném requestu

cy.intercept('POST', '**/api/endpoint', {
  statusCode: 400,
  body: { error: 'Validation failed' }
}).as('errorRequest');

cy.dataCy('submit-button').click();
cy.wait('@errorRequest');
cy.dataCy('error-message')
  .should('be.visible')
  .and('contain.text', 'Validation failed');

404 stránka

cy.visit('/non-existent-page', { failOnStatusCode: false });
cy.dataCy('404-message')
  .should('be.visible')
  .and('contain.text', 'Stránka nenalezena');

Prázdné výsledky

cy.dataCy('no-results-header')
  .should('be.visible')
  .and('contain.text', 'Nenalezeny žádné položky');

cy.dataCy('no-results-description')
  .should('be.visible')
  .and('contain.text', 'Zkuste upravit filtry');

Kompletní příklad

describe('Chybové stavy', () => {
  it('zobrazí chybu při neplatném requestu', () => {
    cy.intercept('POST', '**/api/endpoint', {
      statusCode: 400,
      body: { error: 'Invalid data' }
    }).as('errorRequest');
    
    cy.dataCy('submit-button').click();
    cy.wait('@errorRequest');
    cy.dataCy('error-message')
      .should('be.visible')
      .and('contain.text', 'Invalid data');
  });

  it('zobrazí prázdný stav', () => {
    cy.dataCy('search-input').type('neexistující');
    cy.dataCy('no-results-header')
      .should('be.visible')
      .and('contain.text', 'Nenalezeny žádné položky');
  });
});
