Testování dropdownů a select listů

Jak v Cypressu spolehlivě pracovat s dropdown menu a výběrovými seznamy (select), zejména s překryvnými (overlay) komponentami, kde potřebujete vyhledávat jen uvnitř otevřeného dropdownu, ne na zbytku stránky.

Typy dropdownů v praxi

1. Nativní HTML <select>

Klasický HTML prvek <select> s <option>. V Cypressu se ovládá příkazem cy.select() (viz stránka cy.select() v základech).

2. Vlastní (custom) dropdown komponenty

Moderní aplikace (Angular, React, Vue, …) často používají vlastní dropdowny: seznam je vykreslený v overlay mimo původní DOM strom (např. do .cdk-overlay-container, .dropdown-menu, apod.). Tam nelze použít cy.select() a je potřeba pracovat s .click(), .find(), .contains(), .within() atd.

Základní postup v naší aplikaci (overlay dropdown)

V naší aplikaci (podle reálných testů) se dropdown často otevírá do overlay kontejneru (např. .cdk-overlay-container). Postup je vždy stejný:

  1. Otevřít dropdown – klik na trigger (input, tlačítko, řádek v tabulce…).
  2. Najít overlay kontejner – např. cy.get('.cdk-overlay-container') nebo lépe pomocí data-cy.
  3. Omezit scope – použít .within() nebo .find(), aby se hledalo jen uvnitř overlaye.
  4. Vybrat položku – .contains() / .find() na konkrétní text/hodnotu.

Typický vzor v naší aplikaci

// 1) Otevřu dropdown
cy.dataCy('feed-type-select').click();

// 2) Pracuji pouze v overlay okně
cy.get('.cdk-overlay-container').within(() => {
  // 3) Hledám jen uvnitř overlaye, ne na celé stránce
  cy.contains('.dropdown-item', 'Obecný XML')
    .should('be.visible')
    .click();
});

Klíčová část je .within(() => { ... }) nad overlay kontejnerem – vše uvnitř tohoto bloku hledá jen v overlayi, ne v celé stránce.

Použití .within() a .find() pro omezení scope

.within() – práce „uvnitř jednoho okna“

// Otevřu dropdown
cy.dataCy('country-select').click();

// Pracuji jen uvnitř overlay dropdownu
cy.get('.cdk-overlay-container').within(() => {
  cy.get('.dropdown-item')
    .should('have.length.at.least', 1);

  cy.contains('.dropdown-item', 'Česká republika')
    .click();
});

.find() – zřetězené hledání potomků

cy.get('.cdk-overlay-container')
  .find('.dropdown-item')
  .contains('Česká republika')
  .click();

Rozdíl:

  • .within() změní scope pro všechny příkazy uvnitř callbacku.
  • .find() je chain příkaz, který hledá potomky od aktuálního elementu.
  • Oba přístupy jsou správné – vyber ten, který je pro tebe čitelnější.

Jak to řeší jiní testeři v externích aplikacích

Vzor pro Material / CDK overlay (Angular)

// Otevřu select
cy.get('[data-cy="country-select"]').click();

// Overlay má classu .cdk-overlay-pane nebo .cdk-overlay-container
cy.get('.cdk-overlay-container')
  .find('.mat-option-text')
  .contains('Česká republika')
  .click();

Vzor pro bootstrap/dropdown-menu (React/Vue)

cy.get('[data-cy="status-dropdown"]').click();

cy.get('.dropdown-menu.show') // jen otevřené menu
  .within(() => {
    cy.contains('li', 'Aktivní').click();
  });

Vzor s ARIA role (obecnější a odolnější)

// Trigger
cy.get('[aria-haspopup="listbox"]').click();

// Overlay/listbox
cy.get('[role="listbox"]').within(() => {
  cy.contains('[role="option"]', 'Hodnota 1').click();
});

Časté doporučení z fór a GitHub issues:

  • Nespoléhat se na generované názvy tříd typu .cdk-overlay-0, ale na stabilnější selektory (role, data-*, sémantika).
  • Vždy nejprve otevřít dropdown (jinak overlay neexistuje a test padá).
  • Pracovat s .within() / .find(), aby se nevybíraly prvky z jiných částí stránky.

Jak si testy zjednodušit vlastními příkazy

Pro časté patterny je dobré vytvořit si vlastní command, který skryje technické detaily (overlay, třídy) a v testu pak používáš jen čitelnou akci.

Praktický příklad: selectDropdownItem

V naší aplikaci používáme vlastní command cy.selectDropdownItem(), který zjednodušuje práci s overlay dropdowny.

TypeScript deklarace

interface Chainable {
  selectDropdownItem(
    dataCy: string,
    itemText: string
  ): Chainable<JQuery<HTMLElement>>;
}

Implementace

Cypress.Commands.add('selectDropdownItem', (dataCy: string, itemText: string) => {
  cy.dataCy(dataCy).scrollIntoView().click();
  cy.get('.cdk-overlay-container')
    .find('.dropdown-item')
    .contains(itemText)
    .should('be.visible')
    .click();
});

Použití v testu

// Místo několika řádků:
// cy.dataCy('feed-type-select').click();
// cy.get('.cdk-overlay-container').within(() => {
//   cy.contains('.dropdown-item', 'Obecný XML').click();
// });

// Stačí jeden řádek:
cy.selectDropdownItem('feed-type-select', 'Obecný XML');

Co příkaz dělá?

  1. Najde trigger podle data-cy atributu a otevře dropdown.
  2. Najde overlay kontejner (.cdk-overlay-container).
  3. Omezí scope pomocí .find('.dropdown-item') – hledá jen uvnitř overlaye.
  4. Najde položku obsahující zadaný text.
  5. Ověří viditelnost a klikne na položku.

Detailní popis tohoto příkazu najdeš v sekci "Pokročilé" → "Vlastní příkazy".

Obecný vzor pro vlastní command

// cypress/support/commands.ts
Cypress.Commands.add('selectFromOverlay', (triggerSelector, optionText) => {
  cy.get(triggerSelector).click();

  cy.get('.cdk-overlay-container').within(() => {
    cy.contains('.dropdown-item, [role=\"option\"]', optionText)
      .should('be.visible')
      .click();
  });
});

// Použití v testu
cy.selectFromOverlay('[data-cy=\"country-select\"]', 'Česká republika');

Tímto způsobem můžeš mít v testech velmi čitelný kód a kdykoli se změní implementace dropdownu, opravíš jen jeden command.

Typické chyby a jak se jim vyhnout

1. Hledání na celé stránce místo v overlayi

// ❌ Může najít položku jinde na stránce
cy.contains('Česká republika').click();

// ✅ Hledám jen uvnitř overlay dropdownu
cy.get('.cdk-overlay-container')
  .contains('.dropdown-item', 'Česká republika')
  .click();

2. Práce s dropdownem, který ještě není otevřený

// ❌ Overlay neexistuje
cy.get('.cdk-overlay-container').find('.dropdown-item');

// ✅ Nejprve dropdown otevřu
cy.dataCy('country-select').click();
cy.get('.cdk-overlay-container').find('.dropdown-item');

3. Křehké selektory

// ❌ Křehký selektor
cy.get('.cdk-overlay-0 .mat-option-3').click();

// ✅ Stabilnější selektor
cy.get('.cdk-overlay-container')
  .contains('[role=\"option\"]', 'Česká republika')
  .click();

Shrnutí

  • Vždy nejprve otevři dropdown (klik na trigger).
  • Najdi overlay kontejner a používej .within() nebo .find() pro práci jen uvnitř něj.
  • Používej stabilní selektory – data-cy, role (role=\"listbox\", role=\"option\"), sémantika.
  • Pro opakované vzory si vytvoř vlastní commands (např. cy.selectFromOverlay()).
  • Tím získáš čitelné a odolné testy i pro složité dropdown komponenty.
