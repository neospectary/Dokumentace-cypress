Testování formulářů

Kompletní průvodce testováním formulářů v Cypressu. Zahrnuje vyplňování polí, validaci, odesílání a ověření stavu formuláře.

Základní vyplňování formuláře

Text input

cy.fillInput('name-container', 'Hodnota', {
  required: true,
  type: 'text',
  clear: true
});

cy.checkInputValue('name-container', 'Hodnota');

Textarea

cy.fillTextarea('description-container', 'Popis textu', {
  required: false,
  clear: true
});

cy.checkTextareaValue('description-container', 'Popis textu');

Checkbox

cy.fillCheckbox('terms-container', 'Souhlasím s podmínkami', {
  required: true
});

// Ověření zaškrtnutí
cy.get('[data-cy="terms-container"] input[type="checkbox"]')
  .should('be.checked');

Select/Dropdown

cy.selectFromList('Hodnota', 0);

// Ověření výběru
cy.checkSelectValue('Hodnota', 0);

Validace formuláře

Ověření chybové zprávy

// Pokus o odeslání prázdného formuláře
cy.dataCy('submit-button').click();

// Ověření chybové zprávy
cy.dataCy('error-validation')
  .should('be.visible')
  .and('contain.text', 'Toto pole je povinné.');

Ověření povinných polí

// Pole by mělo mít required atribut
cy.get('[data-cy="name-container"] input')
  .should('have.attr', 'required');

// Nebo pomocí vlastního příkazu
cy.checkLabel('name-container', {
  labelValue: 'Název',
  tooltipValue: 'Tooltip text'
});

Odesílání formuláře

Základní odeslání

cy.intercept({ method: 'POST', url: '**/api/endpoint' }).as('submit');
cy.dataCy('submit-button').click();
cy.wait('@submit').its('response.statusCode').should('eq', 200);

Ověření úspěšného odeslání

cy.wait('@submit').then((interception) => {
  expect(interception.response.statusCode).to.eq(200);
  expect(interception.response.body).to.have.property('id');
});

Komplexní formulář s více kroky

describe('Vytvoření kontaktu', () => {
  const HASH = (+new Date()).toString(36);

  before(() => {
    cy.tokenAuth('/contacts/create');
  });

  it('vyplní základní údaje', () => {
    cy.fillInput('email-container', `${HASH}@example.com`, {
      required: true,
      type: 'email'
    });
    cy.fillInput('name-container', `Name_${HASH}`, {
      type: 'text'
    });
  });

  it('vyplní osobní údaje', () => {
    cy.dataCy('personal-info-accordion-item').click();
    cy.fillInput('phone-container', '123456789', {
      type: 'tel'
    });
  });

  it('odešle formulář', () => {
    cy.intercept({ method: 'POST', url: '**/api/contact' }).as('create');
    cy.dataCy('submit-button').click();
    cy.wait('@create');
  });
});

Ověření stavu formuláře

Ověření vyplněných hodnot

cy.checkInputValue('name-container', 'Očekávaná hodnota');
cy.checkTextareaValue('description-container', 'Očekávaný text');

Ověření disabled stavu

// Tlačítko by mělo být disabled, dokud není formulář validní
cy.dataCy('submit-button')
  .should('be.visible')
  .and('be.disabled');

// Po vyplnění by mělo být enabled
cy.fillInput('name-container', 'Hodnota');
cy.dataCy('submit-button').should('be.enabled');
