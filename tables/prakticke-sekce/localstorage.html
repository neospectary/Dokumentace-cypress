Testování localStorage

Kompletní průvodce testováním localStorage v Cypressu. Zahrnuje čtení, zápis a ověření hodnot v localStorage.

Čtení z localStorage

cy.window().its('localStorage').invoke('getItem', 'API_TOKEN')
  .should('not.be.null')
  .and('not.be.empty');

Zápis do localStorage

cy.window().then((win) => {
  win.localStorage.setItem('API_TOKEN', 'token-value');
});

Ověření po logout

it('vymaže token po logout', () => {
  cy.dataCy('logout-button').click();
  cy.window().its('localStorage').invoke('getItem', 'API_TOKEN')
    .should('be.null');
});

Kompletní příklad

describe('localStorage', () => {
  it('uloží token po přihlášení', () => {
    cy.tokenAuth('/dashboard');
    cy.window().its('localStorage').invoke('getItem', 'API_TOKEN')
      .should('not.be.null');
  });

  it('vymaže token po logout', () => {
    cy.dataCy('logout-button').click();
    cy.window().its('localStorage').invoke('getItem', 'API_TOKEN')
      .should('be.null');
  });
});
