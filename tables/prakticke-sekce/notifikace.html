Testování notifikací

Kompletní průvodce testováním notifikací a toast zpráv v Cypressu. Zahrnuje ověření zobrazení, obsahu a zavření notifikací.

Ověření zobrazení notifikace

Základní ověření

cy.get('se-toasts-hosting')
  .should('be.visible');

// Nebo pomocí data-cy
cy.dataCy('toast-message')
  .should('be.visible')
  .and('contain.text', 'Úspěšně uloženo');

Zavření notifikace

cy.get('se-toasts-hosting')
  .find('button')
  .click({ force: true });

Notifikační centrum

Otevření dropdown

cy.dataCy('notification-dropdown')
  .should('be.visible')
  .click();

cy.dataCy('notification-dropdown-overlay')
  .should('be.visible');

Navigace do notifikačního centra

cy.intercept({ method: 'GET', url: '**/onboarding/application-settings' }).as('getNotifications');
cy.dataCy('notification-dropdown-title')
  .should('be.visible')
  .contains('Notifikační centrum')
  .click();
cy.wait('@getNotifications').its('response.statusCode').should('eq', 200);

Ověření stránky notifikací

cy.dataCy('page-header')
  .should('be.visible')
  .and('contain.text', 'Přehled notifikací');

Kompletní příklad

describe('Notifikace', () => {
  before(() => {
    cy.tokenAuth('/dashboard');
  });

  it('zobrazí toast po úspěšné akci', () => {
    cy.dataCy('save-button').click();
    cy.get('se-toasts-hosting')
      .should('be.visible')
      .and('contain.text', 'Úspěšně uloženo');
  });

  it('zavře toast zprávu', () => {
    cy.get('se-toasts-hosting')
      .find('button')
      .click({ force: true });
  });

  it('otevře notifikační centrum', () => {
    cy.dataCy('notification-dropdown').click();
    cy.dataCy('notification-dropdown-overlay').should('be.visible');
  });
});
