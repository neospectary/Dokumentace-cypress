Testování paginace

Kompletní průvodce testováním paginace v Cypressu. Zahrnuje navigaci mezi stránkami a ověření zobrazení správných dat.

Základní ověření paginace

Ověření zobrazení paginace

cy.dataCy('pagination-links')
  .should('be.visible')
  .and('have.length', 1);

Kliknutí na stránku

cy.intercept({ method: 'GET', url: '**/api/data?page=2' }).as('page2');
cy.dataCy('pagination-link-2').click();
cy.wait('@page2');

Ověření dat na stránce

cy.wait('@page2').then(() => {
  cy.dataCy('table-row').should('have.length', 10);
  // Ověření, že data se změnila
  cy.dataCy('table-row').first().should('not.contain.text', 'Předchozí text');
});

Kompletní příklad

describe('Paginace', () => {
  before(() => {
    cy.tokenAuth('/contacts');
  });

  it('zobrazí paginaci', () => {
    cy.dataCy('pagination-links').should('be.visible');
  });

  it('přejde na druhou stránku', () => {
    cy.intercept({ method: 'GET', url: '**/contact/grid/**' }).as('page2');
    cy.dataCy('pagination-link-2').click();
    cy.wait('@page2');
  });

  it('zobrazí data druhé stránky', () => {
    cy.dataCy('table-row').should('have.length.greaterThan', 0);
  });
});
