Testování tabs

Kompletní průvodce testováním tabů v Cypressu. Zahrnuje přepínání mezi taby, ověření aktivního tabu a obsahu.

Základní práce s taby

Kliknutí na tab

cy.dataCy('tab-1')
  .should('be.visible')
  .and('contain.text', 'Název tabu')
  .click();

Ověření aktivního tabu

cy.dataCy('tab-1')
  .should('have.class', 'active');

cy.dataCy('tab-0')
  .should('not.have.class', 'active');

Ověření obsahu tabu

cy.dataCy('tab-1').click();
cy.dataCy('tab-content')
  .should('be.visible')
  .and('contain.text', 'Obsah tabu');

Procházení všech tabů

cy.dataCy('tab-container')
  .find('[data-cy^="tab-"]')
  .each(($tab, index) => {
    const tabName = $tab.text().trim();
    cy.wrap($tab).click();
    cy.dataCy('tab-content')
      .eq(index)
      .within(() => {
        cy.contains('h3', tabName).should('be.visible');
      });
  });

Kompletní příklad

describe('Tabs', () => {
  before(() => {
    cy.tokenAuth('/page');
  });

  it('zobrazí všechny taby', () => {
    cy.dataCy('tab-container').should('be.visible');
    cy.dataCy('tab-0').should('be.visible').and('contain.text', 'Tab 1');
    cy.dataCy('tab-1').should('be.visible').and('contain.text', 'Tab 2');
  });

  it('přepne na druhý tab', () => {
    cy.dataCy('tab-1').click();
    cy.dataCy('tab-1').should('have.class', 'active');
    cy.dataCy('tab-content').should('contain.text', 'Obsah Tab 2');
  });
});
