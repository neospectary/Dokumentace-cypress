Testování toastových hlášek

Kompletní průvodce testováním toastových hlášek (toast notifications) v Cypressu. Toastové hlášky jsou dočasné zprávy, které se zobrazují po akcích uživatele (úspěch, chyba, varování).

Základní ověření toastu

Ověření zobrazení toastu

// Toast se zobrazuje v elementu se-toasts-hosting
cy.get('se-toasts-hosting')
  .should('be.visible');

Ověření obsahu toastu

// Ověření textu v toastu
cy.get('se-toasts-hosting')
  .should('be.visible')
  .and('contain.text', 'Úspěšně uloženo');

// Nebo pomocí contains
cy.get('se-toasts-hosting')
  .contains('Úspěšně uloženo')
  .should('be.visible');

Zavření toastu

Základní zavření

// Kliknutí na tlačítko zavření v toastu
cy.get('se-toasts-hosting')
  .find('button')
  .click({ force: true });

Ověření, že toast zmizel

cy.get('se-toasts-hosting')
  .find('button')
  .click({ force: true });

// Toast může zmizet automaticky nebo po kliknutí
cy.get('se-toasts-hosting')
  .should('not.exist')
  .or('not.be.visible');

Typy toastových hlášek

Úspěšná zpráva

it('zobrazí toast po úspěšném uložení', () => {
  cy.dataCy('save-button').click();
  cy.get('se-toasts-hosting')
    .should('be.visible')
    .and('contain.text', 'Úspěšně uloženo');
});

Chybová zpráva

it('zobrazí chybový toast', () => {
  cy.dataCy('continue-button').click();
  cy.get('se-toasts-hosting')
    .should('be.visible')
    .and('contain.text', 'Je nutné mít u každé skupiny alespoň jednu podmínku');
});

Varovná zpráva

it('zobrazí varovný toast', () => {
  cy.dataCy('delete-button').click();
  cy.get('se-toasts-hosting')
    .should('be.visible')
    .and('contain.text', 'Varování');
});

Práce s více toasty

Zavření všech toastů

// Pokud se zobrazí více toastů najednou
cy.get('se-toasts-hosting')
  .find('button')
  .each(($button) => {
    cy.wrap($button).click({ force: true });
  });

Ověření konkrétního toastu

// Pokud je více toastů, můžeme použít contains pro konkrétní
cy.get('se-toasts-hosting')
  .contains('Úspěšně uloženo')
  .should('be.visible')
  .parent()
  .find('button')
  .click({ force: true });

Toast po akci

Toast po uložení

it('zobrazí toast po uložení', () => {
  cy.intercept({ method: 'POST', url: '**/api/endpoint' }).as('save');
  cy.dataCy('save-button').click();
  cy.wait('@save');
  
  cy.get('se-toasts-hosting')
    .should('be.visible')
    .and('contain.text', 'Úspěšně uloženo');
});

Toast po smazání

it('zobrazí toast po smazání', () => {
  cy.intercept({ method: 'DELETE', url: '**/api/endpoint/**' }).as('delete');
  cy.dataCy('delete-button').click();
  cy.wait('@delete');
  
  cy.get('se-toasts-hosting')
    .should('be.visible')
    .and('contain.text', 'Úspěšně smazáno');
});

Automatické zavření toastu

Toasty se obvykle zavírají automaticky po určité době. Pokud potřebujete počkat na automatické zavření: 

// Počkat na automatické zavření (obvykle 3-5 sekund)
cy.get('se-toasts-hosting')
  .should('be.visible');

cy.wait(5000); // počkat 5 sekund

cy.get('se-toasts-hosting')
  .should('not.exist')
  .or('not.be.visible');

Kompletní příklady

Příklad 1: Toast po úspěšné akci

describe('Toast po uložení', () => {
  before(() => {
    cy.tokenAuth('/page');
  });

  it('zobrazí toast po úspěšném uložení', () => {
    cy.fillInput('name-container', 'Hodnota');
    cy.intercept({ method: 'POST', url: '**/api/endpoint' }).as('save');
    cy.dataCy('save-button').click();
    cy.wait('@save');
    
    cy.get('se-toasts-hosting')
      .should('be.visible')
      .and('contain.text', 'Úspěšně uloženo');
  });

  it('zavře toast zprávu', () => {
    cy.get('se-toasts-hosting')
      .find('button')
      .click({ force: true });
  });
});

Příklad 2: Chybový toast

describe('Chybový toast', () => {
  before(() => {
    cy.tokenAuth('/page');
  });

  it('zobrazí chybový toast při neplatné akci', () => {
    cy.dataCy('continue-button').scrollIntoView().click();
    
    cy.get('se-toasts-hosting')
      .should('be.visible')
      .and('contain.text', 'Je nutné mít u každé skupiny alespoň jednu podmínku');
  });
});

Příklad 3: Toast po výběru šablony

describe('Toast při výběru šablony', () => {
  before(() => {
    cy.tokenAuth('/templates');
  });

  it('zobrazí toast a zavře ho', () => {
    cy.dataCy('template-name')
      .should('be.visible')
      .and('contain.text', 'Template Name');
    
    // Zavření toastu, který se zobrazil při výběru
    cy.get('se-toasts-hosting')
      .find('button')
      .click({ force: true });
  });
});

Best Practices

✅ DOPORUČENO

  • Vždy ověřte zobrazení toastu - pomocí should('be.visible')
  • Ověřte obsah toastu - pomocí contains() nebo contain.text
  • Použijte force: true - při kliknutí na tlačítko zavření, pokud je toast překrytý
  • Počkejte na API request - před ověřením toastu, pokud se zobrazí po API callu

❌ NEDOPORUČENO

  • Nepoužívejte cy.wait(ms) - pro čekání na toast, použijte should('be.visible')
  • Neignorujte toasty - vždy je ověřte, pokud se mají zobrazit
  • Nepředpokládejte automatické zavření - pokud potřebujete zavřít, zavřete explicitně

Důležité poznámky

  • Toastové hlášky se zobrazují v elementu se-toasts-hosting
  • Toasty se obvykle zobrazují v pravém horním nebo dolním rohu
  • Toasty se mohou automaticky zavřít po 3-5 sekundách
  • Při kliknutí na tlačítko zavření použijte { force: true }, pokud je toast překrytý
  • Pokud se toast zobrazí po API requestu, počkejte na request pomocí cy.wait('@alias')
