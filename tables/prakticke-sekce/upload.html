Testování uploadu souborů

Kompletní průvodce testováním uploadu souborů v Cypressu. Zahrnuje nahrávání souborů pomocí cypress-file-upload pluginu.

Instalace pluginu

npm install --save-dev cypress-file-upload

Nastavení v support/e2e.ts

import 'cypress-file-upload';

// Nebo v commands.ts
import 'cypress-file-upload';

Základní upload

Upload pomocí attachFile

cy.get('input[type="file"]').attachFile('fixtures/file.csv');

// Nebo s data-cy
cy.dataCy('file-input').attachFile('fixtures/file.csv');

Upload s vlastním příkazem

// Definice custom příkazu
Cypress.Commands.add('insertFile', (filePath) => {
  cy.get('input[type="file"]').attachFile(filePath);
});

// Použití
cy.insertFile('import/users_single_line.csv');

Ověření uploadu

Ověření zobrazení souboru

cy.dataCy('file-name')
  .should('be.visible')
  .and('contain.text', 'users_single_line.csv');

cy.dataCy('file-size')
  .should('be.visible')
  .and('contain.text', '123.0 B');

Ověření preview tabulky

cy.dataCy('data-preview-table').should('exist');
cy.dataCy('data-preview-header')
  .should('be.visible')
  .and('contain.text', 'Náhled dat');

Odebrání souboru

cy.dataCy('remove-file').click();
cy.dataCy('file-name').should('not.exist');

Kompletní příklad

describe('Upload souboru', () => {
  const FILE_NAME = 'users_single_line';

  before(() => {
    cy.tokenAuth('/import');
  });

  it('otevře upload formulář', () => {
    cy.dataCy('upload-button').click();
  });

  it('nahraje CSV soubor', () => {
    cy.insertFile(`import/${FILE_NAME}.csv`);
  });

  it('zobrazí informace o souboru', () => {
    cy.dataCy('file-name')
      .should('be.visible')
      .and('contain.text', `${FILE_NAME}.csv`);
    cy.dataCy('file-size').should('be.visible');
  });

  it('zobrazí preview tabulku', () => {
    cy.dataCy('data-preview-table').should('exist');
    cy.dataCy('data-preview-header')
      .should('be.visible')
      .and('contain.text', 'Náhled dat');
  });

  it('odebere soubor', () => {
    cy.dataCy('remove-file').click();
    cy.dataCy('file-name').should('not.exist');
  });
});
