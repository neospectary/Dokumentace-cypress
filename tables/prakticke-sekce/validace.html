Testování validace

Kompletní průvodce testováním validace formulářů v Cypressu. Zahrnuje ověření chybových zpráv, povinných polí a validace v reálném čase.

Ověření chybových zpráv

Zobrazení chybové zprávy

// Pokus o odeslání prázdného formuláře
cy.dataCy('submit-button').click();

// Ověření chybové zprávy
cy.dataCy('error-validation')
  .should('be.visible')
  .and('contain.text', 'Toto pole je povinné.');

Chybová zpráva u konkrétního pole

cy.dataCy('name-container')
  .within(() => {
    cy.dataCy('error-message')
      .should('be.visible')
      .and('contain.text', 'Název je povinný');
  });

Ověření povinných polí

Atribut required

cy.get('[data-cy="name-container"] input')
  .should('have.attr', 'required');

Vizuální indikace povinného pole

cy.dataCy('name-container')
  .find('label')
  .should('contain.text', '*'); // hvězdička pro povinné pole

Validace v reálném čase

Validace po vyplnění

// Neplatný email
cy.fillInput('email-container', 'neplatny-email');
cy.dataCy('error-validation')
  .should('be.visible')
  .and('contain.text', 'Zadejte platný email');

// Platný email
cy.fillInput('email-container', 'platny@email.com');
cy.dataCy('error-validation').should('not.exist');

Stav tlačítka podle validace

// Tlačítko by mělo být disabled, dokud není formulář validní
cy.dataCy('submit-button')
  .should('be.visible')
  .and('be.disabled');

// Po vyplnění všech povinných polí
cy.fillInput('name-container', 'Hodnota');
cy.fillInput('email-container', 'test@example.com');
cy.dataCy('submit-button').should('be.enabled');

Kompletní příklad

describe('Validace formuláře', () => {
  before(() => {
    cy.tokenAuth('/contacts/create');
  });

  it('zobrazí chybu při prázdném odeslání', () => {
    cy.dataCy('submit-button').click();
    cy.dataCy('error-validation')
      .should('be.visible')
      .and('contain.text', 'Toto pole je povinné.');
  });

  it('validuje email v reálném čase', () => {
    cy.fillInput('email-container', 'neplatny');
    cy.dataCy('error-validation')
      .should('contain.text', 'Zadejte platný email');
    
    cy.fillInput('email-container', 'platny@email.com');
    cy.dataCy('error-validation').should('not.exist');
  });

  it('povolí odeslání po vyplnění všech polí', () => {
    cy.fillInput('name-container', 'Jméno');
    cy.fillInput('email-container', 'test@example.com');
    cy.dataCy('submit-button').should('be.enabled');
  });
});
