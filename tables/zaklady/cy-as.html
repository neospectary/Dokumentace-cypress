.as()

Vytvoření aliasu. Umožňuje pojmenovat element nebo hodnotu pro pozdější použití. Alias lze použít pomocí cy.get('@aliasName').

Syntaxe

.as(aliasName)
.as(aliasName, options)

Použití

✅ Správné použití

cy.get('button').as('submitBtn')           // Alias elementu
cy.wrap('value').as('myValue')             // Alias hodnoty
cy.intercept('GET', '/api/users').as('getUsers') // Alias requestu
cy.get('@submitBtn').click()               // Použití aliasu

❌ Nesprávné použití

cy.as('alias')                              // Chyba, nelze řetězit z 'cy'
cy.get('@alias').as('newAlias')            // Chyba, alias nemůže obsahovat @

Argumenty

aliasName (String)

Název aliasu. Měl by být bez @ prefixu (Cypress ho přidá automaticky při použití s cy.get('@aliasName')).

options (Object)

  • type (String) - Typ aliasu ('query', 'static')
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s elementem nebo hodnotou. Alias lze použít později pomocí cy.get('@aliasName').

Příklady

Základní alias

cy.get('button').as('submitBtn')
cy.get('@submitBtn').click()

S hodnotou

cy.wrap('value').as('myValue')
cy.get('@myValue').should('eq', 'value')

Více použití

cy.get('.user-list').as('users')
cy.get('@users').find('.active')
cy.get('@users').should('have.length', 10)

S intercept

cy.intercept('GET', '/api/users').as('getUsers')
cy.visit('/users')
cy.wait('@getUsers')

Poznámky

Použití aliasu

Alias použijte pomocí cy.get('@aliasName'). Alias je dostupný v celém testu (ne jen v rámci callback funkce).

Typy aliasů

Alias lze použít pro elementy, hodnoty i requesty. Pro requesty použijte s cy.wait('@aliasName').

Scope

Aliasy jsou dostupné v celém testu. Pokud vytvoříte alias v beforeEach, je dostupný ve všech testech.

Command Log

Příkaz je zobrazen v Command Log s informacemi o vytvořeném aliasu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
