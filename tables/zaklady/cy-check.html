cy.check()

Zaškrtnutí checkboxu nebo radio buttonu. Ověří a zaškrtne element. Pro odškrtnutí použijte .uncheck().

Syntaxe

.check()
.check(value)
.check(values)
.check(options)

Použití

✅ Správné použití

cy.get('input[type="checkbox"]').check()              // Checkbox
cy.get('input[type="radio"]').check('option1')        // Radio button
cy.get('input[type="checkbox"]').check(['opt1', 'opt2']) // Více checkboxů
cy.get('[data-cy="terms"]').check()                   // Data atribut

❌ Nesprávné použití

cy.check()                                             // Chyba, nelze řetězit z 'cy'
cy.window().check()                                    // Chyba, window není checkbox

Argumenty

value (String|Number)

Hodnota pro radio button. Použijte pro výběr konkrétního radio buttonu ze skupiny.

values (Array)

Pole hodnot pro více checkboxů. Použijte pro zaškrtnutí více checkboxů najednou.

options (Object)

  • force (Boolean, default: false) - Vynutí zaškrtnutí, přeskočí kontrolu actionability
  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací stejný element, který byl zaškrtnut. Lze řetězit další příkazy.

Příklady

Základní zaškrtnutí

cy.get('input[type="checkbox"]').check()
cy.get('[data-cy="terms"]').check()

Radio button

cy.get('input[type="radio"]').check('option1')
cy.get('input[name="gender"]').check('male')

Více checkboxů

cy.get('input[type="checkbox"]').check(['option1', 'option2'])

S force

cy.get('input[type="checkbox"]').check({ force: true })

Poznámky

Actionability

.check() je "action command", který čeká na actionability elementu. Element musí být viditelný, nepřekrytý a checkable.

Checkbox vs Radio

.check() funguje s checkboxy i radio buttony. Pro radio buttony je nutné zadat hodnotu, pokud je více možností.

Uncheck

Pro odškrtnutí checkboxu použijte .uncheck(). Radio buttony nelze odškrtnout pomocí .uncheck().

Command Log

Příkaz je zobrazen v Command Log s informacemi o zaškrtnutém elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
