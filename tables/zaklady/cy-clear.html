cy.clear()

Vymazání hodnoty z input nebo textarea pole. Odstraní veškerý text z pole před vyplněním nové hodnoty.

Syntaxe

.clear()
.clear(options)

Použití

✅ Správné použití

cy.get('input').clear()                     // Vymazání input pole
cy.get('textarea').clear()                  // Vymazání textarea
cy.get('input').clear().type('nová hodnota') // S následným vyplněním

❌ Nesprávné použití

cy.clear()                                   // Chyba, nelze řetězit z 'cy'
cy.window().clear()                          // Chyba, window není input

Argumenty

options (Object)

  • force (Boolean, default: false) - Vynutí vymazání, přeskočí kontrolu actionability
  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací stejný element, ze kterého byla hodnota vymazána. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('input[name="email"]').clear()
cy.get('textarea').clear()

S následným vyplněním

cy.get('input').clear().type('nová hodnota')

S force

cy.get('input').clear({ force: true })

Poznámky

Actionability

.clear() je "action command", který čeká na actionability elementu. Element musí být viditelný, nepřekrytý a focusable.

Typ elementu

.clear() funguje jen pro input a textarea elementy. Pro ostatní typy elementů použijte jiný přístup.

Placeholder

.clear() vymaže veškerý text včetně placeholder (pokud je editovatelný). Po vymazání zůstane pole prázdné.

Command Log

Příkaz je zobrazen v Command Log s informacemi o vymazaném elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
