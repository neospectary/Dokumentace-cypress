cy.click()

Kliknutí na DOM element. Simuluje kliknutí myší na tlačítko, odkaz nebo jiný klikatelný element.

Syntaxe

.click()
.click(options)
.click(position)
.click(position, options)
.click(x, y)
.click(x, y, options)

Použití

✅ Správné použití

cy.get('.btn').click()              // Kliknutí na tlačítko
cy.focused().click()                // Kliknutí na element s focusem
cy.contains('Welcome').click()      // Kliknutí na první element obsahující 'Welcome'

❌ Nesprávné použití

cy.click('.btn')                    // Chyba, nelze řetězit z 'cy'
cy.window().click()                 // Chyba, 'window' nevrací DOM element

Argumenty

position (String)

Pozice, kde má být kliknutí provedeno. Výchozí je center. Platné pozice: topLeft, top, topRight, left, center, right, bottomLeft, bottom, bottomRight.

x, y (Number)

Vzdálenost v pixelech od levého horního rohu elementu, kde má být kliknutí provedeno.

options (Object)

  • altKey (Boolean, default: false) - Aktivuje alt klávesu (option na Mac)
  • ctrlKey (Boolean, default: false) - Aktivuje control klávesu
  • force (Boolean, default: false) - Vynutí kliknutí, přeskočí kontrolu actionability
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log
  • metaKey (Boolean, default: false) - Aktivuje meta klávesu (Windows/Command na Mac)
  • multiple (Boolean, default: false) - Klikne na více elementů postupně
  • shiftKey (Boolean, default: false) - Aktivuje shift klávesu
  • timeout (Number) - Čas čekání na kliknutí

Co vrací (Yields)

Vrací stejný element, na který bylo kliknuto. POZOR: Po .click() není bezpečné řetězit další příkazy, které závisí na elementu.

Příklady

Bez argumentů

cy.get('.nav > a').click()

S pozicí

cy.get('img').click('topRight')

S koordináty

cy.get('#top-banner').click(15, 40)

Force kliknutí

cy.get('.close').click({ force: true })

Kliknutí na více elementů

cy.get('[id^=btn]').click({ multiple: true })

S klávesovými zkratkami

// Shift + kliknutí
cy.get('li:first').click({ shiftKey: true })

// Ctrl + kliknutí
cy.get('.item').click({ ctrlKey: true })

Poznámky

Actionability

.click() je "action command", který čeká na actionability elementu. Element musí být:

  • Viditelný
  • Nepřekrytý jiným elementem
  • Nestabilní (ne animuje se)
  • Povolený (enabled)

Focus

Focus je dán prvnímu focusovatelnému elementu. Například kliknutí na <span> uvnitř <button> dá focus na button.

Force

Použití { force: true } přeskočí kontrolu actionability a automaticky spustí eventy. Používejte opatrně.

Command Log

Příkaz je zobrazen v Command Log s informacemi o kliknutém elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
