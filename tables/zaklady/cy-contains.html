cy.contains()

Výběr elementu podle textového obsahu. Najde element, který obsahuje zadaný text (včetně potomků).

Syntaxe

cy.contains(text)
cy.contains(selector, text)
cy.contains(text, options)

Použití

✅ Správné použití

cy.contains('Odeslat')                    // Najde element s textem
cy.contains('button', 'Odeslat')          // S selektorem
cy.contains(/Odeslat|Submit/)             // S regex
cy.contains('.menu-item', 'Nastavení')     // V rámci selektoru

❌ Nesprávné použití

cy.contains()                              // Chyba, chybí text
cy.window().contains('text')               // Chyba, nelze řetězit

Argumenty

text (String|RegExp)

Text k nalezení nebo regex pattern. Hledá v celém textovém obsahu elementu (včetně potomků).

selector (String)

CSS selektor pro omezení hledání. Najde elementy odpovídající selektoru, které obsahují text.

options (Object)

  • matchCase (Boolean, default: true) - Zda respektovat velikost písmen
  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s nalezeným elementem obsahujícím text. Lze řetězit další příkazy.

Příklady

Základní použití

cy.contains('Odeslat').click()
cy.contains('Přihlásit se')

S selektorem

cy.contains('button', 'Odeslat')
cy.contains('.menu-item', 'Nastavení')
cy.contains('form', 'Přihlášení')

S regex

cy.contains(/Odeslat|Submit/)
cy.contains(/^\d+$/)  // pouze čísla

Case insensitive

cy.contains('odeslat', { matchCase: false })

Poznámky

Hledání textu

cy.contains() hledá v celém textovém obsahu elementu včetně všech potomků. Text může být rozdělen mezi více elementů.

Case sensitivity

Výchozí je case-sensitive hledání. Pro case-insensitive použijte { matchCase: false }.

První nalezený element

Vrací první element, který obsahuje zadaný text. Pokud potřebujete konkrétní element, použijte selektor.

Performance

cy.contains() může být pomalejší než cy.get() s přesným selektorem, protože musí prohledat textový obsah elementů.

Command Log

Příkaz je zobrazen v Command Log s informacemi o nalezeném textu a elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
