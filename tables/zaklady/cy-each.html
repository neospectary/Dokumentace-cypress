cy.each()

Iterace přes kolekci elementů. Prochází každý element v kolekci a provádí akce pomocí callback funkce.

Syntaxe

.each(callbackFn)
.each(options, callbackFn)

Použití

✅ Správné použití

cy.get('li').each(($li) => {                // Iterace přes elementy
  cy.wrap($li).should('be.visible')
})
cy.get('tr').each(($tr, index) => {         // S indexem
  if (index > 0) {
    cy.wrap($tr).find('td').first()
  }
})

❌ Nesprávné použití

cy.each(() => {})                            // Chyba, nelze řetězit z 'cy'
cy.window().each(() => {})                   // Chyba, window není kolekce

Argumenty

callbackFn (Function)

Callback funkce, která je volána pro každý element v kolekci. Dostává jQuery element a index jako argumenty.

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s původní kolekcí elementů. Lze řetězit další příkazy.

Příklady

Základní iterace

cy.get('li').each(($li) => {
  cy.wrap($li).should('be.visible')
})

S indexem

cy.get('tr').each(($tr, index) => {
  if (index > 0) {  // přeskočit hlavičku
    cy.wrap($tr).find('td').first().should('contain', 'text')
  }
})

Ověření všech elementů

cy.get('.item').each(($item) => {
  cy.wrap($item)
    .should('be.visible')
    .and('contain.text', 'required')
})

S interakcí

cy.get('button').each(($btn) => {
  cy.wrap($btn).click()
  cy.get('.modal').should('be.visible')
  cy.get('.close').click()
})

Poznámky

Callback funkce

Callback dostává jQuery element jako první argument a index jako druhý argument. Pro práci s elementem použijte cy.wrap().

cy.wrap()

Pro práci s elementem uvnitř callbacku použijte cy.wrap($element), aby se element dostal zpět do Cypress chainu.

Nepoužívejte return

Nepoužívejte return uvnitř callbacku. Každá iterace je samostatný Cypress command.

Synchronní operace

Každá iterace je samostatný Cypress command a je provedena synchronně v rámci Cypress queue. Nepokoušejte se o asynchronní operace.

Command Log

Příkaz je zobrazen v Command Log. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
