cy.env()

Bezpečné čtení proměnných prostředí (environment variables) nastavených v Cypress konfiguraci, souboru cypress.env.json nebo přes CYPRESS_* proměnné systému. Na rozdíl od Cypress.env() vrací pouze explicitně vyžádané proměnné — citlivá data tak nejsou zbytečně vystavena.

Syntaxe

cy.env(keys)
cy.env(keys, options)

Argumenty

keys (String[])

Pole názvů proměnných, které chceš načíst. Pokud proměnná není nastavena, vrátí se pro ni undefined. Názvy jsou case-sensitive — musí přesně odpovídat konfiguraci.

options (Object)

  • log (Boolean, default: true) — Zobrazí příkaz v Command Log. Hodnoty proměnných se do logu nikdy nezapisují, jen jejich názvy.
  • timeout (Number, default: 4000) — Čas v ms, po který příkaz čeká, než vyprší.

Co vrací (Yields)

Vrací Chainable s objektem obsahujícím vyžádané proměnné a jejich hodnoty. Nedefinované proměnné mají hodnotu undefined. 

cy.env(['apiUrl', 'apiKey']).then((env) => {
  // env = { apiUrl: 'https://api.example.com', apiKey: 'secret-key-123' }
})

Nastavení proměnných

V cypress.config.ts

import { defineConfig } from 'cypress'

export default defineConfig({
  e2e: {
    baseUrl: 'http://localhost:4200',
  },
  env: {
    apiUrl: 'https://api.example.com',
    apiKey: 'secret-key-123',
    timeout: 5000,
  },
})

V souboru cypress.env.json (gitignore!)

{
  "apiKey": "secret-key-123",
  "dbPassword": "super-secret"
}

Přes systémové proměnné (CYPRESS_ prefix)

CYPRESS_apiKey=secret-key-123 cypress run
CYPRESS_apiUrl=https://api.example.com cypress run

Použití

✅ Správné použití

// Načtení jedné proměnné
cy.env(['apiUrl']).then(({ apiUrl }) => {
  cy.visit(apiUrl)
})

// Načtení více proměnných najednou
cy.env(['apiUrl', 'apiKey', 'timeout']).then(({ apiUrl, apiKey, timeout }) => {
  cy.request({
    url: `${apiUrl}/users`,
    headers: { Authorization: `Bearer ${apiKey}` },
    timeout: timeout || 5000,
  })
})

❌ Nesprávné použití

// Chyba — cy.env() je read-only, nelze nastavovat hodnoty
cy.env('apiKey', 'new-value')           // Nelze — pro zápis použij Cypress.env()

// Chyba — argument musí být pole, ne string
cy.env('apiUrl').then(...)              // Nesprávný typ argumentu

Příklady

Přihlášení přes API s tajným klíčem

it('přihlásí uživatele přes API', () => {
  cy.env(['apiUrl', 'apiKey']).then(({ apiUrl, apiKey }) => {
    cy.request({
      method: 'POST',
      url: `${apiUrl}/auth/login`,
      headers: { Authorization: `Bearer ${apiKey}` },
      body: { username: 'testuser', password: 'testpass' },
    }).then((response) => {
      expect(response.status).to.eq(200)
    })
  })
})

Vlastní command s cy.env()

// cypress/support/commands.ts
Cypress.Commands.add('apiRequest', (endpoint, options = {}) => {
  cy.env(['apiUrl', 'apiKey']).then(({ apiUrl, apiKey }) => {
    cy.request({
      url: `${apiUrl}${endpoint}`,
      headers: {
        Authorization: `Bearer ${apiKey}`,
        ...options.headers,
      },
      ...options,
    })
  })
})

// Použití v testu
cy.apiRequest('/users').its('body').should('have.length.gt', 0)

Ošetření nepovinných proměnných

cy.env(['required', 'optional']).then(({ required, optional }) => {
  if (required === undefined) {
    throw new Error('Proměnná "required" musí být nastavena v cypress.env.json')
  }
  if (optional) {
    cy.log(`Volitelná hodnota: ${optional}`)
  }
})

Přizpůsobení testu podle prostředí

cy.env(['environment']).then(({ environment }) => {
  if (environment === 'staging') {
    cy.get('[data-cy="env-badge"]').should('have.text', 'STAGING')
  } else {
    cy.get('[data-cy="env-badge"]').should('not.exist')
  }
})

Nastavení základní URL dynamicky

beforeEach(() => {
  cy.env(['apiUrl']).then(({ apiUrl }) => {
    Cypress.config('baseUrl', apiUrl)
  })
})

Poznámky

Read-only příkaz

cy.env() je pouze pro čtení — runtime změny nejsou možné. Pokud potřebuješ hodnotu za běhu testu přepsat, použij starší Cypress.env('key', value).

Hodnoty se nezapisují do logu

V Command Log se zobrazují pouze názvy vyžádaných proměnných, nikdy jejich hodnoty. Citlivá data tak nejsou viditelná ve výstupu testů ani ve screenshotech.

Soubor cypress.env.json patří do .gitignore

Soubor cypress.env.json slouží pro lokální tajná data. Vždy ho přidej do .gitignore — nesmí být commitován do repozitáře.

Vypnutí starého Cypress.env() API

Pokud chceš vynutit používání nového cy.env() a zakázat přímý přístup přes Cypress.env(), nastav v konfiguraci: 

// cypress.config.ts
export default defineConfig({
  allowCypressEnv: false,
})

Command Log

Příkaz je zobrazen v Command Log s názvy vyžádaných proměnných. Hodnoty se z bezpečnostních důvodů nikdy nezobrazují — ani při kliknutí na příkaz v logu.
