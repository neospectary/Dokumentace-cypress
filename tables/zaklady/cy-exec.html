cy.exec()

Spuštění shell příkazu. Umožňuje spustit systémový příkaz v Node.js prostředí. Užitečné pro systémové operace, práci s databází nebo spuštění shell skriptů.

Syntaxe

cy.exec(command)
cy.exec(command, options)

Použití

✅ Správné použití

cy.exec('npm run build')                  // Shell příkaz
cy.exec('ls -la')                         // List souborů
cy.exec('echo "Hello"')                   // Echo příkaz

❌ Nesprávné použití

cy.exec()                                  // Chyba, chybí command
cy.get('.btn').exec('ls')                 // Chyba, nelze řetězit

Argumenty

command (String)

Shell příkaz k provedení. Může být jakýkoli systémový příkaz dostupný v shellu.

options (Object)

  • timeout (Number) - Čas čekání na dokončení příkazu
  • failOnNonZeroExit (Boolean, default: true) - Zda selhat při non-zero exit kódu
  • env (Object) - Environment proměnné
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s výsledkem příkazu obsahujícím code (exit kód), stdout (výstup), stderr (chybový výstup). Lze použít s .then().

Příklady

Základní použití

cy.exec('npm run build')
cy.exec('ls -la')

S výsledkem

cy.exec('echo "Hello"').then((result) => {
  expect(result.code).to.eq(0)
  expect(result.stdout).to.include('Hello')
})

S failOnNonZeroExit

cy.exec('command-that-might-fail', { failOnNonZeroExit: false })

Poznámky

Node.js prostředí

Příkazy se spouštějí v Node.js prostředí (mimo prohlížeč), takže můžete používat systémové příkazy dostupné v shellu.

Bezpečnost

cy.exec() může být bezpečnostní riziko, protože spouští systémové příkazy. Používejte opatrně a jen pro důvěryhodné příkazy.

Exit kód

Výchozí je failOnNonZeroExit: true, což znamená, že test selže, pokud příkaz vrátí non-zero exit kód. Pro příkazy, které mohou selhat, nastavte failOnNonZeroExit: false.

Command Log

Příkaz je zobrazen v Command Log s informacemi o spuštěném příkazu a výsledku. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
