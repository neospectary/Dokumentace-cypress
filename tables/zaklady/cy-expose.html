Cypress.expose()

Synchronní přístup k veřejným konfiguračním hodnotám v testech — feature flagy, verze API, nastavení pluginů a jiná nečitelná data, která potřebuješ sdílet napříč testy. Není to Cypress příkaz v chainu, ale globální metoda dostupná kdykoliv. Přidáno v Cypress 15.10.0.

Syntaxe

Cypress.expose()               // Vrátí všechny hodnoty jako objekt
Cypress.expose(key)            // Vrátí hodnotu pro daný klíč
Cypress.expose(key, value)     // Nastaví jednu hodnotu
Cypress.expose(object)         // Nastaví více hodnot najednou

Argumenty

key (String)

Název konfigurační proměnné, kterou chceš číst nebo nastavit.

value (Any)

Serializovatelná hodnota — string, number, boolean, objekt, pole. Nesmí obsahovat citlivá data (hesla, tokeny, API klíče).

object (Object)

Více klíč–hodnota párů, které se sloučí s existujícími hodnotami.

Nastavení hodnot

V konfiguračním souboru (cypress.config.ts)

import { defineConfig } from 'cypress'

export default defineConfig({
  e2e: {
    baseUrl: 'http://localhost:4200',
  },
  expose: {
    pluginConfig: 'production',
    featureFlag: true,
    apiVersion: 2,
  },
})

Přes CLI při spuštění

cypress run --expose pluginConfig=staging,featureFlag=false
cypress run -x apiVersion=3,betaMode=true

Použití v testech

Čtení všech hodnot

const config = Cypress.expose()
cy.log(JSON.stringify(config))   // { pluginConfig: 'production', featureFlag: true, apiVersion: 2 }

Čtení jedné hodnoty

const flag = Cypress.expose('featureFlag')   // true
const version = Cypress.expose('apiVersion') // 2

Nastavení jedné hodnoty za běhu

Cypress.expose('featureFlag', false)
Cypress.expose('environment', 'staging')

Nastavení více hodnot najednou

Cypress.expose({
  featureFlag: false,
  apiVersion: 3,
  betaMode: true,
})

Příklady

Podmíněný test podle feature flagu

it('zobrazí beta sekci pouze, když je flag zapnutý', () => {
  if (Cypress.expose('betaMode')) {
    cy.get('[data-cy="beta-section"]').should('be.visible')
  } else {
    cy.get('[data-cy="beta-section"]').should('not.exist')
  }
})

Přizpůsobení URL podle verze API

it('volá správný API endpoint', () => {
  const version = Cypress.expose('apiVersion')
  cy.intercept('GET', `/api/v${version}/users`).as('getUsers')
  cy.visit('/users')
  cy.wait('@getUsers')
})

Nastavení hodnoty v beforeEach

describe('testy v staging prostředí', () => {
  beforeEach(() => {
    Cypress.expose('environment', 'staging')
  })

  it('zobrazí staging banner', () => {
    cy.visit('/')
    cy.get('[data-cy="env-badge"]').should('have.text', 'staging')
  })
})

Sdílení konfigurace pluginu

// cypress.config.ts
expose: { reportingEnabled: true, reportUrl: 'https://reports.example.com' }

// V testu
afterEach(() => {
  if (Cypress.expose('reportingEnabled')) {
    const url = Cypress.expose('reportUrl')
    cy.task('sendReport', { url, title: Cypress.currentTest.title })
  }
})

Poznámky

⚠️ Bezpečnostní upozornění

Hodnoty nastavené přes Cypress.expose() jsou dostupné v kontextu prohlížeče — včetně kódu aplikace, třetích stran a rozšíření prohlížeče. Nikdy sem nedávej citlivá data jako API klíče, hesla nebo tokeny. Pro citlivé hodnoty použij Cypress.env().

Platnost hodnot

Hodnoty přetrvávají pouze po dobu, kdy je prohlížeč otevřený. Změny provedené za běhu testu platí jen pro aktuální spec soubor — do Node.js kontextu (setupNodeEvents) se nepropagují.

Dostupnost od verze

Cypress.expose() bylo přidáno v Cypress 15.10.0. Ve starších verzích tato metoda neexistuje.
