.find()

Hledání potomků uvnitř aktuálního elementu. Na rozdíl od cy.get() hledá jen uvnitř vybraného elementu (ne v celém dokumentu).

Syntaxe

.find(selector)
.find(selector, options)

Použití

✅ Správné použití

cy.get('.container').find('.item')            // Hledání uvnitř container
cy.get('form').find('input[name="email"]')    // Hledání v formu
cy.get('.parent').find('.child')              // Hledání potomka

❌ Nesprávné použití

cy.find('.item')                               // Chyba, nelze řetězit z 'cy'
cy.window().find('.item')                      // Chyba, window není DOM element

Argumenty

selector (String)

CSS selektor pro hledání potomků. Hledá jen uvnitř aktuálního elementu (ne v celém dokumentu).

options (Object)

  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s nalezenými potomky. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('.container').find('.item')
cy.get('form').find('input[name="email"]')

Rozdíl mezi get() a find()

// ❌ ŠPATNĚ - get hledá všude
cy.get('.parent').get('.child')

// ✅ SPRÁVNĚ - find hledá jen uvnitř parent
cy.get('.parent').find('.child')

S více úrovněmi

cy.get('.table')
  .find('tbody')
  .find('tr')
  .find('td')
  .first()

V každém elementu

cy.get('.item').each(($item) => {
  cy.wrap($item).find('.button').click()
})

Poznámky

Scope hledání

.find() hledá jen uvnitř aktuálního elementu, ne v celém dokumentu. Na rozdíl od cy.get(), který hledá od root elementu (celý dokument).

Automatické čekání

.find() automaticky čeká na existenci potomků (retry mechanismus). Potomci nemusí být okamžitě přítomni v DOM.

Best practices

Používejte .find() pro hledání uvnitř elementu a cy.get() pro hledání od root elementu. Tím zúžíte scope hledání a testy budou rychlejší a stabilnější.

Command Log

Příkaz je zobrazen v Command Log s informacemi o nalezených potomcích. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
