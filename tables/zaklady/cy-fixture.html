cy.fixture()

Načtení testovacích dat ze souboru. Umožňuje načíst JSON, text nebo binární data z fixtures složky pro použití v testech.

Syntaxe

cy.fixture(filePath)
cy.fixture(filePath, encoding)
cy.fixture(filePath, options)

Použití

✅ Správné použití

cy.fixture('users.json').then((users) => {     // JSON soubor
  cy.log(users[0].name)
})
cy.fixture('image.jpg', 'base64')               // Binární soubor
cy.fixture('data.json').as('testData')          // S aliasem

❌ Nesprávné použití

cy.fixture()                                     // Chyba, chybí filePath
cy.get('.btn').fixture('data.json')             // Chyba, nelze řetězit

Argumenty

filePath (String)

Cesta k souboru v cypress/fixtures/ složce. Může být relativní cesta nebo jen název souboru.

encoding (String)

Encoding pro binární soubory: 'utf8' (výchozí), 'base64', 'hex'.

options (Object)

  • encoding (String) - Encoding pro soubor
  • timeout (Number) - Čas čekání na načtení
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s načtenými daty. Pro JSON automaticky parsuje data. Lze použít s .then() pro přístup k datům.

Příklady

Načtení JSON

cy.fixture('users.json').then((users) => {
  cy.log(users[0].name)
})

S intercept

cy.fixture('users.json').then((users) => {
  cy.intercept('GET', '/api/users', users)
})

Base64 encoding

cy.fixture('image.jpg', 'base64').then((fileContent) => {
  // použít pro upload
})

S aliasem

cy.fixture('data.json').as('testData')
cy.get('@testData').then((data) => {
  // práce s daty
})

Poznámky

Složka fixtures

Soubory musí být v cypress/fixtures/ složce. Cypress automaticky hledá soubory v této složce.

Typy souborů

Cypress podporuje JSON (automaticky parsuje), text, obrázky, binární soubory. Pro JSON vrací přímo objekt, pro ostatní vrací obsah jako string.

Použití s intercept

cy.fixture() je často používán s cy.intercept() pro mockování API response pomocí fixture dat.

Command Log

Příkaz je zobrazen v Command Log s informacemi o načteném souboru. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
