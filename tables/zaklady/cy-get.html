cy.get()

Výběr jednoho nebo více DOM elementů pomocí CSS selektorů nebo aliasů. Základní příkaz pro práci s elementy na stránce.

Syntaxe

cy.get(selector)
cy.get(alias)
cy.get(selector, options)

Použití

✅ Správné použití

cy.get('.btn')                      // CSS selektor
cy.get('#submit-button')            // ID selektor
cy.get('[data-cy="login"]')         // Data atribut
cy.get('@aliasName')                // Alias
cy.get('button', { timeout: 10000 }) // S options

❌ Nesprávné použití

cy.get()                             // Chyba, chybí selector
cy.window().get('.btn')              // Chyba, cy.get() nelze řetězit

Argumenty

selector (String)

CSS selektor, ID, třída, data atribut nebo alias (s @). Cypress podporuje všechny standardní CSS selektory.

alias (String)

Název aliasu s @ prefixem (např. '@todoList'). Alias musí být dříve vytvořen pomocí .as().

options (Object)

  • timeout (Number, default: defaultCommandTimeout) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log
  • includeShadowDom (Boolean, default: false) - Zahrne Shadow DOM

Co vrací (Yields)

Vrací Chainable s nalezenými DOM elementy. Lze řetězit další příkazy (např. .click(), .type(), .should()). 

cy.get('button')      // vrací všechny tlačítka
  .first()            // vrací první
  .click()            // klikne na něj

Příklady

Základní výběr

cy.get('.btn-primary')
cy.get('#submit-button')
cy.get('[data-cy="login"]')
cy.get('button.btn-primary')

Použití aliasu

cy.get('ul#todos').as('todoList')
cy.get('@todoList').find('li')

S vlastním timeoutem

cy.get('.slow-element', { timeout: 10000 })

Složitější selektory

cy.get('form input[type="email"]')
cy.get('.menu > li:first-child')
cy.get('button:contains("Submit")')

Poznámky

Automatické čekání

cy.get() automaticky čeká na existenci elementu (retry mechanismus). Element nemusí být okamžitě přítomen v DOM.

Scope hledání

cy.get() vždy hledá od root elementu (celý dokument). Pro hledání uvnitř elementu použijte .find() nebo cy.within().

Best practices

  • Preferujte data atributy (data-cy, data-test) před CSS třídami
  • Používejte specifické selektory pro stabilní testy
  • Vyhýbejte se selektorům závislým na pozici (např. :nth-child(3))

Command Log

Příkaz je zobrazen v Command Log s informacemi o nalezených elementech. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
