cy.go()

Navigace v historii prohlížeče. Umožňuje jít dopředu nebo zpět v historii. Užitečné pro testování tlačítek Zpět/Dopředu nebo ověření chování při navigaci.

Syntaxe

cy.go(direction)
cy.go(direction, options)

Použití

✅ Správné použití

cy.go('back')                           // Zpět v historii
cy.go('forward')                        // Dopředu v historii
cy.go(-1)                               // Zpět (číslo)
cy.go(1)                                // Dopředu (číslo)

❌ Nesprávné použití

cy.go()                                  // Chyba, chybí direction
cy.get('.btn').go('back')               // Chyba, nelze řetězit

Argumenty

direction (String|Number)

Směr navigace: 'back' nebo -1 (zpět), 'forward' nebo 1 (dopředu). Lze použít i jiná čísla pro více kroků v historii.

options (Object)

  • timeout (Number) - Čas čekání na načtení stránky
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable. Po dokončení je navigace dokončena a stránka je načtená.

Příklady

Zpět

cy.go('back')
cy.go(-1)

Dopředu

cy.go('forward')
cy.go(1)

Vícenásobná navigace

cy.go(-2)  // 2 kroky zpět
cy.go(2)   // 2 kroky dopředu

Poznámky

Historie

cy.go() funguje jen pokud existuje historie. Pokud se pokusíte jít zpět, když není historie, test selže.

Čekání na načtení

cy.go() automaticky čeká na načtení stránky po navigaci (pageLoadTimeout). Stránka musí být plně načtená před pokračováním.

Command Log

Příkaz je zobrazen v Command Log s informacemi o navigaci. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
