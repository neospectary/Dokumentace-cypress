cy.intercept()

Mockování, sledování a modifikace HTTP requestů. Umožňuje zachytit, mockovat nebo modifikovat API volání během testu.

Syntaxe

cy.intercept(method, url, routeHandler)
cy.intercept(method, url, response)
cy.intercept(url, response)
cy.intercept(routeMatcher, routeHandler)

Použití

✅ Správné použití

cy.intercept('GET', '/api/users', { fixture: 'users.json' })  // Mock response
cy.intercept('POST', '/api/login').as('login')                 // Sledování
cy.intercept('GET', '/api/**', { statusCode: 500 })            // Simulace chyby
cy.intercept('/api/users', { body: [] })                       // Bez metody

❌ Nesprávné použití

cy.visit('/page')
cy.intercept('GET', '/api/users')                              // Chyba, musí být před visit
cy.get('.btn').intercept('GET', '/api/users')                  // Chyba, nelze řetězit

Argumenty

method (String)

HTTP metoda (GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS). Volitelné - pokud není zadána, zachytí všechny metody.

url (String|RegExp|RouteMatcher)

URL pattern, regex nebo RouteMatcher objekt. Podporuje wildcards: ** (libovolné znaky), * (jeden segment).

response (Object|String|Fixture)

Mock response. Může být objekt s statusCode, body, headers, nebo string, nebo fixture pomocí { fixture: 'filename' }.

routeHandler (Function)

Callback funkce pro dynamickou response. Dostává request objekt a může modifikovat response.

Co vrací (Yields)

Vrací Chainable. Lze použít s .as() pro vytvoření aliasu pro použití s cy.wait().

Příklady

Základní mock

cy.intercept('GET', '/api/users', {
  statusCode: 200,
  body: [{ id: 1, name: 'John' }]
})

S aliasem

cy.intercept('GET', '/api/users').as('getUsers')
cy.visit('/users')
cy.wait('@getUsers')

Simulace chyby

cy.intercept('POST', '/api/login', {
  statusCode: 401,
  body: { error: 'Unauthorized' }
})

S fixture

cy.intercept('GET', '/api/users', { fixture: 'users.json' })

Dynamická response

cy.intercept('GET', '/api/users', (req) => {
  req.reply((res) => {
    res.body = res.body.filter(u => u.active)
  })
})

Wildcards

cy.intercept('GET', '/api/**', { statusCode: 200 })
cy.intercept('GET', '/api/users/*/posts', { body: [] })

Poznámky

Pořadí

cy.intercept() musí být definováno před cy.visit() nebo akcí, která spustí request. Intercepty jsou aktivní až do konce testu.

Wildcards

Cypress podporuje wildcards: ** (libovolné znaky), * (jeden URL segment). Lze také použít regex pro URL matching.

Fixture data

Pro použití fixture dat použijte { fixture: 'filename' }. Soubory musí být v cypress/fixtures/ adresáři.

Route handler

Route handler funkce dostává request objekt a může modifikovat response, přidat delay, nebo vrátit vlastní response.

Command Log

Intercepty jsou zobrazeny v Command Log. Kliknutím na intercept v logu uvidíte detaily requestu a response. Intercepty jsou také viditelné v Network tab.
