cy.invoke()

Volání jQuery metod na elementu. Umožňuje zavolat jQuery funkce jako .show(), .hide(), .val(), .css(), atd. Cypress používá jQuery pod kapotou.

Syntaxe

.invoke(functionName)
.invoke(functionName, ...args)

Použití

✅ Správné použití

cy.get('input').invoke('val')                    // Získání hodnoty
cy.get('div').invoke('show')                     // Zobrazení elementu
cy.get('input').invoke('val', 'new value')       // Nastavení hodnoty
cy.get('div').invoke('css', 'color', 'red')      // CSS vlastnost

❌ Nesprávné použití

cy.invoke('val')                                  // Chyba, nelze řetězit z 'cy'
cy.window().invoke('val')                         // Chyba, window není DOM element

Argumenty

functionName (String)

Název jQuery metody k volání (např. 'val', 'show', 'hide', 'css', 'attr', atd.).

args (Any)

Argumenty pro jQuery metodu. Počet argumentů závisí na konkrétní metodě.

Co vrací (Yields)

Vrací Chainable s návratovou hodnotou jQuery metody. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('input').invoke('val')
cy.get('div').invoke('show')
cy.get('div').invoke('hide')

S argumenty

cy.get('input').invoke('val', 'new value')
cy.get('div').invoke('css', 'color', 'red')
cy.get('a').invoke('attr', 'href')

Získání hodnoty

cy.get('input').invoke('val').then((value) => {
  cy.log(`Hodnota: ${value}`)
})

Poznámky

jQuery metody

.invoke() funguje jen s jQuery metodami. Cypress používá jQuery pod kapotou, takže všechny jQuery metody jsou dostupné.

Kdy použít

.invoke() je užitečné, když potřebujete použít jQuery API, které není přímo dostupné v Cypress. Pro většinu případů používejte nativní Cypress příkazy.

Command Log

Příkaz je zobrazen v Command Log s informacemi o volané metodě. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
