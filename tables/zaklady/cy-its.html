cy.its()

Získání property z objektu. Umožňuje přístup k vlastnostem objektu nebo pole pomocí dot notation. Užitečné pro práci s API response nebo vnořenými objekty.

Syntaxe

.its(propertyName)
.its(propertyName, options)

Použití

✅ Správné použití

cy.wrap({ name: 'John' }).its('name')              // Jednoduchá property
cy.wrap({ user: { name: 'John' } }).its('user.name') // Vnořená property
cy.request('/api/user').its('body').its('data')     // Z response

❌ Nesprávné použití

cy.its('name')                                       // Chyba, nelze řetězit z 'cy'
cy.window().its('name')                              // Chyba, window nemá property 'name'

Argumenty

propertyName (String)

Název property nebo cesta k property pomocí dot notation (např. 'name', 'body.data.id', 'user.name').

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s hodnotou property. Lze řetězit další příkazy nebo použít více .its() za sebou pro přístup k vnořeným properties.

Příklady

Základní použití

cy.wrap({ name: 'John', age: 30 })
  .its('name')
  .should('eq', 'John')

Vnořené property

cy.wrap({ user: { name: 'John' } })
  .its('user.name')
  .should('eq', 'John')

S response

cy.request('GET', '/api/user')
  .its('body')
  .its('data')
  .its('name')
  .should('eq', 'John')

Vnořené property (jedna cesta)

cy.request('GET', '/api/user')
  .its('body.data.name')
  .should('eq', 'John')

Poznámky

Dot notation

.its() podporuje dot notation pro přístup k vnořeným properties. Můžete použít buď řetězení více .its() nebo jednu cestu s dot notation.

Řetězení

Lze řetězit více .its() za sebou pro přístup k vnořeným properties. Každé .its() vrací hodnotu property.

API response

.its() je často používán s cy.request() pro přístup k částem API response (např. .its('body'), .its('body.data')).

Command Log

Příkaz je zobrazen v Command Log s informacemi o přístupu k property. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
