cy.location()

Ověření URL a dalších vlastností location objektu. Umožňuje kontrolovat pathname, hash, search, host, href a další vlastnosti aktuální URL. Užitečné pro přesné ověření navigace.

Syntaxe

cy.location()
cy.location(key)
cy.location(key, options)

Použití

✅ Správné použití

cy.location('pathname').should('eq', '/dashboard')  // Pathname
cy.location('hash').should('eq', '#section1')       // Hash
cy.location('search').should('include', 'id=123')   // Query parametry
cy.location('href').should('include', 'dashboard')  // Celá URL

❌ Nesprávné použití

cy.get('.btn').location('pathname')                  // Chyba, nelze řetězit
cy.location()                                        // Chyba, bez key vrací objekt (použijte cy.location('href'))

Argumenty

key (String)

Název vlastnosti location objektu: 'pathname', 'hash', 'search', 'host', 'href', 'port', 'protocol', atd.

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s hodnotou location vlastnosti. Lze použít s .should() pro assertions.

Příklady

Ověření pathname

cy.location('pathname').should('eq', '/dashboard')
cy.location('pathname').should('include', '/settings')

// Po kliknutí na link
cy.dataCy('settings-link').click()
cy.location('pathname').should('eq', '/settings/user')

Ověření celé URL (href)

cy.location('href').should('include', 'dashboard')
cy.location('href').should('eq', 'http://localhost:4200/dashboard')

Ověření hash

cy.location('hash').should('eq', '#section1')
cy.location('hash').should('include', 'section')

Ověření query parametrů

cy.location('search').should('include', 'id=123')
cy.location('search').should('eq', '?id=123&page=1')

Praktický příklad

it('naviguje na správnou stránku', () => {
  cy.dataCy('profile-menu-content').within(() => {
    cy.contains('se-button', 'Nastavení účtu').click()
  })
  
  cy.location('pathname').should('eq', '/settings/user')
  cy.get('h1').should('contain.text', 'Uživatelské nastavení')
})

Poznámky

Preferujte cy.location() před cy.url()

cy.location('pathname') je přesnější než cy.url() pro ověření konkrétní části URL. cy.url() vrací celou URL jako string, zatímco cy.location() umožňuje přístup k jednotlivým částem.

Navigace

cy.location() je užitečné pro ověření navigace po akcích (kliknutí, submit, atd.). Automaticky čeká, dokud není hodnota dostupná.

Dostupné vlastnosti

Cypress podporuje všechny vlastnosti location objektu: pathname, hash, search, host, href, port, protocol, atd.

Command Log

Příkaz je zobrazen v Command Log s informacemi o location vlastnosti. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
