cy.log()

Vypisování zpráv do Cypress Command Log. Užitečné pro debugování a lepší čitelnost testů. Zprávy jsou viditelné v Cypress Test Runner v Command Log.

Syntaxe

cy.log(message)
cy.log(message, ...args)

Použití

✅ Správné použití

cy.log('Začínám test')                    // Jednoduchá zpráva
cy.log('Hodnota:', value)                 // S hodnotou
cy.log(`Název: ${name}`)                  // Template literal

❌ Nesprávné použití

cy.get('.btn').log('text')                // Chyba, nelze řetězit
cy.log()                                  // Chyba, chybí message

Argumenty

message (String)

Text zprávy k zobrazení v Command Log. Může obsahovat template literals pro dynamické hodnoty.

args (Any)

Další argumenty k zobrazení. Může být jakákoli hodnota - string, number, object, atd.

Co vrací (Yields)

Vrací Chainable. Zpráva je zobrazena v Command Log v Cypress Test Runner.

Příklady

Základní použití

cy.log('Začínám test')
cy.log('Krok 1: Vyhledávám feed')
cy.log('Test dokončen')

S hodnotami proměnných

const feedName = 'Test Feed'
cy.log(`Název feedu: ${feedName}`)

const currentTariff = 'monthly'
cy.log(`Current active tariff: ${currentTariff}`)

Označení kroků

cy.log('1. Vyhledávám feed')
// ... test kód ...
cy.log('2. Otevírám párování')
// ... test kód ...

Debugging hodnot

cy.wait('@createFeed').then((interception) => {
  cy.log(`Status kód: ${interception.response.statusCode}`)
  cy.log('Response body:', interception.response.body)
})

Poznámky

Command Log

Zprávy jsou viditelné v Cypress Command Log v Cypress Test Runner. Užitečné pro lepší čitelnost testů a debugování.

Kdy použít

cy.log() je užitečné pro označení kroků v komplexních testech nebo pro vypisování hodnot proměnných. Nepoužívejte místo skutečných assertions.

Template literals

Pro dynamické hodnoty použijte template literals (backticks): cy.log(`Hodnota: ${value}`).

Command Log

Příkaz je zobrazen v Command Log s zprávou. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
