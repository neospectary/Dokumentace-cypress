cy.readFile()

Čtení souboru z filesystému. Načte obsah souboru z projektu. Užitečné pro čtení konfiguračních souborů nebo ověření obsahu souboru.

Syntaxe

cy.readFile(filePath)
cy.readFile(filePath, encoding)
cy.readFile(filePath, options)

Použití

✅ Správné použití

cy.readFile('cypress/fixtures/data.json')     // JSON soubor
cy.readFile('config.json', 'utf8')            // S encoding
cy.readFile('data.txt')                        // Textový soubor

❌ Nesprávné použití

cy.readFile()                                  // Chyba, chybí filePath
cy.get('.btn').readFile('file.json')          // Chyba, nelze řetězit

Argumenty

filePath (String)

Cesta k souboru. Relativní k root projektu nebo absolutní cesta.

encoding (String)

Encoding pro soubor: 'utf8' (výchozí), 'base64', 'hex'.

options (Object)

  • encoding (String) - Encoding pro soubor
  • timeout (Number) - Čas čekání na načtení
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s obsahem souboru. Pro JSON automaticky parsuje data. Lze použít s .then() pro přístup k datům.

Příklady

Základní čtení

cy.readFile('cypress/fixtures/data.json')
  .then((data) => {
    cy.log(data)
  })

JSON soubor

cy.readFile('config.json').then((config) => {
  expect(config).to.have.property('baseUrl')
})

Textový soubor

cy.readFile('data.txt', 'utf8').then((text) => {
  cy.log(text)
})

Poznámky

Cesta k souboru

Cesta je relativní k root projektu. Pro JSON soubory automaticky parsuje data do objektu.

Encoding

Výchozí encoding je 'utf8'. Pro binární soubory použijte 'base64' nebo 'hex'.

Rozdíl od cy.fixture()

cy.readFile() čte soubory z libovolné cesty v projektu, zatímco cy.fixture() čte jen z cypress/fixtures/ složky.

Command Log

Příkaz je zobrazen v Command Log s informacemi o načteném souboru. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
