cy.reload()

Obnovení (refresh) stránky. Znovu načte aktuální stránku. Užitečné pro testování chování po refresh nebo resetování stavu aplikace.

Syntaxe

cy.reload()
cy.reload(forceReload)
cy.reload(options)

Použití

✅ Správné použití

cy.reload()                             // Standardní reload
cy.reload(true)                         // Force reload (ignoruje cache)
cy.reload({ timeout: 30000 })           // S timeoutem

❌ Nesprávné použití

cy.get('.btn').reload()                  // Chyba, nelze řetězit
cy.reload('text')                        // Chyba, forceReload musí být boolean

Argumenty

forceReload (Boolean)

Pokud je true, ignoruje cache prohlížeče a načte stránku znovu ze serveru. Výchozí je false.

options (Object)

  • timeout (Number) - Čas čekání na načtení stránky
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable. Po dokončení je stránka znovu načtená a připravená pro interakci.

Příklady

Základní reload

cy.reload()

S force (ignoruje cache)

cy.reload(true)

Po akci

cy.get('button').click()
cy.reload()
cy.get('.element').should('be.visible')

Poznámky

Čekání na načtení

cy.reload() automaticky čeká na načtení stránky po reload (pageLoadTimeout). Stránka musí být plně načtená před pokračováním.

Force reload

Force reload (cy.reload(true)) ignoruje cache prohlížeče a načte stránku znovu ze serveru. Užitečné pro testování, když chcete zajistit, že se načte nejnovější verze.

Command Log

Příkaz je zobrazen v Command Log. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
