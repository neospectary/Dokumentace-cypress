cy.request()

HTTP requesty. Umožňuje provádět HTTP požadavky přímo z testu, bez prohlížeče. Requesty probíhají v Node.js prostředí.

Syntaxe

cy.request(url)
cy.request(method, url)
cy.request(method, url, body)
cy.request(options)

Použití

✅ Správné použití

cy.request('GET', '/api/users')                 // GET request
cy.request('POST', '/api/login', { body })      // POST request
cy.request({ method: 'GET', url: '/api/data' }) // S options
cy.request('https://api.example.com/data')      // Absolutní URL

❌ Nesprávné použití

cy.request()                                     // Chyba, chybí URL
cy.get('.btn').request('/api/data')             // Chyba, nelze řetězit

Argumenty

method (String)

HTTP metoda: GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS. Pokud není zadána, výchozí je GET.

url (String)

URL endpointu. Může být absolutní URL nebo relativní k baseUrl z config.

body (Object|String)

Request body. Pro POST, PUT, PATCH requesty. Může být objekt (automaticky JSON stringify) nebo string.

options (Object)

  • method (String) - HTTP metoda
  • url (String) - URL endpointu
  • body (Object|String) - Request body
  • headers (Object) - HTTP hlavičky
  • auth (Object) - HTTP authentication
  • timeout (Number) - Čas čekání na response
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s response objektem obsahujícím status, body, headers, duration. Lze použít s .then() pro přístup k response.

Příklady

GET request

cy.request('GET', '/api/users')
  .then((response) => {
    expect(response.status).to.eq(200)
    expect(response.body).to.have.length(10)
  })

POST request

cy.request('POST', '/api/login', {
  username: 'admin',
  password: 'password'
}).then((response) => {
  expect(response.status).to.eq(200)
})

S headers

cy.request({
  method: 'GET',
  url: '/api/data',
  headers: {
    'Authorization': 'Bearer token'
  }
})

Přihlášení pomocí API

cy.request('POST', '/api/login', {
  username: 'user',
  password: 'pass'
}).then((response) => {
  window.localStorage.setItem('token', response.body.token)
})

Poznámky

Node.js prostředí

Requesty probíhají mimo prohlížeč v Node.js prostředí. Jsou rychlejší než UI interakce a užitečné pro setup a cleanup testů.

Automatické cookies

Cookies z prohlížeče nejsou automaticky přidány k requestům. Pokud potřebujete cookies, musíte je přidat ručně do headers.

Base URL

Relativní URL se kombinují s baseUrl z Cypress config. Pokud není baseUrl nastaven, musíte použít absolutní URL.

Command Log

Příkaz je zobrazen v Command Log s informacemi o requestu a response. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
