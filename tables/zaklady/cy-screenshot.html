cy.screenshot()

Pořízení screenshotu. Uloží obrázek aktuálního stavu stránky nebo elementu. Užitečné pro debugování, vizuální testování nebo dokumentaci.

Syntaxe

cy.screenshot()
cy.screenshot(name)
cy.screenshot(name, options)

Použití

✅ Správné použití

cy.screenshot()                         // Screenshot celé stránky
cy.screenshot('login-page')            // S názvem
cy.get('.modal').screenshot('modal')   // Screenshot elementu

❌ Nesprávné použití

cy.get('.btn').screenshot()             // Chyba, nelze řetězit
cy.window().screenshot()                // Chyba, window není DOM element

Argumenty

name (String)

Název souboru pro screenshot. Pokud není zadán, použije se automatický název.

options (Object)

  • clip (Object) - Oříznutí screenshotu (x, y, width, height)
  • capture (String) - Typ screenshotu ('fullPage', 'viewport', 'runner')
  • overwrite (Boolean) - Přepsat existující soubor
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable. Screenshot je uložen v cypress/screenshots/ adresáři.

Příklady

Základní screenshot

cy.screenshot()

S názvem

cy.screenshot('login-page')

Elementu

cy.get('.modal').screenshot('modal')

Full page

cy.screenshot('full-page', { capture: 'fullPage' })

Poznámky

Ukládání

Screenshots jsou uloženy v cypress/screenshots/ adresáři. Struktura adresáře odpovídá struktuře test souborů.

Automatické screenshoty

Cypress automaticky pořizuje screenshoty při selhání testu. Můžete také pořídit screenshoty manuálně pomocí cy.screenshot().

Element screenshoty

Pro screenshot konkrétního elementu použijte .screenshot() na elementu (např. cy.get('.modal').screenshot('modal')).

Command Log

Příkaz je zobrazen v Command Log s informacemi o screenshotu. Kliknutím na příkaz v logu můžete zobrazit screenshot.
