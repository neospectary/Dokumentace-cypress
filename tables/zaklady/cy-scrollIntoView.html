.scrollIntoView()

Scrollování elementu do viditelné oblasti. Posune element tak, aby byl viditelný v viewportu. Užitečné pro interakci s elementy, které jsou mimo viditelnou oblast.

Syntaxe

.scrollIntoView()
.scrollIntoView(options)

Použití

✅ Správné použití

cy.get('.footer').scrollIntoView()       // Scroll na element
cy.get('.element').scrollIntoView({      // S options
  duration: 500
})

❌ Nesprávné použití

cy.scrollIntoView()                       // Chyba, nelze řetězit z 'cy'
cy.window().scrollIntoView()              // Chyba, window není DOM element

Argumenty

options (Object)

  • duration (Number) - Délka animace scrollování v milisekundách
  • easing (String) - Typ animace ('swing', 'linear')
  • offset (Object) - Offset pro pozici elementu
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s elementem. Lze řetězit další příkazy.

Příklady

Základní scroll

cy.get('.footer').scrollIntoView()

S options

cy.get('.element').scrollIntoView({
  duration: 500,
  easing: 'swing'
})

Před interakcí

cy.get('.button').scrollIntoView().click()

Poznámky

Automatické scrollování

Cypress automaticky scrolluje elementy do viditelné oblasti před interakcí (např. .click(), .type()). .scrollIntoView() použijte, když potřebujete explicitně zajistit viditelnost.

Kdy použít

.scrollIntoView() je užitečné, když potřebujete zajistit, že element je viditelný před interakcí, nebo když chcete testovat scrollování.

Command Log

Příkaz je zobrazen v Command Log s informacemi o scrollování. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
