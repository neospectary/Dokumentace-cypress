cy.select()

Výběr hodnoty z HTML select (dropdown) elementu. Vybere option podle hodnoty, textu nebo indexu.

Syntaxe

.select(value)
.select(values)
.select(value, options)

Použití

✅ Správné použití

cy.get('select').select('cz')                    // Podle hodnoty
cy.get('select').select('Česká republika')       // Podle textu
cy.get('select[multiple]').select(['opt1', 'opt2']) // Více hodnot

❌ Nesprávné použití

cy.select('value')                                // Chyba, nelze řetězit z 'cy'
cy.window().select('value')                       // Chyba, window není select

Argumenty

value (String|Number)

Hodnota, text nebo index option k výběru. Cypress najde option podle hodnoty, textu nebo indexu.

values (Array)

Pole hodnot pro multiple select. Použijte pro výběr více hodnot v select elementu s multiple atributem.

options (Object)

  • force (Boolean, default: false) - Vynutí výběr, přeskočí kontrolu actionability
  • timeout (Number) - Čas čekání na element
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací stejný select element. Lze řetězit další příkazy.

Příklady

Podle hodnoty

cy.get('select').select('cz')
cy.get('select[name="country"]').select('us')

Podle textu

cy.get('select').select('Česká republika')
cy.get('select').select('United States')

Více hodnot (multiple select)

cy.get('select[multiple]').select(['option1', 'option2'])

Poznámky

HTML select elementy

.select() funguje jen s HTML <select> elementy. Pro custom dropdowny (Angular Material, React Select, atd.) použijte jiný přístup.

Actionability

.select() je "action command", který čeká na actionability elementu. Element musí být viditelný, nepřekrytý a selectable.

Výběr option

Cypress najde option podle hodnoty (value atribut), textu (textový obsah) nebo indexu. Pokud najde více shod, vybere první.

Command Log

Příkaz je zobrazen v Command Log s informacemi o vybrané hodnotě a elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
