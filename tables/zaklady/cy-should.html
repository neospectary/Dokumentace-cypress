cy.should()

Assertions (ověření). Ověřuje stav elementu, hodnotu nebo podmínku. Základní příkaz pro testování. Automaticky opakuje assertion až do úspěchu nebo timeoutu.

Syntaxe

.should(chainers)
.should(chainers, value)
.should(callbackFn)

Použití

✅ Správné použití

cy.get('button').should('be.visible')           // S chainerem
cy.get('input').should('have.value', 'text')     // S hodnotou
cy.get('h1').should('contain', 'text')           // Částečná shoda
cy.get('div').should(($div) => {                 // Vlastní callback
  expect($div).to.have.length(3)
})

❌ Nesprávné použití

cy.should('be.visible')                          // Chyba, nelze řetězit z 'cy'
cy.window().should('be.visible')                 // Chyba, window není DOM element

Argumenty

chainers (String)

Chainer pro assertion (např. 'be.visible', 'have.text', 'contain', 'have.value', atd.). Viz sekce Assertions pro kompletní seznam.

value (Any)

Očekávaná hodnota pro assertion (např. text, třída, atribut, hodnota).

callbackFn (Function)

Vlastní callback funkce pro komplexní ověření. Funkce dostane element jako argument.

Co vrací (Yields)

Vrací stejný element, na kterém byla assertion provedena. Lze řetězit další assertions pomocí .and().

Příklady

Základní assertions

cy.get('button').should('be.visible')
cy.get('input').should('be.disabled')
cy.get('.error').should('not.exist')

Text a obsah

cy.get('h1').should('have.text', 'Vítejte')
cy.get('p').should('contain', 'text')
cy.get('span').should('include.text', 'část')

Atributy a hodnoty

cy.get('input').should('have.value', 'test')
cy.get('a').should('have.attr', 'href', '/page')
cy.get('img').should('have.attr', 'alt')

CSS třídy

cy.get('.btn').should('have.class', 'active')
cy.get('.item').should('not.have.class', 'disabled')

Vícenásobné assertions

cy.get('button')
  .should('be.visible')
  .and('be.enabled')
  .and('have.text', 'Odeslat')

Vlastní callback

cy.get('input').should(($input) => {
  expect($input.val()).to.match(/^\d+$/)
})

Poznámky

Retry mechanismus

.should() automaticky opakuje assertion (retry mechanismus). Čeká až do úspěchu nebo timeoutu. To znamená, že nemusíte explicitně čekat na element.

Řetězení assertions

Lze řetězit více assertions pomocí .and() aliasu: .should('be.visible').and('have.text', 'text').

Chai assertions

.should() používá Chai assertions pod kapotou. Všechny Chai chainers jsou dostupné.

Callback funkce

Vlastní callback funkce jsou užitečné pro komplexní ověření, která nelze vyjádřit pomocí standardních chainers.

Command Log

Příkaz je zobrazen v Command Log s informacemi o assertion. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
