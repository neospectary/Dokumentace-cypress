cy.task()

Spuštění Node.js úkolu. Umožňuje spustit kód v Node.js prostředí (mimo prohlížeč). Užitečné pro práci se soubory, databází nebo jinými operacemi, které nelze provést v prohlížeči.

Syntaxe

cy.task(taskName)
cy.task(taskName, arg)
cy.task(taskName, arg, options)

Použití

✅ Správné použití

cy.task('log', 'Hello')                   // S argumentem
cy.task('resetDb')                        // Bez argumentu
cy.task('readFile', 'data.json')          // Čtení souboru

❌ Nesprávné použití

cy.task()                                  // Chyba, chybí taskName
cy.get('.btn').task('log')                // Chyba, nelze řetězit
cy.task('undefined')                      // Chyba, úkol musí být definován

Argumenty

taskName (String)

Název úkolu definovaného v cypress.config.ts v setupNodeEvents funkci.

arg (Any)

Argument pro úkol. Může být jakákoli hodnota (string, number, object, atd.).

options (Object)

  • timeout (Number) - Čas čekání na dokončení úkolu
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s návratovou hodnotou úkolu. Lze použít s .then() pro přístup k výsledku.

Příklady

Definice úkolu v config

// V cypress.config.ts
export default defineConfig({
  e2e: {
    setupNodeEvents(on, config) {
      on('task', {
        log(message) {
          console.log(message)
          return null
        },
        readFile(path) {
          return fs.readFileSync(path, 'utf8')
        }
      })
    }
  }
})

Použití v testu

cy.task('log', 'Hello from Node.js')
cy.task('readFile', 'data.json').then((data) => {
  cy.log(data)
})

Poznámky

Definice úkolů

Úkoly musí být definovány v cypress.config.ts v setupNodeEvents funkci pomocí on('task', {...}).

Node.js prostředí

Úkoly se spouštějí v Node.js prostředí (mimo prohlížeč), takže můžete používat Node.js API (např. fs, path, databázové knihovny, atd.).

Návratová hodnota

Úkol musí vrátit hodnotu (nebo null/undefined). Vrácená hodnota je dostupná v testu pomocí .then().

Command Log

Příkaz je zobrazen v Command Log s informacemi o spuštěném úkolu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
