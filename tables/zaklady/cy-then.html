cy.then()

Práce s výsledky příkazů. Umožňuje přístup k hodnotám z předchozích příkazů a provádění vlastní logiky pomocí callback funkce.

Syntaxe

.then(callbackFn)
.then(options, callbackFn)

Použití

✅ Správné použití

cy.get('input').then(($input) => {          // Callback s elementem
  const value = $input.val()
  cy.log(`Hodnota: ${value}`)
})
cy.wrap(5).then((num) => num * 2)           // Callback s hodnotou

❌ Nesprávné použití

cy.then(() => {})                             // Chyba, nelze řetězit z 'cy'
cy.window().then(($el) => {})                // Chyba, window není DOM element

Argumenty

callbackFn (Function)

Callback funkce, která dostane jako argument hodnotu z předchozího příkazu (jQuery element, hodnota, objekt, atd.).

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s návratovou hodnotou callback funkce. Pokud callback vrací Cypress command, vrátí jeho výsledek. Lze řetězit další příkazy.

Příklady

Získání hodnoty

cy.get('input').then(($input) => {
  const value = $input.val()
  cy.log(`Hodnota je: ${value}`)
})

Práce s textem

cy.get('.price').then(($el) => {
  const text = $el.text()
  const number = parseFloat(text.replace('Kč', ''))
  expect(number).to.be.greaterThan(0)
})

Vícenásobné then()

cy.get('input')
  .then(($input) => $input.val())
  .then((value) => {
    cy.log(`Hodnota: ${value}`)
  })

S cy.wrap()

cy.get('input').then(($input) => {
  const value = $input.val()
  cy.wrap(value).should('eq', 'test')
})

Návrat do Cypress chainu

cy.get('input').then(($input) => {
  const value = $input.val()
  return cy.wrap(value)
}).should('eq', 'test')

Poznámky

Callback funkce

Callback dostává jako argument hodnotu z předchozího příkazu. Pro DOM elementy je to jQuery element, pro ostatní hodnoty je to přímo hodnota.

Návrat do Cypress chainu

Pro návrat do Cypress chainu použijte cy.wrap() nebo vraťte Cypress command. Vrácení hodnoty přímo ji předá dalšímu .then().

Async/await

Nepoužívejte async/await uvnitř .then() callbacku. Cypress příkazy nejsou Promises a nelze na ně čekat pomocí await.

Cyklické operace

Pro cyklické operace přes kolekci elementů použijte .each() místo .then().

Command Log

Příkaz je zobrazen v Command Log. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
