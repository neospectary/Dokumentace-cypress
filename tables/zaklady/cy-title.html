cy.title()

Získání title stránky. Vrací text z <title> tagu v HTML hlavičce. Užitečné pro ověření SEO title nebo navigace.

Syntaxe

cy.title()
cy.title(options)

Použití

✅ Správné použití

cy.title().should('eq', 'Domů')           // Přesná shoda
cy.title().should('include', 'Cypress')   // Částečná shoda
cy.title().should('match', /^.* - .*$/)   // Regex

❌ Nesprávné použití

cy.title('text')                           // Chyba, cy.title() nemá parametry
cy.get('.btn').title()                     // Chyba, nelze řetězit

Argumenty

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s textem title stránky. Lze použít s .should() pro ověření.

Příklady

Základní ověření

cy.title().should('eq', 'Domů')
cy.title().should('include', 'Cypress')

S regex

cy.title().should('match', /^.* - .*$/)

Ověření po navigaci

cy.visit('/dashboard')
cy.title().should('eq', 'Dashboard')
cy.title().should('include', 'Dashboard')

Poznámky

Title tag

cy.title() vrací text z <title> tagu v HTML hlavičce. Toto je stejné jako document.title.

Automatické čekání

cy.title() automaticky čeká na načtení stránky. Title musí být dostupný před pokračováním.

Command Log

Příkaz je zobrazen v Command Log s aktuálním title stránky. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
