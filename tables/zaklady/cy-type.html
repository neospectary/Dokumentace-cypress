cy.type()

Psaní textu do input polí, textarea nebo editovatelných elementů. Simuluje psaní na klávesnici s událostmi keyboard a input.

Syntaxe

.type(text)
.type(text, options)

Použití

✅ Správné použití

cy.get('input').type('text')                // Psaní textu
cy.get('textarea').type('Long text...')      // Psaní do textarea
cy.get('input').type('text{enter}')          // S Enter klávesou
cy.get('[contenteditable]').type('text')     // Editovatelný element

❌ Nesprávné použití

cy.type('text')                               // Chyba, nelze řetězit z 'cy'
cy.window().type('text')                      // Chyba, window nevrací DOM element

Argumenty

text (String)

Text k napsání nebo speciální klávesy ({enter}, {esc}, {backspace}, atd.).

options (Object)

  • delay (Number, default: 10) - Delay mezi znaky v milisekundách
  • parseSpecialCharSequences (Boolean, default: true) - Zda parsovat speciální sekvence
  • force (Boolean, default: false) - Vynutí psaní, přeskočí kontrolu actionability
  • timeout (Number) - Čas čekání na element

Co vrací (Yields)

Vrací stejný element, do kterého bylo psáno. Lze řetězit další příkazy.

Příklady

Základní psaní

cy.get('input[name="email"]').type('test@example.com')
cy.get('textarea').type('Dlouhý text...')

S rychlým psaním (bez delay)

cy.get('input').type('text', { delay: 0 })

Speciální klávesy

cy.get('input').type('text{enter}')        // Enter
cy.get('input').type('{esc}')               // Escape
cy.get('input').type('{backspace}')         // Backspace
cy.get('input').type('{selectall}{del}')    // Vybrat vše a smazat

Kombinace kláves

cy.get('input').type('{ctrl}a')            // Ctrl+A (Select All)
cy.get('input').type('{cmd}c')             // Cmd+C (Mac)
cy.get('input').type('{shift}text')        // Shift+text

Poznámky

Actionability

.type() je "action command", který čeká na actionability elementu. Element musí být viditelný, nepřekrytý a focusable.

Delay mezi znaky

Výchozí delay mezi znaky je 10ms, což simuluje přirozené psaní. Pro rychlejší testy použijte { delay: 0 }.

File inputy

.type() nelze použít pro file inputy. Pro upload souborů použijte cy.fixture() a plugin cypress-file-upload.

Speciální znaky

Pro psaní literálních složených závorek použijte dvojité závorky: {{ a }}.

Command Log

Příkaz je zobrazen v Command Log s informacemi o napsaném textu a elementu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
