cy.url()

Získání aktuální URL stránky. Užitečné pro ověření navigace nebo routingu. Vrací celou URL včetně protokolu a domény.

Syntaxe

cy.url()
cy.url(options)

Použití

✅ Správné použití

cy.url().should('include', '/dashboard')        // Ověření URL
cy.url().should('eq', 'https://example.com')    // Přesná shoda
cy.url({ decode: true }).should('contain', 'text') // Dekódovaná URL

❌ Nesprávné použití

cy.get('.btn').url()                            // Chyba, nelze řetězit
cy.url('/page')                                 // Chyba, cy.url() nemá parametry

Argumenty

options (Object)

  • decode (Boolean, default: false) - Dekódovat URL
  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s aktuální URL jako string. Lze použít s .should() pro ověření.

Příklady

Základní ověření

cy.url().should('include', '/dashboard')
cy.url().should('eq', 'https://example.com/page')

Ověření části URL

cy.url().should('contain', '/users/')
cy.url().should('match', /\/users\/\d+$/)

S decode

cy.url({ decode: true }).should('include', 'český text')

Poznámky

Alias pro cy.location()

cy.url() je alias pro cy.location('href'). Oba vrací stejnou hodnotu.

Části URL

Pro přístup k částem URL (pathname, query, hash, atd.) použijte cy.location() místo cy.url().

Command Log

Příkaz je zobrazen v Command Log s aktuální URL. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
