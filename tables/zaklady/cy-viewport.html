cy.viewport()

Změna velikosti viewportu (okna prohlížeče). Užitečné pro testování responzivního designu. Změní rozlišení prohlížeče pro aktuální test.

Syntaxe

cy.viewport(width, height)
cy.viewport(preset)
cy.viewport(width, height, options)

Použití

✅ Správné použití

cy.viewport(1920, 1080)              // Vlastní rozlišení
cy.viewport('iphone-x')              // Preset
cy.viewport(375, 667)                // Mobilní rozlišení

❌ Nesprávné použití

cy.viewport()                         // Chyba, chybí parametry
cy.get('.btn').viewport(1920, 1080)  // Chyba, nelze řetězit

Argumenty

width (Number)

Šířka viewportu v pixelech.

height (Number)

Výška viewportu v pixelech.

preset (String)

Předdefinované rozlišení: 'iphone-x', 'ipad-2', 'macbook-15', 'macbook-13', 'macbook-11', atd.

options (Object)

  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable. Změní velikost viewportu pro aktuální test. Viewport zůstane nastavený pro celý test, dokud není změněn.

Příklady

Vlastní rozlišení

cy.viewport(1920, 1080)
cy.viewport(375, 667)  // iPhone

Presety

cy.viewport('iphone-x')
cy.viewport('ipad-2')
cy.viewport('macbook-15')

V testu

it('test na mobilu', () => {
  cy.viewport('iphone-x')
  cy.visit('/')
  cy.get('.menu').should('not.be.visible')
})

Poznámky

Scope změny

Změna viewportu platí pro celý test. Lze použít vícekrát v jednom testu pro testování různých rozlišení.

Presety

Cypress poskytuje předdefinované presety pro běžná zařízení. Seznam všech presetů naleznete v oficiální dokumentaci.

Command Log

Příkaz je zobrazen v Command Log s informacemi o nastaveném viewportu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
