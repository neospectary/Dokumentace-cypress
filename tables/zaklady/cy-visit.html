cy.visit()

Navigace na URL stránku. Základní příkaz pro otevření stránky v testu. Načte URL a čeká na načtení stránky.

Syntaxe

cy.visit(url)
cy.visit(url, options)

Použití

✅ Správné použití

cy.visit('https://example.com')      // Absolutní URL
cy.visit('/dashboard')                // Relativní URL (k baseUrl)
cy.visit('/login', { method: 'POST' }) // S options

❌ Nesprávné použití

cy.visit()                              // Chyba, chybí URL
cy.get('.btn').visit('/page')           // Chyba, nelze řetězit

Argumenty

url (String)

URL stránky k návštěvě. Může být absolutní URL nebo relativní cesta (relativní k baseUrl z config).

options (Object)

  • method (String) - HTTP metoda (GET, POST, atd.)
  • body (Object|String) - Tělo requestu
  • headers (Object) - HTTP hlavičky
  • timeout (Number) - Čas čekání na načtení stránky
  • onBeforeLoad (Function) - Callback před načtením
  • onLoad (Function) - Callback po načtení
  • failOnStatusCode (Boolean) - Zda selhat při HTTP error

Co vrací (Yields)

Vrací Chainable s window objektem. Po dokončení je stránka plně načtená a připravená pro interakci.

Příklady

Základní použití

cy.visit('https://example.com')
cy.visit('/dashboard')  // relativní k baseUrl

S options

cy.visit('/login', {
  method: 'POST',
  body: { username: 'admin' }
})

V beforeEach

beforeEach(() => {
  cy.visit('/dashboard')
})

S timeoutem

cy.visit('/slow-page', { timeout: 30000 })

Poznámky

Čekání na načtení

cy.visit() automaticky čeká na načtení stránky (pageLoadTimeout). Stránka musí být plně načtená před pokračováním.

Base URL

Relativní URL se kombinují s baseUrl z Cypress config. Pokud máte baseUrl: 'http://localhost:4200', pak cy.visit('/dashboard') navštíví http://localhost:4200/dashboard.

DOM Ready

Cypress automaticky čeká na DOM ready event. Pro SPA aplikace může být potřeba čekat na další události pomocí cy.wait() nebo assertions.

Command Log

Příkaz je zobrazen v Command Log s informacemi o navštívené URL. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
