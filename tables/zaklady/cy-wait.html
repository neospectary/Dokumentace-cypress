cy.wait()

Čekání na HTTP requesty (s aliasem) nebo časový interval. Pro requesty čeká na dokončení. Pro časový interval čeká zadaný počet milisekund.

Syntaxe

cy.wait(ms)
cy.wait(alias)
cy.wait(aliases)

Použití

✅ Správné použití

cy.wait('@getUsers')                       // Čekání na request
cy.wait(['@getUsers', '@getPosts'])        // Čekání na více requestů
cy.wait(1000)                              // Čekání na čas (používejte opatrně)

❌ Nesprávné použití

cy.get('.btn').wait(1000)                  // Chyba, cy.wait() nelze řetězit
cy.wait()                                  // Chyba, chybí parametr

Argumenty

ms (Number)

Počet milisekund k čekání. Poznámka: cy.wait(ms) je anti-pattern - preferujte implicitní čekání nebo čekání na requesty.

alias (String)

Alias requestu (s @ prefixem). Request musí být dříve zachycen pomocí cy.intercept() a označen aliasem pomocí .as().

aliases (Array)

Pole aliasů requestů. Cypress počká na všechny requesty v poli.

Co vrací (Yields)

Pro requesty vrací Chainable s response objektem. Pro časový interval vrací Chainable bez hodnoty. Lze řetězit další příkazy.

Příklady

Čekání na request

cy.intercept('GET', '/api/users').as('getUsers')
cy.visit('/users')
cy.wait('@getUsers')

Více requestů

cy.wait(['@getUsers', '@getPosts'])

S ověřením response

cy.wait('@getUsers').then((interception) => {
  expect(interception.response.statusCode).to.eq(200)
})

Čekání na čas (používejte opatrně)

cy.wait(1000)  // čeká 1 sekundu (anti-pattern)

Poznámky

Implicitní čekání

Cypress automaticky čeká na elementy v příkazech (např. cy.get(), .click()). Preferujte implicitní čekání místo cy.wait(ms).

Čekání na requesty

cy.wait('@alias') je v pořádku a doporučený způsob, jak čekat na API requesty. Zajišťuje, že test pokračuje až po dokončení requestu.

Anti-pattern

cy.wait(ms) pro čekání na čas je anti-pattern. Místo toho čekejte na konkrétní element nebo stav pomocí .should() nebo assertions.

Command Log

Příkaz je zobrazen v Command Log s informacemi o čekání. Pro requesty zobrazí detaily requestu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
