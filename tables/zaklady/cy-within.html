cy.within()

Omezení scope hledání. Všechny příkazy uvnitř callback funkce hledají jen v rámci vybraného elementu (ne v celém dokumentu). Užitečné pro práci s formuláři, modály nebo jinými izolovanými sekcemi.

Syntaxe

.within(callbackFn)
.within(options, callbackFn)

Použití

✅ Správné použití

cy.get('form').within(() => {            // Formulář
  cy.get('input[name="email"]').type('test@example.com')
  cy.get('button').click()
})
cy.get('.modal').within(() => {          // Modal
  cy.get('.close-button').click()
})

❌ Nesprávné použití

cy.within(() => {})                      // Chyba, nelze řetězit z 'cy'
cy.window().within(() => {})             // Chyba, window není DOM element

Argumenty

callbackFn (Function)

Callback funkce obsahující Cypress příkazy. Všechny cy.get() uvnitř této funkce hledají jen v rámci aktuálního elementu.

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s původním elementem. Lze řetězit další příkazy.

Příklady

Základní použití

cy.get('form').within(() => {
  cy.get('input[name="email"]').type('test@example.com')
  cy.get('input[name="password"]').type('password')
  cy.get('button').click()
})

S modálem

cy.get('.modal').within(() => {
  cy.get('.title').should('contain', 'Confirm')
  cy.get('.close-button').click()
})

Rozdíl s cy.get()

// ❌ Bez within - get hledá všude
cy.get('form')
cy.get('input')  // Najde všechny inputy na stránce

// ✅ S within - get hledá jen uvnitř formu
cy.get('form').within(() => {
  cy.get('input')  // Najde jen inputy uvnitř formu
})

Poznámky

Scope hledání

Všechny cy.get() uvnitř callback funkce hledají jen v rámci aktuálního elementu, ne v celém dokumentu. To zjednodušuje selektory a zrychluje testy.

Výhody

.within() je užitečné pro práci s formuláři, modály nebo jinými izolovanými sekcemi. Zjednodušuje selektory a zvyšuje čitelnost testů.

Command Log

Příkaz je zobrazen v Command Log. Všechny příkazy uvnitř callback funkce jsou viditelné v logu. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
