cy.wrap()

Obalení hodnoty do Cypress chainu. Umožňuje použít Cypress příkazy na hodnoty mimo chain (string, number, object, jQuery element).

Syntaxe

cy.wrap(subject)
cy.wrap(subject, options)

Použití

✅ Správné použití

cy.wrap('text').should('eq', 'text')         // String
cy.wrap(5).should('eq', 5)                   // Number
cy.wrap({ name: 'John' }).should('have.property', 'name') // Object
cy.get('input').then(($input) => {           // Z then()
  cy.wrap($input.val()).should('eq', 'test')
})

❌ Nesprávné použití

cy.wrap()                                     // Chyba, chybí hodnota
cy.get('.btn').wrap('text')                  // Chyba, nelze řetězit

Argumenty

subject (Any)

Hodnota k obalení. Může být string, number, object, array, jQuery element nebo jakákoli jiná hodnota.

options (Object)

  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable s obalenou hodnotou. Lze řetězit další Cypress příkazy (např. .should(), .then()).

Příklady

Obalení hodnoty z then()

cy.get('input').then(($input) => {
  const value = $input.val()
  cy.wrap(value).should('eq', 'test')
})

Obalení primitivní hodnoty

cy.wrap('text').should('eq', 'text')
cy.wrap(5).should('eq', 5)
cy.wrap(true).should('be.true')

Obalení jQuery elementu

cy.get('li').each(($li) => {
  cy.wrap($li).should('be.visible')
})

Obalení objektu

cy.wrap({ name: 'John', age: 30 })
  .should('have.property', 'name')
  .and('have.property', 'age')

Poznámky

Návrat do Cypress chainu

cy.wrap() je užitečný pro návrat do Cypress chainu z callback funkcí (např. .then(), .each()). Umožňuje použít Cypress příkazy na hodnoty mimo chain.

Typ hodnoty

cy.wrap() může obalit jakoukoli hodnotu - string, number, object, array, jQuery element, atd. Cypress příkazy pak fungují na obalené hodnotě.

Použití v each()

Uvnitř .each() použijte cy.wrap() pro práci s elementem - umožní použít Cypress příkazy na element z callback funkce.

Command Log

Příkaz je zobrazen v Command Log s informacemi o obalené hodnotě. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
