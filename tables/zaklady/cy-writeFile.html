cy.writeFile()

Zápis do souboru. Uloží data do souboru v projektu. Užitečné pro vytváření testovacích dat, logování výsledků nebo ukládání dočasných souborů.

Syntaxe

cy.writeFile(filePath, contents)
cy.writeFile(filePath, contents, options)

Použití

✅ Správné použití

cy.writeFile('data.json', { name: 'John' })  // JSON objekt
cy.writeFile('log.txt', 'Text')              // Textový obsah
cy.writeFile('data.json', '{"key": "value"}') // JSON string

❌ Nesprávné použití

cy.writeFile()                                // Chyba, chybí parametry
cy.get('.btn').writeFile('file.txt', 'text') // Chyba, nelze řetězit

Argumenty

filePath (String)

Cesta k souboru. Relativní k root projektu nebo absolutní cesta.

contents (String|Object)

Obsah k zápisu. Může být string nebo objekt. Pro JSON objekty automaticky převede na JSON string.

options (Object)

  • flag (String) - Flag pro fs.writeFile ('w', 'a', atd.)
  • encoding (String) - Encoding pro soubor
  • timeout (Number) - Čas čekání
  • log (Boolean, default: true) - Zobrazí příkaz v Command Log

Co vrací (Yields)

Vrací Chainable. Soubor je uložen po dokončení příkazu.

Příklady

Základní zápis

cy.writeFile('cypress/fixtures/data.json', {
  name: 'John',
  age: 30
})

Textový soubor

cy.writeFile('log.txt', 'Test dokončen')

S append

cy.writeFile('log.txt', 'Nový řádek\n', { flag: 'a' })

Poznámky

JSON formátování

Pro JSON objekty automaticky převede na JSON string a formátuje. Pro vlastní formátování předajte string.

Cesta k souboru

Cesta je relativní k root projektu. Pokud soubor neexistuje, bude vytvořen. Pokud existuje, bude přepsán (pokud není použita flag 'a').

Encoding

Výchozí encoding je 'utf8'. Pro binární soubory použijte 'base64'.

Command Log

Příkaz je zobrazen v Command Log s informacemi o zapsaném souboru. Kliknutím na příkaz v logu uvidíte detaily v konzoli.
